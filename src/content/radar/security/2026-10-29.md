## 今日高危漏洞

### 1. CVE-2026-110879 — jackson-databind 类型反序列化漏洞

jackson-databind 校验类名类型 ID 的外部类时，接受泛型内部攻击者选择类，可能通过反序列化实现任意代码执行。影响所有使用 jackson-databind 的 Java 序列化栈。

- **CVSS**：9.8
- **影响组件**：jackson-databind（Java）
- **与当前栈关联**：当前 Java 后端技术栈使用 jackson-databind，需立即确认版本并修复
- **来源等级**：official
- **来源名称**：NVD
