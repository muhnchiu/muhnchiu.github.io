## 今日高危漏洞

### 1. CVE-2026-129448 — Apache Roller 未认证反序列化 RCE（CISA KEV 新增）

Apache Roller 4.0.0 至 6.1.4 版本中，XML-RPC 端点在验证请求者身份之前即接受并反序列化供应商扩展类型，攻击者可无需认证即触发任意代码执行。该漏洞已于 2026-11-20 被 CISA 收录至 KEV 目录，属于已知被利用漏洞。Apache Roller 为较老的 Java 内容管理系统，当前技术栈未部署该组件；若历史项目或第三方系统仍在使用，需立即升级或下线。

- **CVSS**：未确认（NVD 页面 CVSS 数据未在抓取范围内）
- **影响组件**：Apache Roller 4.0.0 - 6.1.4（Java 内容管理系统）
- **与当前栈关联**：当前 Java 后端技术栈未使用 Apache Roller；需确认历史项目或第三方集成是否仍有部署
- **来源等级**：official
- **来源名称**：CISA KEV / NVD

### 2. CVE-2026-65094 — NVIDIA Bluefield VIRTIO-Net Write-What-Where（CVSS 9.0）

NVIDIA VIRTIO-Net for Bluefield 中的 Virtio-Net 驱动存在 Write-What-Where 漏洞，VM 内用户可构造恶意消息触发，成功利用后在 Virtio-Net 驱动范围内实现代码执行。该漏洞影响使用 NVIDIA Bluefield 智能网卡进行虚拟化网络卸载的环境，属于高严重度但影响面相对狭窄（需特定硬件）。当前环境无 Bluefield 网卡，与 Java/Spring Boot/MySQL/Nginx/Node.js 栈无直接关联。

- **CVSS**：9.0
- **影响组件**：NVIDIA VIRTIO-Net for Bluefield（智能网卡驱动）
- **与当前栈关联**：无直接关联（当前环境未使用 Bluefield 智能网卡，未确认）
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-133553 — crun tmpfs 竞争条件：容器文件复制到宿主机 /proc/sys（CVSS 7.8）

crun 在将文件复制到挂载了 tmpcopyup 的 tmpfs 时，会按路径名第二次打开目标文件。若共享可写卷的容器能在此窗口内修改该路径，crun 将把镜像文件复制到宿主机文件，包括 /proc/sys 下的文件，可能造成宿主机配置被篡改。该漏洞影响使用 crun 作为 OCI 运行时且涉及 tmpfs 卷共享的容器环境，当前 Java/Node.js 技术栈未使用 crun，但若基础设施层有容器编排组件需关注。

- **CVSS**：7.8
- **影响组件**：crun（OCI 容器运行时）
- **与当前栈关联**：无直接关联；若基础设施使用 crun 作为容器运行时需评估
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-133528 — BeamNG.drive LuaJIT FFI 沙箱逃逸（CVSS 8.6）

BeamNG.drive 0.40.6 之前版本中，JIT 编译的 LuaJIT trace 省略了 FFI 数组边界检查，攻击者可通过恶意 mod 构造 FFI 写循环，利用 tostring() 地址泄漏进行越界写，重新启用 ffi.load 后以游戏用户权限执行任意命令。属游戏引擎场景，与当前 Web/后端技术栈无关联。

- **CVSS**：8.6
- **影响组件**：BeamNG.drive < 0.40.6（游戏引擎）
- **与当前栈关联**：无直接关联
- **来源等级**：official
- **来源名称**：NVD / VulnCheck

### 5. CVE-2026-133534 — PowerLink SQL 注入（未认证，CVSS 7.5）

Neotroni Lighting 开发的 PowerLink 产品存在 SQL 注入漏洞，未认证的远程攻击者可注入任意 SQL 命令读取数据库内容。影响工业自动化照明控制场景，当前技术栈未使用该产品。

- **CVSS**：7.5
- **影响组件**：PowerLink（Neotroni Lighting，工业自动化）
- **与当前栈关联**：无直接关联
- **来源等级**：official
- **来源名称**：NVD
