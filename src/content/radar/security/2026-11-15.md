## 今日高危漏洞

### 1. CVE-2026-129250 — Edimax BR6478ACV2 1.23 PPTP 设置函数远程代码执行

NVD 收录 Edimax BR6478ACV2 固件 1.23 的安全缺陷，受影响的函数为 formPPTPSetup，CVSS 评分 9.9。Edimax 为网络设备厂商，该漏洞若暴露于公网且未打补丁，可被远程利用；未确认在野利用记录，也未确认与当前 Java 后端、Node.js 前端或办公网络部署直接关联。

- **CVSS**：9.9
- **影响组件**：Edimax BR6478ACV2（固件 1.23）
- **与当前栈关联**：未确认（非 Java/Spring Boot/MySQL/Nginx/Node.js 组件；若网络设备清单中存在该型号需优先排查管理接口暴露面）
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-126173 — WordPress AutomatorWP Pro Webhook 插件授权绕过

WordPress 插件 AutomatorWP Pro 的 Webhook 附加组件在受影响版本中存在授权绕过缺陷（CVSS 9.8），攻击者可绕过权限控制触发 Webhook 逻辑。当前栈以 Java/Node.js 为主，未确认使用 WordPress；若存在 WordPress 站点（如文档、运营站）需升级插件至修复版本。

- **CVSS**：9.8
- **影响组件**：WordPress AutomatorWP Pro 插件（Webhook 附加组件，受影响版本见 NVD 详情）
- **与当前栈关联**：未确认（与当前 Java/Node 栈无直接关联；WordPress 站点需单独排查）
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-120522 — WordPress Cloud Storage Manager for Fluent Forms 插件缺陷

Fluent Forms 的云存储管理插件（支持 Google Drive、Dropbox、OneDrive、S3 上传）存在安全缺陷，CVSS 9.8。影响范围与使用场景同 AutomatorWP 类 WordPress 生态组件；当前栈未确认使用，保持观察即可。

- **CVSS**：9.8
- **影响组件**：WordPress Cloud Storage Manager for Fluent Forms 插件
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

- **CVSS**：8.7
