## 今日高危漏洞

### 1. CVE-2026-133469 — Vates Xen Orchestra 类型校验缺陷

Vates Xen Orchestra 存在指定类型校验不当漏洞，攻击者可利用该缺陷执行未授权操作。该漏洞已被纳入 CISA KEV 目录，表明已被在野利用。Xen Orchestra 常用于虚拟化环境管理，若当前基础设施中使用该产品或类似虚拟化平台，需立即评估影响。

- **CVSS**：未确认
- **影响组件**：Vates Xen Orchestra
- **与当前栈关联**：若使用虚拟化环境（KVM/Xen 相关），需检查 Xen Orchestra 版本并打补丁；当前 Java/Spring Boot/MySQL/Nginx/Node.js 栈不直接涉及
- **来源等级**：official
- **来源名称**：CISA KEV

### 2. CVE-2026-133323 — Mitel MiCollab OS 命令注入

Mitel MiCollab 存在操作系统命令注入漏洞，攻击者可构造恶意输入执行系统命令。该漏洞已被纳入 CISA KEV 目录。若网络中使用 Mitel MiCollab 系列通信设备，需立即隔离并打补丁。

- **CVSS**：未确认
- **影响组件**：Mitel MiCollab
- **与当前栈关联**：未确认（若网络中有 Mitel 通信设备则高度相关）
- **来源等级**：official
- **来源名称**：CISA KEV

### 3. CVE-2026-103406 — HPE/Juniper Session Smart Conductor 相关

HPE Juniper Session Smart Conductor 和 Session Smart Router 存在安全漏洞，已被纳入 CISA KEV 目录。该组件常用于网络流量调度，若网络架构中包含该产品，需评估影响。

- **CVSS**：未确认
- **影响组件**：HPE Juniper Session Smart Conductor / Session Smart Router
- **与当前栈关联**：未确认（若网络中有 HPE Juniper 网络设备则相关）
- **来源等级**：official
- **来源名称**：CISA KEV

### 4. CVE-2026-133303 — Mitel MiCollab XML 注入

Mitel MiCollab 存在 XML 注入漏洞，攻击者可构造恶意 XML 载荷进行攻击。该漏洞已被纳入 CISA KEV 目录。

- **CVSS**：未确认
- **影响组件**：Mitel MiCollab
- **与当前栈关联**：未确认（若使用 Mitel MiCollab 则相关）
- **来源等级**：official
- **来源名称**：CISA KEV

### 5. CVE-2026-133275 — Mitel MiCollab 危险类型文件上传

Mitel MiCollab 存在未限制的危险类型文件上传漏洞，攻击者可上传恶意文件。该漏洞已被纳入 CISA KEV 目录。

- **CVSS**：未确认
