## 今日高危漏洞

### 1. CVE-2026-110264 — GitLab 7.0 至 19.1 严重漏洞

NVD 收录的 GitLab CE/EE 高危公告，影响版本从 7.0 起覆盖 18.11.13 之前、19.0.10 之前和 19.1 系列版本。公告描述截断，未确认具体攻击路径、在野利用情况或修复验证结果，因此仅按官方高危信息跟踪。

- **CVSS**：10.0
- **影响组件**：GitLab CE/EE 7.0 至 19.1 系列（截断前信息）
- **与当前栈关联**：当前技术栈未确认使用 GitLab，如部署 GitLab 需核实版本与公告对照
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-114635 Traefik SNI 检查认证绕过

Traefik 2.11.58 之前和 3.7.14 之前存在认证绕过漏洞，公告指出 SNI 检查在特定条件下被跳过。修复边界明确，属于网关组件常见认证边界问题。

- **CVSS**：8.7
- **影响组件**：Traefik before v2.11.58 and v3.7.14
- **与当前栈关联**：当前技术栈未确认使用 Traefik，如使用反向代理网关需升级至 2.11.58 或 3.7.14
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-114637 Traefik 实验 FastProxy 认证绕过

Traefik 3.2.0 之前至 3.7.14 的实验性 FastProxy 连接存在认证绕过漏洞。该类漏洞影响需要显式启用实验 FastProxy 的部署。

- **CVSS**：8.7
- **影响组件**：Traefik v3.2.0 之前至 v3.7.14
- **与当前栈关联**：当前技术栈未确认使用 Traefik 实验 FastProxy，启用者需升级并验证认证
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-102764 BeyondTrust 认证绕过（CISA KEV）

CISA KEV 于 2026-10-16 收录 BeyondTrust Remote Support 认证绕过漏洞，属于已列入已知被利用目录的远程支持类漏洞。公告未提供与当前环境的确认关联。

- **CVSS**：未确认
- **影响组件**：BeyondTrust Remote Support
- **与当前栈关联**：当前技术栈未确认使用 BeyondTrust，如部署远程支持系统需升级补丁
- **来源等级**：official
- **来源名称**：CISA

### 5. CVE-2026-96654 至 96656 Plex Media Server 多条 KEV 漏洞

CISA KEV 于 2026-10-20 收录 Plex Media Server 三条相关漏洞，涉及外部文件名或路径控制、SSRF 和编码 URI 方案。该组公告未确认与当前基础设施的关联。
