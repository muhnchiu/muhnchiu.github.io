## 今日高危漏洞

### 1. CVE-2026-125370 — Kubero 3.0.0 至 3.1.1 认证绕过漏洞

Kubero 是 Kubernetes 应用管理平台，3.0.0 至 3.1.1 版本存在认证绕过漏洞，允许未认证远程攻击者获取系统访问权限。CVSS 9.8 为最高严重级别。当前技术栈为 Java/Spring Boot + Node.js，未确认当前基础设施使用 Kubero。若部署了 Kubernetes 且有 Kubero 平台，需立即升级。

- **CVSS**：9.8
- **影响组件**：Kubero 3.0.0 - 3.1.1
- **与当前栈关联**：未确认当前技术栈使用 Kubero
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-125391 — Webmin through 2.670 OS 命令注入漏洞

Webmin 2.670 及更早版本中 samba/save_euser.cgi 存在 OS 命令注入漏洞，已认证 Super User 可执行任意系统命令。当前技术栈未使用 Webmin 作为服务器管理工具，但若网络层有 Webmin 部署需检查。

- **CVSS**：7.2
- **影响组件**：Webmin <= 2.670
- **与当前栈关联**：未确认当前技术栈使用 Webmin
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-125382 — Map-OS 5.0.0 至 5.2.2 权限提升漏洞

Map-OS REST 用户 API 存在权限提升漏洞，非管理员用户可获取更高权限。独立产品，未确认当前技术栈使用。

- **CVSS**：7.2
- **影响组件**：Map-OS 5.0.0 - 5.2.2（不含）
- **与当前栈关联**：未确认当前技术栈使用 Map-OS
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-125358 — universal-modder WebSocket Origin 校验缺失

universal-modder 在 commit e88f6876745427321eb755ebc98276063a962d8a 之前存在 WebSocket Origin 校验缺失漏洞。当前技术栈未确认使用该项目。

- **CVSS**：8.1
- **影响组件**：universal-modder（commit e88f687 之前）
- **与当前栈关联**：未确认当前技术栈使用 universal-modder
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-125383 / CVE-2026-125384 — INDOTALENT WHMS 认证绕过与默认凭据

INDOTALENT WHMS 10.20261109 之前版本存在两个严重漏洞：认证绕过（9.8）和默认凭据（9.8）。独立产品，未确认当前技术栈使用。

- **CVSS**：9.8（每条）
- **影响组件**：INDOTALENT WHMS < 10.20261109
- **与当前栈关联**：未确认当前技术栈使用 INDOTALENT WHMS
- **来源等级**：official
- **来源名称**：NVD

## CISA KEV 新增（已知被利用漏洞）

CISA KEV 目录 2026-11-09 和 2026-11-10 新增多条记录，与当前基础设施相关的重点如下：

- **CVE-2026-125350**（2026-11-10）：Google Chromium Use-After-Free 漏洞。当前前端使用现代浏览器，Chromium 为底层引擎，需确认浏览器版本是否已修补。
- **CVE-2026-116606**（2026-11-10）：Barracuda ESG 认证缺陷。当前技术栈未确认使用 Barracuda 邮件网关，若网络层部署需检查。
- **CVE-2026-111560**（2026-11-10）：Barracuda 多产品 OS 命令注入漏洞。同上，未确认当前环境使用 Barracuda。
- **CVE-2026-102895**（2026-11-09）：GPUStack 不当认证漏洞。AI 推理框架，若当前环境部署 GPUStack 需立即检查。
- **CVE-2026-123158**（2026-11-09）：OpenBSD OpenSSH 异常状态码漏洞。当前后端运行在 Rocky Linux 9.7 上，OpenSSH 为标准系统组件，需确认系统 OpenSSH 版本及是否受该 CVE 影响。建议检查 `yum list updates` 中是否有 openssh 安全更新。
- **CVE-2026-116779**（2026-11-09）：SignalWire FreeSwitch 代码注入漏洞。未确认当前环境使用 FreeSwitch，若使用需立即升级。
- **CVE-2026-123218**（2026-11-09）：IBM Aspera Faspex 授权缺陷。未确认当前环境使用 IBM Aspera，若使用需检查。

新增日期以 CISA 官方目录为准。OpenSSH 和 Chromium 条目与当前基础设施直接相关，建议优先处理。
