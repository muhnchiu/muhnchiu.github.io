## 今日高危漏洞

### 1. CVE-2026-94493 — Gigatech PDV5701 未明处理远程代码执行（CVSS 10.0）

Gigatech PDV5701 固件版本 1.0.31_240305_112640 存在严重漏洞，攻击者可通过未明处理路径实现远程代码执行。该漏洞影响特定嵌入式设备，CVSS 评分 10.0，为今日最高危漏洞。

- **CVSS**：10.0
- **影响组件**：Gigatech PDV5701 固件
- **与当前栈关联**：无关。嵌入式设备漏洞，不影响多乐士 CMS 或本机环境

### 2. CVE-2026-13355 — Meta Box AIO WordPress 插件权限提升（CVSS 9.8）

Meta Box AIO 插件在 2.0 及之前版本存在权限提升漏洞，低权限用户可提升至管理员权限。攻击者需具备已认证会话，利用插件认证检查缺陷完成提权。

- **CVSS**：9.8
- **影响组件**：WordPress Meta Box AIO 插件（<= 2.0）
- **与当前栈关联**：无关。WordPress 生态，多乐士 CMS 技术栈不涉及

### 3. CVE-2026-19658 — Give Tributes WordPress 插件 PHP 对象注入（CVSS 9.8）

Give Tributes 插件 2.3.1 及之前所有版本存在 PHP 对象注入漏洞，攻击者可通过精心构造的序列化数据利用该方法实现任意代码执行。需要插件安装并激活 GiveWP 依赖。

- **CVSS**：9.8
- **影响组件**：WordPress Give Tributes 插件（<= 2.3.1）
- **与当前栈关联**：无关。WordPress 生态漏洞

### 4. CVE-2026-87078 — Net::IDN::Punycode Perl 输出缓冲区信息泄露（CVSS 9.1）

Net::IDN::Punycode 模块在 2.302 至 2.590（不含）之间，对每个被拒绝的标签解码时会泄露输出缓冲区内容，可能导致敏感内存数据暴露。

- **CVSS**：9.1
- **影响组件**：Perl Net::IDN::Punycode 模块
- **与当前栈关联**：无关。Perl 生态，多乐士 CMS 为 Java/Node.js 栈

### 5. CVE-2026-87080 — Net::IDN::Punycode::PP Perl 截断标签解码漏洞（CVSS 9.1）

Net::IDN::Punycode::PP 在 2.590 之前版本中，解码截断标签时会产生从未输入的字符，可能导致域名验证绕过或进一步注入攻击。

- **CVSS**：9.1
- **影响组件**：Perl Net::IDN::Punycode::PP 模块
- **与当前栈关联**：无关。Perl 生态漏洞

### 6. CVE-2025-1281 — BM Content Builder WordPress 插件任意文件删除（CVSS 8.8）

BM Content Builder 插件存在文件路径验证不足问题，攻击者可通过构造请求删除服务器上任意文件，可能导致服务中断或进一步利用。

- **CVSS**：8.8
- **影响组件**：WordPress BM Content Builder 插件
- **与当前栈关联**：无关。WordPress 生态漏洞

### 7. CVE-2026-92438 — Ninja Forms WordPress 插件 XSS（CVSS 8.8）

Ninja Forms 3.15.3 提交表单字段值未转义直接输出，导致存储型 XSS。攻击者可通过表单提交注入恶意脚本。

- **CVSS**：8.8
- **影响组件**：WordPress Ninja Forms 插件 3.15.3
- **与当前栈关联**：无关。WordPress 插件漏洞

### 8. CVE-2026-74766 — Net::IDN::Punycode Perl 堆释放后使用（CVSS 8.4）

Net::IDN::Punycode 2.301 至 2.590（不含）版本存在堆释放后使用漏洞，解码特定码点时可触发，可能导致内存破坏或代码执行。

- **CVSS**：8.4
- **影响组件**：Perl Net::IDN::Punycode 模块
- **与当前栈关联**：无关。Perl 生态漏洞
