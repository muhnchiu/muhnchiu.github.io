## 今日高危漏洞

### 1. CVE-2026-89111 — SAP Cloud SDK for Python OAuth2 SSRF

SAP Cloud SDK for Python 中存在 OAuth2 SSRF 漏洞，影响多租户 BTP 应用，攻击者可借由 SSRF 触达内部服务。CVSS 10.0 是本次 NVD 批次中最高分。该漏洞针对 SAP BTP 生态，与当前 Java 后端技术栈无直接暴露面；是否影响当前环境需确认是否使用 SAP Cloud SDK 或 BTP 服务。

- **CVSS**：10.0
- **影响组件**：SAP Cloud SDK for Python / SAP BTP 多租户应用
- **与当前栈关联**：未确认；当前栈不含 SAP 组件
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-96119 — IBM i 7.3-7.6 敏感信息获取/任意代码执行

IBM i 7.3/7.4/7.5/7.6 允许远程认证攻击者获取敏感信息或执行任意代码。CVSS 9.9。针对 IBM i 平台，当前基础设施未确认使用 IBM i，无直接关联。

- **CVSS**：9.9
- **影响组件**：IBM i 7.3 / 7.4 / 7.5 / 7.6
- **与当前栈关联**：未确认；当前栈不含 IBM i
- **来源等级**：official
- **来源名称**：NVD

- **CVSS**：9.8
