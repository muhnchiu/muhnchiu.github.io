### 1. CVE-2026-109395 — Ning compress-lzf 越界内存访问漏洞

Ning 框架 compress-lzf 组件 1.2.0 之前版本存在基于 sun.misc.Unsafe 的越界内存访问漏洞，可导致远程代码执行（RCE）。CVSS 9.1。若当前 Java 后端项目直接或间接依赖 Ning compress-lzf，需立即升级至 1.2.0 或更高版本；未确认当前项目是否使用该依赖，需排查依赖树。

- **CVSS**：9.1
- **影响组件**：Ning compress-lzf 1.2.0 之前版本（Java 生态）
- **与当前栈关联**：可能影响当前 Java 后端技术栈，需排查 pom/gradle 依赖树确认是否引入
- **来源等级**：official
- **来源名称**：NVD
