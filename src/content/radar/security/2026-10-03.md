## 今日高危漏洞

### 1. CVE-2026-104120 — MCP Server Fetch/Everything 安全漏洞

modelcontextprotocol 的 mcp-server-fetch 和 mcp-server-everything 在 2026 年版本之前存在安全漏洞，CVSS 7.3。该漏洞影响 MCP 协议生态中常用的两个服务端组件，可能导致未授权访问或信息泄露。MCP 是 AI 工具链中日益常用的协议，若当前开发环境中使用了相关 MCP 服务端，需及时升级。

- **CVSS**：7.3
- **影响组件**：modelcontextprotocol/mcp-server-fetch, mcp-server-everything
- **与当前栈关联**：若开发环境中使用了 MCP 相关工具链（如 AI 编码助手集成），则受影响；未确认当前是否在用
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-14378 — DevKit Pro WordPress 插件认证绕过 (CVSS 9.8)

DevKit Pro WordPress 插件存在认证绕过漏洞，可导致管理员账户被接管。CVSS 9.8，属于严重级别。该漏洞影响所有 DevKit Pro 插件版本。

- **CVSS**：9.8
- **影响组件**：DevKit Pro WordPress 插件
- **与当前栈关联**：当前技术栈为 Java/Spring Boot/Node.js，不使用 WordPress，无直接影响
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-19660 — Divi Membership WordPress 插件认证绕过 (CVSS 9.8)

Divi Membership 插件在 2.x 及以下版本存在认证绕过漏洞，CVSS 9.8。攻击者可绕过认证获取管理权限。

- **CVSS**：9.8
- **影响组件**：Divi Membership WordPress 插件
- **与当前栈关联**：不使用 WordPress，无直接影响
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-86345 — 389-ds-base 明文缓冲区漏洞 (CVSS 9.0)

389-ds-base（LDAP 目录服务器）在处理客户端连接时未正确丢弃已缓冲的明文字节，可能导致信息泄露或认证绕过。CVSS 9.0。

- **CVSS**：9.0
- **影响组件**：389-ds-base（Red Hat Directory Server）
- **与当前栈关联**：当前栈未使用 389-ds-base LDAP 服务，无直接影响；若基础设施中有 LDAP 依赖需关注
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-15896 — Super Forms WordPress 插件目录遍历 (CVSS 9.1)

Super Forms 表单构建器插件存在目录遍历漏洞，可能允许攻击者读取任意文件或上传恶意文件。

- **CVSS**：9.1
- **影响组件**：Super Forms – Drag & Drop Form Builder WordPress 插件
- **与当前栈关联**：不使用 WordPress，无直接影响
- **来源等级**：official
- **来源名称**：NVD

## 建议动作

**立即处理：**
1. 检查开发环境中是否使用了 modelcontextprotocol/mcp-server-fetch 或 mcp-server-everything，若在用则升级至最新版本
2. 确认基础设施中是否存在 FortiMail、Citrix NetScaler、Cisco SD-WAN 等设备，若存在需按 KEV 指引修补

**跟踪观察：**
- CISA KEV 新增的 Zammad 和 WordPress Core 漏洞，虽然不在当前栈中，但 WordPress Core RFI (CVE-2026-87902) 影响面广，持续关注后续披露
- 389-ds-base LDAP 漏洞 (CVE-2026-86345)，确认基础设施中是否有 LDAP 服务依赖

**无需动作：**
- 大量 WordPress 插件漏洞（DevKit Pro、Divi Membership、Super Forms、Ninja Forms 等）与当前 Java/Node.js 技术栈无直接关联
- Mooncake 传输引擎漏洞与当前基础设施无关联
- Android API key 相关漏洞不在服务器端栈范围
