## 今日高危漏洞

### 1. CVE-2026-123531 — Vikunja Uncontrolled Resource Consumption

Vikunja 1.0.0 至 2.7.1 版本存在未受控资源消耗漏洞，认证用户可触发资源耗尽，可能影响服务可用性。该漏洞为通用任务管理工具问题，未确认当前技术栈使用 Vikunja。

- **CVSS**：8.8
- **影响组件**：Vikunja 1.0.0 - 2.7.0
- **与当前栈关联**：未确认当前 Java/Spring Boot/MySQL/Nginx/Node.js 技术栈是否使用 Vikunja，若无则无需动作
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-123520 — Vikunja Privilege Escalation

Vikunja 0.18.0 至 2.7.1 版本存在权限提升漏洞，Team Owner 可获取 Admin 权限。与 CVE-2026-123531 同产品，影响范围一致。

- **CVSS**：7.1
- **影响组件**：Vikunja 0.18.0 - 2.7.0
- **与当前栈关联**：未确认当前技术栈是否使用 Vikunja
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-123522 — Vikunja Authorization Bypass

Vikunja 2.7.1 之前版本存在授权绕过漏洞，认证用户可读取任意任务。与上述两个 CVE 同产品，建议统一升级至 2.7.1+。

- **CVSS**：7.1
- **影响组件**：Vikunja < 2.7.1
- **与当前栈关联**：未确认当前技术栈是否使用 Vikunja
- **来源等级**：official
- **来源名称**：NVD
