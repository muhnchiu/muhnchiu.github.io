## 今日高危漏洞

### 1. CVE-2026-115731 — Perforce Puppet Enterprise 反序列化漏洞

CISA KEV 于 2026-11-17 新增此条目，涉及 Puppet Enterprise 反序列化不可信数据漏洞。该漏洞允许攻击者通过精心构造的数据实现远程代码执行，Puppet Enterprise 广泛用于自动化基础设施管理和配置管理。当前环境未部署 Puppet Enterprise，需确认是否在任何管理节点或 CI/CD 流水线中存在相关组件。

- **CVSS**：未确认
- **影响组件**：Perforce Puppet Enterprise
- **与当前栈关联**：未确认当前环境是否部署 Puppet Enterprise
- **来源等级**：official
- **来源名称**：CISA KEV

### 2. CVE-2026-125350 — Google Chromium Use-After-Free 漏洞

CISA KEV 于 2026-11-10 新增此条目，涉及 Chromium 浏览器的 Use-After-Free 漏洞。此类漏洞通常允许攻击者通过恶意网页实现任意代码执行，影响所有基于 Chromium 的浏览器（Chrome、Edge、Brave 等）。当前环境若使用 Chromium 内核浏览器访问外部内容，需确认已更新至包含修复的版本。

- **CVSS**：未确认
- **影响组件**：Google Chromium 及衍生浏览器
- **与当前栈关联**：未确认当前环境是否使用 Chromium 内核浏览器
- **来源等级**：official
- **来源名称**：CISA KEV

### 3. CVE-2026-130361 — AdminNeo ClickHouse 驱动参数注入漏洞

AdminNeo 5.9.1 之前版本存在 ClickHouse 驱动参数注入漏洞，CVSS 8.8，允许攻击者通过恶意参数执行未授权操作。AdminNeo 是 PHP 管理框架，若当前项目依赖此框架需升级至 5.9.1 或更高版本。

- **CVSS**：8.8
- **影响组件**：AdminNeo < 5.9.1
- **与当前栈关联**：未确认当前 Java/Spring Boot 项目是否依赖 AdminNeo
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-130371 — phpMyFAQ 认证绕过漏洞

phpMyFAQ 4.1.9 之前版本及 4.2.0-alpha 到 4.2.0-RC.2 版本存在认证绕过漏洞，CVSS 8.1，攻击者可绕过 Web 认证直接访问系统。若当前环境部署 phpMyFAQ 作为知识库系统需立即升级。

- **CVSS**：8.1
- **影响组件**：phpMyFAQ < 4.1.12 / 4.2.0-alpha ~ 4.2.0-RC.2
- **与当前栈关联**：未确认当前环境是否部署 phpMyFAQ
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-12487 — Zyxel EE5301 固件 SNMP 授权错误漏洞

Zyxel EE5301-00 定制固件 5.63(ACLD) 之前版本存在 SNMP 参数授权错误，CVSS 7.5，允许未授权用户通过 SNMP 协议读取或修改设备配置。若当前网络使用 Zyxel 网络设备需检查固件版本并升级。

- **CVSS**：7.5
- **影响组件**：Zyxel EE5301-00 定制固件 < 5.63(ACLD)
- **与当前栈关联**：未确认当前网络是否使用 Zyxel EE5301 设备
- **来源等级**：official
- **来源名称**：NVD
