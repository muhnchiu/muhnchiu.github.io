## 今日高危漏洞

### 1. CVE-2026-88772 — Citrix NetScaler 在野利用漏洞

CISA KEV 于 2026-09-27 新增条目，Citrix NetScaler 存在操作范围不当限制漏洞，已被确认在野利用。该漏洞影响 NetScaler 网关设备，攻击者可绕过限制执行未授权操作。当前 Java 后端技术栈不直接涉及 NetScaler 设备，但若网络边界部署了 Citrix 设备则需立即排查。

- **CVSS**：未确认（CISA KEV 未标注具体分数， severity 待定）
- **影响组件**：Citrix NetScaler（ADC/Gateway）
- **与当前栈关联**：不直接关联当前 Java/Spring Boot/MySQL/Nginx 技术栈；若网络边界使用 Citrix 设备则高优
- **来源等级**：official
- **来源名称**：CISA KEV

### 2. CVE-2026-88771 — Citrix NetScaler 输入验证漏洞

CISA KEV 于 2026-09-27 新增条目，Citrix NetScaler 存在输入验证漏洞，被确认在野利用。该漏洞可能允许攻击者通过特制输入绕过验证机制，获取未授权访问。与 CVE-2026-88772 同批披露，两者可能构成攻击链。

- **CVSS**：未确认
- **影响组件**：Citrix NetScaler（ADC/Gateway）
- **与当前栈关联**：不直接关联当前技术栈；网络边界设备排查优先
- **来源等级**：official
- **来源名称**：CISA KEV

### 3. CVE-2026-101292 — Apache ActiveMQ Artemis 不安全反射漏洞

Apache ActiveMQ Artemis 2.34.0 之前版本在 FederationStreamConnectMessage.getFederationStreamConnectMessage 中存在不安全反射漏洞。攻击者可构造恶意消息触发反射调用，可能导致远程代码执行。ActiveMQ Artemis 是 Java 消息中间件，与当前 Java 后端技术栈生态相关，但需确认是否实际使用 Artemis。

- **CVSS**：8.2
- **影响组件**：Apache ActiveMQ Artemis < 2.34.0
- **与当前栈关联**：Java 消息中间件生态，若使用 ActiveMQ Artemis 需升级至 2.34.0+
- **来源等级**：official
- **来源名称**：NVD

### 4. ManageEngine DDI Central 多个命令注入漏洞

ManageEngine DDI Central build 6201 以下版本存在多个漏洞：CVE-2026-12267（Windows DNS 查询策略命令注入，CVSS 7.2）、CVE-2026-12268（PowerShell 命令注入，CVSS 8.8）、CVE-2026-12269（Keepalived 配置注入，CVSS 8.8）、CVE-2026-12264（任意文件写入，CVSS 8.8）、CVE-2026-12265（HA 故障转移端点访问控制不足，CVSS 8.8）。这些漏洞影响 DDI（DNS/DHCP/IP 管理）基础设施，与当前技术栈无直接关联，但若组织使用 ManageEngine DDI 管理网络基础设施则需优先处理。

- **CVSS**：7.2 - 8.8
- **影响组件**：ManageEngine DDI Central < build 6201
- **与当前栈关联**：不直接关联当前 Java/Spring Boot/MySQL/Nginx 技术栈
- **来源等级**：official
- **来源名称**：NVD

## 建议动作

**立即处理：**
1. 若网络边界部署了 Citrix NetScaler 设备，立即排查 CVE-2026-88772 和 CVE-2026-88771，这两个漏洞已被确认在野利用。联系网络基础设施团队确认是否使用相关设备。

**跟踪观察：**
- Apache ActiveMQ Artemis CVE-2026-101292（CVSS 8.2）：确认当前 Java 后端是否使用 ActiveMQ Artemis 作为消息中间件，若使用则计划升级至 2.34.0+。
- ManageEngine DDI Central 多个命令注入漏洞：若组织使用 ManageEngine 管理网络基础设施，升级至 build 6201+。
- WSO2 CVE-2026-5430（CISA KEV）：WSO2 产品在 Java 生态中有一定使用率，确认是否使用相关产品。

**无需动作：**
- FAST FAC1200R/FAC1900R 等网络设备漏洞：与当前技术栈无关。
- refly-ai、dbgate、Thinkware U3000 等非核心依赖漏洞：无直接影响。
- NeuVector CVE-2026-78424：若未使用 NeuVector 容器安全平台，无需动作。
