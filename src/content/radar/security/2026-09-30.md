## 今日高危漏洞

### 1. CVE-2026-102422 — shell-quote quote() 注释注入

shell-quote 是 Node.js 生态中广泛使用的命令参数转义库。其 quote() 函数在处理 { comment } 类型 token 时，会将其输出为 # 加文本内容，导致后续命令被注释掉，可能引发命令注入或命令绕过问题。CVSS 8.1，影响 shell-quote 所有使用 quote() 处理含 { comment } token 输入的场景。

- **CVSS**：8.1
- **影响组件**：npm 包 shell-quote（quote() 函数）
- **与当前栈关联**：Node.js 生态常用包，当前前端技术栈及相关工具链可能使用该包进行命令行参数转义，需排查依赖树确认是否受影响
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-102361 — mall4j 未授权密码修改

mall4j 是基于 Spring Boot + Vue 的开源电商系统（截至 4.0 版本）。其 PUT /user/updatePwd 端点存在缺失认证漏洞，允许未认证用户直接修改其他用户密码，可导致账户接管。CVSS 9.1。

- **CVSS**：9.1
- **影响组件**：mall4j through 4.0（PUT /user/updatePwd 端点）
- **与当前栈关联**：mall4j 基于 Spring Boot 框架，与当前 Java 后端技术栈使用相同底层框架。虽未确认直接使用 mall4j，但类似认证缺失模式值得在自有代码中排查
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-5430 — WSO2 多产品路径遍历（CISA KEV）

WSO2 多款产品存在路径遍历漏洞，攻击者可通过构造恶意路径访问受限文件。该漏洞已被 CISA 列入已知被利用漏洞目录（KEV），确认存在在野利用。CISA KEV 新增日期为 2026-09-24。

- **CVSS**：未确认（NVD 今日抓取结果中未列出具体分数）
- **影响组件**：WSO2 多款产品（Java 中间件平台）
- **与当前栈关联**：WSO2 为 Java 生态中间件，当前 Java 后端技术栈若涉及 WSO2 组件需立即排查。未确认当前环境是否使用 WSO2 产品
- **来源等级**：official
- **来源名称**：CISA KEV

### 4. CVE-2026-102240 — Netcore NAP930 命令注入

Netcore NAP930（固件版本 0.1.241010.141410）的 /www/cgi-bin/ 路径下 eval 函数存在命令注入漏洞。CVSS 10.0，为今日 NVD 抓取结果中评分最高的漏洞。攻击者可通过精心构造的请求执行任意命令。

- **CVSS**：10.0
- **影响组件**：Netcore NAP930（网络设备，固件 0.1.241010.141410）
- **与当前栈关联**：网络设备固件漏洞，与当前软件技术栈无直接关联。若网络环境中存在 Netcore NAP930 设备需关注
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-87902 — WordPress Core 远程文件包含（CISA KEV）

WordPress Core 存在远程文件包含漏洞，攻击者可通过该漏洞加载远程恶意文件并执行代码。该漏洞已被 CISA 列入已知被利用漏洞目录。CISA KEV 新增日期为 2026-09-25。

- **CVSS**：未确认（NVD 今日抓取结果未列出具体分数）
- **影响组件**：WordPress Core
- **与当前栈关联**：WordPress CMS 与当前 Java/Node.js 技术栈无直接关联。若附属系统或周边环境中使用 WordPress 需关注
- **来源等级**：official
- **来源名称**：CISA KEV
