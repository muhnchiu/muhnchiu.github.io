## 今日高危漏洞

NVD 最近 24h 返回 9 条 CVSS >= 7.0 漏洞条目。按 CVSS 分数与当前技术栈（Java/Spring Boot/MySQL/Nginx/Node.js）的关联度排序。

### 1. CVE-2026-113736 — D-Link DHP-W610AV 认证绕过漏洞

D-Link DHP-W610AV 1.02EUb03 固件中 login_prepare_hnap 函数存在认证绕过漏洞，攻击者可绕过登录验证获取未授权访问。CVSS 9.8。

- **CVSS**：9.8
- **影响组件**：D-Link DHP-W610AV 1.02EUb03（家用/企业 Wi-Fi 路由器）
- **与当前栈关联**：与 Java/Spring Boot/MySQL/Nginx/Node.js 无直接关联；若当前基础设施使用了 D-Link DHP-W610AV 路由器且未更新固件，建议确认型号并排查
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-114045 — FreeRDP 服务端 rdpsnd 通道 heap 溢出

FreeRDP 3.32.1 之前版本在 server-side rdpsnd channel 处理中因 integer wraparound 导致 heap-based buffer overflow。CVSS 8.8。

- **CVSS**：8.8
- **影响组件**：FreeRDP < 3.32.1（RDP 客户端/服务端）
- **与当前栈关联**：与 Java/Spring Boot/MySQL/Nginx/Node.js 无直接关联；若当前环境使用 FreeRDP 进行远程桌面访问，建议升级至 3.32.1+
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-114050 — vLLM 多模态 uuid 缓存身份注入

vLLM 0.31.0 之前版本将客户端提供的 multimodal uuid 直接作为缓存身份，未做一致性校验，可被恶意客户端利用绕过缓存隔离。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：vLLM < 0.31.0（Python LLM 推理服务）
- **与当前栈关联**：不直接影响 Java/Spring Boot/MySQL/Nginx/Node.js；若当前推理层使用 vLLM 部署多模态模型（如 MOSS-Audio），建议升级至 0.31.0+
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-114051 — vLLM /inference/v1/generate 参数校验缺失

vLLM 0.31.0 之前版本在 /inference/v1/generate 请求中当 max_tokens 为 null 时跳过 min_tokens <= max_tokens 校验，可被利用触发异常处理。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：vLLM < 0.31.0
- **与当前栈关联**：同上；若使用 vLLM 部署推理服务，升级即可同时修复本条及 114050/114052/114053/114055
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-114052 — vLLM MOSS-Audio 内存耗尽漏洞

vLLM 0.24.0 至 0.31.0 之间版本在 MOSS-Audio 模型服务中缓存机制存在 memory exhaustion 问题，远程客户端可触发大量缓存占用。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：vLLM 0.24.0 - 0.31.0（MOSS-Audio 模型）
- **与当前栈关联**：若当前使用 vLLM 部署 MOSS-Audio，升级至 0.31.0+ 可修复
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-114053 — vLLM mm_processor_kwargs 路径注入

vLLM 0.7.3 至 0.31.0 之间版本将请求提供的 mm_processor_kwargs.code_revision 参数直接传递给 Transformers AutoProcess，存在路径注入风险。CVSS 8.1。

- **CVSS**：8.1
- **影响组件**：vLLM 0.7.3 - 0.31.0
- **与当前栈关联**：若使用 vLLM 处理多模态请求且未过滤 mm_processor_kwargs，升级至 0.31.0+ 可修复
- **来源等级**：official
- **来源名称**：NVD

### 7. CVE-2026-114055 — vLLM 远程资源耗尽

vLLM 0.7.3 至 0.31.0 之间版本存在 uncontrolled resource consumption，远程客户端可发送大量请求耗尽服务端资源。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：vLLM 0.7.3 - 0.31.0
- **与当前栈关联**：同 vLLM 系列，升级至 0.31.0+ 一并修复
- **来源等级**：official
- **来源名称**：NVD

### 8. CVE-2026-114059 — ArcadeDB 认证用户 RCE

ArcadeDB 26.10.1 之前版本存在远程代码执行漏洞，已认证用户（包括 read-only 角色）可执行任意代码。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：ArcadeDB < 26.10.1（NoSQL 多模型数据库）
- **与当前栈关联**：不直接影响 Java/Spring Boot/MySQL/Nginx/Node.js；若当前使用 ArcadeDB 作为数据层，建议升级至 26.10.1+
- **来源等级**：official
- **来源名称**：NVD
