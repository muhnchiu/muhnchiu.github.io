## 今日高危漏洞

### 1. CVE-2026-21589 — Atlassian Multiple Products Files or Directories Accessible

该漏洞已被 CISA 列入 2026-10-15 的 KEV 更新，影响 Atlassian 多产品，属于已确认在野利用且与协作工具部署直接相关的目录项。由于抓取摘要未给出完整 CVSS 与受影响版本边界，当前影响范围未确认；若内部使用 Jira、Confluence、Bitbucket 或 Trello 等 Atlassian 产品，应立即核对补丁状态。

- **CVSS**：未确认（抓取未提供完整数值）
- **影响组件**：Atlassian 多产品
- **与当前栈关联**：若部署 Atlassian 协作服务则高度相关；当前核心 Java/Spring Boot/MySQL/Nginx/Node.js 栈未直接确认受影响
- **来源等级**：official
- **来源名称**：CISA KEV

### 2. CVE-2026-110911 — Wheels 1.1.8 through 4.1.1 SQL Injection

Wheels 在动态字段解析时会把调用方提供的引号值再次作为 SQL 解析，导致 SQL 注入。CVSS 9.8 属于严重级别；由于当前后端技术栈未确认使用 Wheels 相关 Python 组件，直接关联未确认。若存在 Python 服务、CI 扩展或数据管道依赖该库，应测试升级或禁用相关解析路径。

- **CVSS**：9.8
- **影响组件**：Wheels 1.1.8 至 4.1.1
- **与当前栈关联**：未确认；当前核心 Java/Spring Boot/MySQL/Nginx/Node.js 栈未直接确认受影响
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-108587 — 10Web Booster WordPress Plugin Arbitrary File Upload

10Web Booster WordPress 插件存在任意文件上传漏洞，CVSS 9.8。当前前端技术栈未确认使用 WordPress 或该插件，因此直接关联未确认；若环境包含 WordPress 站点，应尽快升级或下线该插件。

- **CVSS**：9.8
- **影响组件**：10Web Booster – Website speed optimization, Cache & Page Speed optimizer
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-110908 — Netgate pfSense FRR Package OS Command Injection

pfSense 的 pfSense-pkg-frr 2.0.2_1 及源码 revision 2.1.2_1 存在 OS 命令注入漏洞，CVSS 8.8。当前网络基础设施未确认使用 pfSense 或 FRR 包；若作为测试环境或边缘路由栈使用，应跟踪补丁。

- **CVSS**：8.8
- **影响组件**：Netgate pfSense FRR package
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-77931 — MoviePilot Command Injection

MoviePilot 3.1.5 及之前版本存在命令注入漏洞，CVSS 8.8。当前未确认部署 MoviePilot；若作为本地媒体工具使用，应升级并限制非管理员用户访问。

- **CVSS**：8.8
- **影响组件**：MoviePilot through 3.1.5
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

## CISA KEV 新增（已知被利用漏洞）

2026-10-15 新增 Atlassian 多产品目录可访问项，是当前最值得确认的企业协作面风险。2026-10-14 新增 Cisco Secure Email Gateway 相对路径遍历、PAN-OS 代码注入，以及 Ivanti Connect Secure 认证绕过等条目，均与网络入口、邮件网关或远程访问设备相关；当前基础设施是否包含相关产品未确认。2026-10-08 还可见 Apache Struts 命令注入等历史高影响条目在 KEV 中的持续存在，若当前 Java 栈仍运行 Struts 旧版本应重点排查。

## 建议动作

**立即处理：**
1. 确认内部是否部署 Atlassian 产品（Jira、Confluence、Bitbucket、Trello），如有则立即核对 CVE-2026-21589 补丁状态与访问控制。
