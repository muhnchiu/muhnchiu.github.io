## 今日高危漏洞

### 1. CVE-2026-107908 — FalkorDB Bolt 协议堆越界写入漏洞

FalkorDB 4.20.0 之前的版本在 BoltReadHandler 函数（src/bolt/bolt_api.c）存在堆越界写入漏洞，攻击者可通过 Bolt 协议请求触发内存破坏。FalkorDB 今日在 NVD 集中披露了一批高危漏洞（含 CVE-2026-5759、7826、7827、107908、107909、107910、107911 共 7 条），均已在 4.20.0 修复。未确认是否在野利用。FalkorDB 为基于 Redis 模块的图数据库，与当前 Java 后端与 Node.js 前端技术栈无直接关联，当前环境是否使用未确认。

- **CVSS**：9.8
- **影响组件**：FalkorDB < 4.20.0（Bolt 协议处理模块）
- **与当前栈关联**：未确认（当前栈为 Java 后端与 Node.js 前端，未确认使用 FalkorDB）
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-5759 — FalkorDB RDB 图解码器 double free 与 use-after-free

FalkorDB RDB 图解码器 RdbLoadDeletedNodes 函数存在 double free 与 use-after-free 漏洞，攻击者可通过构造恶意 RDB 文件或协议请求触发，可能导致远程代码执行。同批披露的 7 个 FalkorDB CVE 之一，4.20.0 已修复。未确认是否在野利用。

- **CVSS**：9.8
- **影响组件**：FalkorDB < 4.20.0（RDB 图解码器）
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-7826 — FalkorDB BufferSerializerIOv2 堆越界读取

FalkorDB BufferSerializerIOv2_ReadBuffer 函数（src/serializers/serializer_io.c）存在堆越界读取漏洞，可能导致敏感内存信息泄露或崩溃。同批 FalkorDB 漏洞之一，4.20.0 已修复。

- **CVSS**：9.1
- **影响组件**：FalkorDB < 4.20.0（序列化模块）
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-107909 — FalkorDB WebSocket 帧处理堆越界写入

FalkorDB ws_read_frame 函数（src/bolt/ws.c）与 buffer_apply_mask 函数存在堆越界写入漏洞，攻击者可通过 WebSocket 通道触发。同批 FalkorDB 漏洞之一，4.20.0 已修复。

- **CVSS**：9.1
- **影响组件**：FalkorDB < 4.20.0（Bolt WebSocket 通道）
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-106155 — Progress Telerik Report Server 存储型 XSS

Progress Telerik Report Server 12.2.26.1007 之前的版本在共享调度功能中存在存储型 XSS 漏洞，攻击者可注入恶意脚本影响其他用户会话。同一版本还披露了服务代理权限分配不当漏洞 CVE-2026-106145（CVSS 7.1）。Telerik Report Server 为 .NET 组件，与当前技术栈无直接关联。

- **CVSS**：8.9
- **影响组件**：Progress Telerik Report Server < 12.2.26.1007
- **与当前栈关联**：无直接关联（.NET 组件，当前栈未使用）
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-93548 — WordPress FooSales 插件认证绕过

FooSales WordPress 插件 1.43.3 之前的版本未验证调用方是否有权以目标用户身份操作，认证用户可实施权限提升。属第三方 CMS 生态组件，与当前技术栈无直接关联。

### 7. CVE-2025-15700 — WordPress AWP Classifieds 插件任意文件解压

AWP Classifieds WordPress 插件 4.4.9 之前的版本未校验上传 ZIP 压缩包中解压文件的类型，可能导致任意文件上传与远程代码执行。属第三方 CMS 生态组件，与当前技术栈无直接关联。

- **来源名称**：NVD

### 8. CVE-2026-107914 — Backdrop CMS 配置导出保护不足

Backdrop CMS 1.34.5 之前与 1.35.1 之前的版本在通过 HTTP 交付配置导出时保护不足，可能导致敏感配置泄露。Backdrop CMS 为 PHP CMS，与当前技术栈无直接关联。

- **CVSS**：7.8
