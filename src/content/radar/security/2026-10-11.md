## 今日高危漏洞

以下为 NVD 最近 24 小时 CVSS >= 7.0 的公告摘选，披露时间以 NVD 官方数据为准。本日条目以第三方插件/组件漏洞为主，多数为 WordPress 插件生态，与当前 Java/Node.js 技术栈的直接关联有限。

### 1. CVE-2026-108474 — JetBrains Exposed SQL 注入

JetBrains Exposed（Kotlin ORM 框架）1.5.1 之前版本中，多个 SQL 函数的字符串参数未做转义处理，攻击者可借此注入 SQL。官方已在 1.5.1 修复。该组件属于 JVM 生态常用 ORM 库，是本日条目中与当前 Java 后端技术栈距离最近的一条。

- **CVSS**：9.8
- **影响组件**：JetBrains Exposed < 1.5.1
- **与当前栈关联**：当前 Java 后端以 Spring Boot 常见 ORM 为主，是否使用 Exposed 未确认，建议做一次依赖核查
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-103889 — WordPress 3D Product Configurator for WooCommerce 远程代码执行

该插件全部已知版本存在远程代码执行漏洞，攻击者可在未授权情况下执行任意代码，CVSS 9.8。属于典型的高危插件 RCE。

- **CVSS**：9.8
