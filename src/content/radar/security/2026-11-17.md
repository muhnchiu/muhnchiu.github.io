## 今日高危漏洞

### 1. CVE-2026-82156 — Dell PowerStore 授权绕过

Dell PowerStore 存在授权绕过漏洞，低权限攻击者可利用该漏洞获取更高权限，影响范围覆盖 Dell PowerStore 存储平台。未确认在野利用。

- **CVSS**：8.8
- **影响组件**：Dell PowerStore
- **与当前栈关联**：未确认当前基础设施使用 Dell PowerStore 存储设备
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-129540 — VoAPI 1.0.0-1.2.0 SQL 注入

VoAPI 1.0.0 至 1.2.0 存在 SQL 注入漏洞，认证用户可通过构造参数注入 SQL，可能导致数据泄露或未授权访问。未确认在野利用。

- **CVSS**：8.8
- **影响组件**：VoAPI 1.0.0 - 1.2.0
- **与当前栈关联**：未确认当前项目使用 VoAPI 组件
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-129493 — Bolo (bolo-solo) 1.7-2.6.4 信息泄露

Bolo 1.7 至 2.6.4 存在信息泄露漏洞，未认证攻击者可获取敏感信息。未确认在野利用。

- **CVSS**：7.5
- **影响组件**：Bolo (bolo-solo) 1.7 - 2.6.4
- **与当前栈关联**：未确认当前项目使用 Bolo 组件
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-129494 — CloudPaste 1.1.0-1.9.1 信息泄露

CloudPaste 1.1.0 至 1.9.1 存在信息泄露漏洞，未认证攻击者可获取敏感信息。未确认在野利用。

- **CVSS**：7.5
- **影响组件**：CloudPaste 1.1.0 - 1.9.1
- **与当前栈关联**：未确认当前项目使用 CloudPaste 组件
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-129606 — Samsung mTower 缓冲区溢出

Samsung 开源 mTower 存在缓冲区复制未检查输入尺寸的缺陷（经典缓冲区溢出），可导致内存破坏。未确认在野利用。

- **CVSS**：7.1
- **影响组件**：Samsung Open Source mTower
- **与当前栈关联**：未确认当前基础设施使用 Samsung mTower 组件
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-124672 — WordPress Burst Statistics 插件路由校验缺陷

Burst Statistics WordPress 插件 3.7.5 之前版本未校验请求是否路由到自身 REST 端点，可能导致未授权的 API 调用。未确认在野利用。

- **CVSS**：7.3
- **影响组件**：WordPress Burst Statistics 插件 < 3.7.5
- **与当前栈关联**：当前技术栈为 Java/Spring Boot/MySQL/Nginx/Node.js，不依赖 WordPress，未确认使用
- **来源等级**：official
- **来源名称**：NVD

### 7. CVE-2026-102448 — Rexroth IndraWorks 任意代码执行

Rexroth IndraWorks 存在任意代码执行漏洞，攻击者可能利用该缺陷在目标系统上执行任意代码。未确认在野利用。

- **CVSS**：7.8
- **影响组件**：Rexroth IndraWorks
- **与当前栈关联**：未确认当前基础设施使用 Rexroth IndraWorks 工业控制系统
