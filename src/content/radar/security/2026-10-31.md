## 今日高危漏洞

### 1. CVE-2026-107249 — Drupal Block AJAX 对象注入（CVSS 9.8）

Drupal Block AJAX 组件（0.0.0 至 3.0.2）存在对动态确定对象属性的不当控制漏洞（CWE-915），允许通过 AJAX 请求实现对象注入，未认证即可远程利用。NVD 于 2026-10-30 收录，Drupal 官方已发布安全公告（SA-CONTRIB-2026-192）并修复于 3.0.2。CISA SSVC 评估：无已知在野利用、可自动化利用、影响为总体（total）。

- **CVSS**：9.8（CVSS 3.1 / AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H，NVD 二手评分，状态 Awaiting Analysis）
- **影响组件**：Drupal Block AJAX <= 3.0.2（贡献模块）
- **与当前栈关联**：当前 Java/Spring Boot/MySQL/Nginx/Node.js 栈未使用 Drupal；若运维或同事维护 Drupal 站点则需立即升级至 3.0.2+。未确认本机/当前基础设施是否部署该模块。
- **来源等级**：official
- **来源名称**：NVD / Drupal Security Team（SA-CONTRIB-2026-192）

### 2. CVE-2026-119261 — Google Chrome Skia 输入验证缺陷（CVSS 9.6）

Chrome 156.0.8078.79 之前版本 Skia 组件输入验证不当，攻击者可构造恶意 HTML 页面在沙箱外执行任意代码（CWE-20）。NVD 于 2026-10-30 收录，Google 在 2026-10-21 桌面稳定版更新中修复。

- **CVSS**：9.6（CVSS 3.1 / AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:H/A:H，NVD 二手评分，Undergoing Analysis）
- **影响组件**：Google Chrome / Chromium < 156.0.8078.79
- **与当前栈关联**：若本机/测试环境使用旧版 Chrome 或 Chromium 内核浏览器（含自动化测试 Puppeteer 使用的 Chrome）需更新。前端开发日常使用。
- **来源等级**：official
- **来源名称**：NVD / Google Chromium 发布日志

## 建议动作

**立即处理：**
1. 排查是否部署 Drupal 站点且使用 Block AJAX 模块；若有，升级至 3.0.2+（CVE-2026-107249，CVSS 9.8，可自动化利用）。
2. 排查是否部署 Ivanti Connect Secure；若有，立即应用官方补丁（CVE-2026-118527 / CVE-2026-111357，CISA KEV 2026-10-30）。
3. 排查是否使用 Cisco ASA / Secure FTD；若有，立即修补（CVE-2026-76418，CISA KEV 2026-10-29）。

**跟踪观察：**
- 更新本机/测试环境 Chrome 或 Chromium 至 156.0.8078.79+（覆盖 14 条 8.8-9.6 漏洞）。
- 确认 VMware ESX 宿主机版本是否受 CVE-2026-41709 影响（CISA KEV 2026-10-28）。
- 确认测试环境 Rocky Linux 9.7 内核是否受 CVE-2026-46300 影响并计划升级（CISA KEV 2026-10-28）。
- 排查 GitLab CE/EE 部署（若使用）是否受 CVE-2026-97229 影响（CISA KEV 2026-10-29）。
- 排查 Nginx / Node.js Brotli 压缩是否受 CVE-2026-111497 影响（CISA KEV 2026-10-27）。
- 关注 Gecko Security 等 AI 漏洞扫描工具在开发流程中的适用性。

**无需动作：**
- maven / npm / pip 生态暂无与当前项目依赖相关的 GitHub Security Advisory。
- 当前 Java/Spring Boot 栈未使用 PHP，PHP 相关 KEV（CVE-2026-109618/109619）未确认影响本机，但若有 PHP 遗留服务需单独排查。
