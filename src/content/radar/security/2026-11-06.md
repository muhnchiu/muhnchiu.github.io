## 今日高危漏洞

### 1. Apache Juneau 一批 CVSS 10.0 漏洞（CVE-2026-121489 路径穿越 / CVE-2026-73098 动态类加载 等，共 9 条）

Apache Juneau（Java 数据绑定/REST 框架）于 2026-11-05 集中披露 9 个 CVSS 10.0 漏洞，涵盖路径穿越（DirectoryResource 未限制请求路径在根目录内，启用 view/upload/delete 时可读写删除根外文件）、动态代码加载控制不当（将解析值映射到 java.lang.Class 属性）、CSRF（REST 服务器 content 查询参数可替换请求体）、日志/错误信息泄露敏感数据、重定向时携带凭据头、HTTP 响应头 CRLF 注入等。修复版本未在 NVD 描述中确认。当前 Java 技术栈若引入 Juneau 依赖（直接或传递）需核对版本。

- **CVSS**：10.0
- **影响组件**：Apache Juneau（REST 服务器 / 微服务资源功能启用场景）
- **与当前栈关联**：Java 生态框架，需排查当前 Java 后端依赖树是否引入 Apache Juneau；未确认使用
- **来源等级**：official
- **来源名称**：NVD

### 2. Kyverno 批量漏洞：命名空间越权 + 镜像签名绕过（CVE-2026-122302~122323，最高 CVSS 9.9，1.19.2 修复）

Kubernetes 策略引擎 Kyverno 1.16.0 / 1.17.0 / 1.19.1 至 1.19.2 之前版本存在一批相关漏洞（NVD 同日披露约 20 条）：generate-rule 准入检查校验的是控制器权限而非策略作者权限，namespace admin 可越权创建资源（9.8）；cleanup 控制器构建方式允许 namespace admin 逃逸命名空间 confinement（9.9）；context.apiCall 路径校验与执行不一致（9.9）；verifyImages 签名校验结果按镜像引用字符串（如 tag）而非 digest 缓存，可绕过镜像签名（9.1）；另有策略绕过、DoS、跨命名空间读取等。修复版本 1.19.2。

- **CVSS**：9.9
- **影响组件**：Kyverno < 1.19.2（Kubernetes 集群准入策略引擎）
- **与当前栈关联**：若基础设施使用 K8s 集群并部署 Kyverno 作为策略引擎，需核对版本并升级；未确认部署
- **来源等级**：official
- **来源名称**：NVD

### 5. vault-java-driver 静默禁用 TLS 校验（CVE-2026-109408，CVSS 7.4）

HashiCorp Vault 的 Java 客户端 vault-java-driver 在三种调用状态下会静默禁用 TLS 证书与主机名校验：SslConfig 传入 VaultConfig 但未调用 build()、由 Java 反序列化恢复的 SslConfig、VAULT_SSL_VERIFY 设置为 "true" 以外的 truthy 值（如 "1"）。调用方以为开启了校验，实际处于不校验状态。若使用 Vault 的 Java 服务需排查该客户端版本。

- **CVSS**：7.4
- **影响组件**：vault-java-driver（HashiCorp Vault Java 客户端）
- **与当前栈关联**：Java 生态客户端，若基础设施经 Vault 存取凭据需核对版本；未确认使用
- **来源等级**：official
- **来源名称**：NVD

### 6. ModSecurity 3.0.17 前 multipart 文件名处理与常见应用解析不一致（CVE-2026-104269，CVSS 8.6）

ModSecurity 3.0.0 至 3.0.17 的 multipart 解析器未应用 RFC 2231 filename* 参数优先级，而 Go/Python/Node.js/Java 常见应用解析器会应用，攻击者可在 Content-Disposition 中构造善意 filename 与恶意 filename* 组合，使 WAF 与应用层看到不同文件名，绕过上传过滤。当前 Nginx 若配套 ModSecurity 需核对版本。

- **CVSS**：8.6
- **影响组件**：ModSecurity < 3.0.17（WAF 引擎）
- **与当前栈关联**：Nginx 生态组件；未确认是否部署 ModSecurity
- **来源等级**：official
- **来源名称**：NVD

### 7. MariaDB 分区表 ALTER TABLE ... CONVERT 路径构造编码缺陷（CVE-2026-102523，CVSS 8.0）

MariaDB Server 10.11.1~10.11.19、11.4.13、11.8.9、12.3.3、13.0.2 中，ALTER TABLE ... CONVERT ... PARTITION 未对用户指定的分区名做文件名编码即用于文件系统路径构造，经认证的数据库用户可构造需要编码的分区名触发路径异常。MySQL 生态相关组件，当前 MySQL 部署未确认受影响的 MariaDB 分支。

- **CVSS**：8.0
- **影响组件**：MariaDB Server 多分支版本
- **与当前栈关联**：数据库组件（MySQL 生态），需确认是否为 MariaDB 部署；未确认
- **来源等级**：official
- **来源名称**：NVD

### 8. ingress-nginx mirror-target 注解 DoS（CVE-2026-116472，CVSS 2.7）

ingress-nginx 对 mirror-target Ingress 注解缺少校验，有创建 Ingress 权限的用户可致 ingress-nginx 数据面 DoS 或重定向其他 Ingress 的流量。仅使用 ingress-nginx 的 K8s 集群受影响。

- **CVSS**：2.7
- **影响组件**：ingress-nginx（Kubernetes 集群）
- **与当前栈关联**：K8s 生态组件；未确认使用 K8s 部署 ingress-nginx
- **来源等级**：official
- **来源名称**：NVD

### 9. Angular HttpClient XSRF 拦截器 URL 归一化缺陷（CVE-2026-111753，CVSS 5.9）

@angular/common 20.3.34 / 21.0.3 之前版本中 xsrfInterceptorFn 使用的正则与浏览器 WHATWG URL 解析器的 URL 归一化方式不一致，XSRF 保护场景下可产生拦截差异。修复版本 20.3.34 / 21.0.3。

- **CVSS**：5.9
- **影响组件**：@angular/common < 20.3.34 / < 21.0.3
- **与当前栈关联**：Node.js/前端生态；当前前端技术栈未确认使用 Angular
- **来源等级**：official
- **来源名称**：NVD
