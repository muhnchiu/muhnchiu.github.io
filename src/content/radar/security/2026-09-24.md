## 今日高危漏洞

### 1. CVE-2026-91776 / CVE-2026-91777 / CVE-2026-89425 — FasterXML jackson-databind / jackson-core 拒绝服务漏洞

NVD 近 24h 收录三个 FasterXML jackson 相关漏洞。CVE-2026-91776 位于 TypeDeserializerBase._findDeserializer()，攻击者可通过恶意类型缓存触发拒绝服务；CVE-2026-91777 涉及 @JsonIdentityInfo 对象 ID 的前向引用完成逻辑，存在线性扫描导致的性能退化风险；CVE-2026-89425 位于 UTF8DataInputJsonParser._reportInvalidToken()，通过构造非法 token 可触发资源耗尽。

- **CVSS**：7.5（三个漏洞均为 7.5）
- **影响组件**：FasterXML jackson-databind、jackson-core（Java 生态核心 JSON 库）
- **与当前栈关联**：高度相关。当前 Java 后端技术栈使用 Spring Boot，底层依赖 Jackson 进行 JSON 序列化/反序列化。需确认当前 Jackson 版本是否受影响。
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-96257 — Fast FAC1203R 命令注入 (CVSS 10.0)

Fast FAC1203R Gigabit Edition 2.0.4 的 copy_msg_element 函数存在命令注入漏洞，CVSS 评分 10.0。攻击者可通过该函数执行任意 OS 命令。

- **CVSS**：10.0
- **影响组件**：Fast FAC1203R Gigabit Edition 2.0.4（网络设备固件）
- **与当前栈关联**：不相关。当前环境未使用该设备。
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-82843 — WP OAuth Server OpenID Connect 身份混淆

WordPress WP OAuth Server 插件 6.4.0 之前版本未绑定 OpenID Connect 身份断言，可导致身份混淆。

- **CVSS**：9.0
- **影响组件**：WordPress WP OAuth Server 插件 < 6.4.0
- **与当前栈关联**：不相关。当前环境未使用 WordPress。
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-75799 — YAHMAN Add-ons WordPress 插件远程文件包含

YAHMAN Add-ons WordPress 插件 0.9.31 之前版本未验证远程文件类型，可导致远程文件包含。

- **CVSS**：9.0
- **影响组件**：YAHMAN Add-ons WordPress 插件 < 0.9.31
- **与当前栈关联**：不相关。
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-96272 — ClipBucket SQL 注入

ClipBucket v5 before 5.5.3-#182 的照片搜索端点存在盲注漏洞。

- **CVSS**：7.5
- **影响组件**：ClipBucket v5 < 5.5.3-#182
- **与当前栈关联**：虽然当前后端使用 MySQL，但不使用 ClipBucket。SQL 注入模式值得注意但不直接影响。
- **来源等级**：official
- **来源名称**：NVD
