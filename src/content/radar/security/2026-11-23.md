## 今日高危漏洞

### 1. CVE-2026-134654 — Mailflare host header injection

Mailflare 在 48957fb 之前版本中，密码重置请求处理器存在 host header 注入漏洞，攻击者可利用该漏洞实施密码重置劫持，影响依赖该组件的用户账户安全。CVSS 8.1，属于高危。

- **CVSS**：8.1
- **影响组件**：Mailflare
- **与当前栈关联**：未确认，当前 Java 后端、前端、数据库与 Nginx 环境中未检索到部署
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-134541 — Surya2Developer Online Shopping System 未知函数漏洞

Surya2Developer Online Shopping System 1.0 的未知函数存在漏洞，具体攻击方式与影响范围未确认。CVSS 7.3。

- **CVSS**：7.3
- **影响组件**：Surya2Developer Online Shopping System 1.0
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-134679 — WeddingShare 匿名控制器授权缺失

WeddingShare 1.8.2 及之前版本的匿名 MediaViewerController.Gallery 端点存在授权缺失，未认证用户可访问媒体资源。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：WeddingShare <= 1.8.2
- **与当前栈关联**：未确认
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-134543 — jprocms StrUtil.format 缺陷

jprocms 1.7.7 及之前版本的数据库备份模块 StrUtil.format 函数存在缺陷，可能引发注入或格式化字符串问题。CVSS 7.1。

- **CVSS**：7.1
- **影响组件**：jprocms <= 1.7.7
- **与当前栈关联**：未确认，当前技术栈未检索到该组件
- **来源等级**：official
- **来源名称**：NVD
