## 今日高危漏洞

### 1. CVE-2026-105134 — Ahsay AhsayCBS 未授权代码执行

Ahsay AhsayCBS up to 10.3.2 存在严重漏洞，影响 /rps/api/json/ 路径下的未知代码，CVSS 评分为 10.0。该漏洞允许未授权访问，可能导致远程代码执行。AhsayCBS 为备份软件产品，非当前技术栈组件。

- **CVSS**：10.0
- **影响组件**：Ahsay AhsayCBS up to 10.3.2
- **与当前栈关联**：未关联（备份软件，非 Java/Node.js 技术栈）
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-105135 — InternLM MindSearch 远程代码执行

InternLM MindSearch 0.1.0 的 ExecutionAction.run 函数存在远程代码执行漏洞，CVSS 评分为 10.0。MindSearch 为 AI 搜索框架，非当前技术栈组件，但 AI 相关组件安全需持续关注。

- **CVSS**：10.0
- **影响组件**：InternLM MindSearch 0.1.0
- **与当前栈关联**：未关联（AI 搜索框架，非当前 Java/Node.js 技术栈）
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-103355 — Unlimited Elements SQL 注入

Unlimited Elements 插件存在 SQL 注入漏洞（CWE-89），CVSS 评分为 9.3。该漏洞允许通过特制输入操纵 SQL 查询。虽然该插件属于 WordPress 生态，但 SQL 注入模式对使用 MySQL 的后端技术栈具有参考意义。

- **CVSS**：9.3
- **影响组件**：Unlimited Elements（WordPress 插件）
- **与当前栈关联**：弱关联（WordPress 插件，非当前栈；但 SQL 注入模式值得注意）
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-105123 — vincent-peugnet/wcms 远程代码执行

vincent-peugnet/wcms through 3.18.0 存在远程代码执行漏洞，允许已认证的编辑者执行任意代码，CVSS 评分为 8.8。该 CMS 为 PHP 项目，非当前技术栈组件。

- **CVSS**：8.8
- **影响组件**：vincent-peugnet/wcms through 3.18.0
- **与当前栈关联**：未关联（PHP CMS，非当前 Java/Node.js 技术栈）
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-97307 — Cost Calculator Builder 敏感信息泄露

StylemixThemes Cost Calculator Builder 存在敏感信息写入漏洞，CVSS 评分为 7.5。该漏洞可能导致敏感数据被包含在发送的数据中。属于 WordPress 插件生态。

- **CVSS**：7.5
- **影响组件**：StylemixThemes Cost Calculator Builder
- **与当前栈关联**：未关联（WordPress 插件）
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-105147 — SciPhi-AI R2R JWT 密钥处理不当

SciPhi-AI R2R up to 3.6.6 的 JWT Secret Handler 组件存在漏洞，CVSS 评分为 7.3。虽然 R2R 为 Python AI 框架，但 JWT 密钥管理不当是一个通用安全模式，对使用 JWT 认证的后端技术栈有参考价值。

- **CVSS**：7.3
- **影响组件**：SciPhi-AI R2R up to 3.6.6
- **与当前栈关联**：弱关联（Python AI 框架，但 JWT 密钥管理模式对 Java/Node.js 后端有参考价值）
- **来源等级**：official
- **来源名称**：NVD
