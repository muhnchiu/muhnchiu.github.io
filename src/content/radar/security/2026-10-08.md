## 今日高危漏洞

### 1. CVE-2026-59346 — VMware Workstation/Fusion 整数溢出漏洞

VMware Workstation 和 Fusion 包含一个整数溢出漏洞。拥有本地管理权限的恶意攻击者可利用此漏洞在宿主机上执行代码或导致虚拟机逃逸。该漏洞 CVSS 评分 9.3，为今日 NVD 中评分最高的条目。

- **CVSS**：9.3
- **影响组件**：VMware Workstation、VMware Fusion
- **与当前栈关联**：当前技术栈以 Java 后端 + Nginx + Node.js 为核心，VMware 桌面虚拟化非核心组件。若开发或测试环境使用 VMware，需关注。
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-87782 — Koinonia Link WordPress 插件权限提升

Koinonia Link WordPress 插件 1.1.5 以前版本在保存用户角色时未检查当前用户是否有权更改角色，导致低权限用户可提升自身权限。CVSS 8.8。

- **CVSS**：8.8
- **影响组件**：Koinonia Link WordPress 插件 (< 1.1.5)
- **与当前栈关联**：当前后端技术栈不包含 WordPress，无直接影响。
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-82211 — Nexi XPay Build WordPress 插件支付验证绕过

Nexi XPay Build WordPress 插件 7.6.2 及以前版本未验证多个未经认证端点的支付结果，攻击者可伪造支付状态。CVSS 8.2。

- **CVSS**：8.2
- **影响组件**：Nexi XPay Build WordPress 插件 (<= 7.6.2)
- **与当前栈关联**：当前技术栈不包含 WordPress，无直接影响。
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-59347 — VMware Workstation/Fusion HGFS 栈缓冲区溢出

VMware Workstation 和 Fusion 在 HGFS（Host-Guest File System）组件中存在栈缓冲区溢出漏洞。拥有本地管理权限的攻击者可触发此漏洞。CVSS 8.1。

- **CVSS**：8.1
- **影响组件**：VMware Workstation、VMware Fusion（HGFS 组件）
- **与当前栈关联**：与 CVE-2026-59346 同属 VMware 桌面产品，非服务端核心组件。
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-106471 — Candlepin 授权过滤绕过

Candlepin（Red Hat 订阅管理系统）的中心授权过滤器在多个 @Verify 注解条件下错误地授予访问权限，导致授权绕过。CVSS 8.1。Candlepin 基于 Java，与当前 Java 后端技术栈有一定生态关联，但非直接依赖。

- **CVSS**：8.1
- **影响组件**：Candlepin（Red Hat 订阅管理）
- **与当前栈关联**：同为 Java 生态组件，但非当前技术栈直接依赖。可关注授权过滤模式作为架构参考。
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-82212 — Nexi XPay Build WordPress 插件令牌验证不当

Nexi XPay Build WordPress 插件 7.6.2 及以前版本未正确验证支付通知端点的安全令牌。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：Nexi XPay Build WordPress 插件 (<= 7.6.2)
- **与当前栈关联**：当前技术栈不包含 WordPress，无直接影响。
- **来源等级**：official
- **来源名称**：NVD

### 7. CVE-2026-102173 — Kirki WordPress 插件存储型 XSS

Kirki 页面构建器/自定义器 WordPress 插件存在存储型跨站脚本漏洞。CVSS 7.2。

- **CVSS**：7.2
- **影响组件**：Kirki WordPress 插件
- **与当前栈关联**：当前技术栈不包含 WordPress，无直接影响。
- **来源等级**：official
- **来源名称**：NVD

### 8. CVE-2026-104677 — WP Coder WordPress 插件 PHP 代码执行

WP Coder WordPress 插件 4.5.2 以前版本未将 PHP 代码执行功能限制为管理员可用，低权限用户可执行任意 PHP 代码。CVSS 7.2。

- **CVSS**：7.2
- **影响组件**：WP Coder WordPress 插件 (< 4.5.2)
- **与当前栈关联**：当前技术栈不包含 WordPress，无直接影响。
- **来源等级**：official
- **来源名称**：NVD
