## 今日高危漏洞

### 1. CVE-2026-132751 — yt (Python 分析库) 代码注入漏洞

yt 4.4.4 及之前版本在 `SavedDataset._parse_parameter_file()` 中不受限制地将 `con_args` 传给 `eval()`，攻击者可通过构造恶意 .h5 HDF5 数据文件，使用 `yt.load()` 加载时以当前用户权限执行任意 Python 代码。属于典型的数据文件解析反序列化风险。当前技术栈无 yt 依赖，与 Java/Spring Boot/Node.js 后端无直接关联；若本地 Python 数据科学工作流使用 yt 加载外部 .h5 文件则需升级。

- **CVSS**：7.8
- **影响组件**：yt <= 4.4.4（Python）
- **与当前栈关联**：无直接关联（未确认 Python 数据流使用 yt）
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-132756 — Geany 编辑器 OS 命令注入漏洞

Geany 2.1.0 及之前版本在 Compile/Build/Execute 操作时，将文件名中的元字符（反引号、`$(...)`）直接拼入 shell 命令，攻击者构造含 shell 元字符的文件名后诱导用户执行编译或运行，即可实现以用户权限的任意命令执行。属桌面 IDE 场景，与当前 Web/后端技术栈无关联。

- **CVSS**：7.8
- **影响组件**：Geany <= 2.1.0（桌面编辑器）
- **与当前栈关联**：无直接关联
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-132748 — Vtiger CRM PHP 代码注入漏洞

Vtiger CRM 8.4.0 及之前版本中，已认证管理员可通过 `updatedFields` 参数构造 `HELPDESK_SUPPORT_EMAIL_ID` 值，绕过邮箱格式校验后闭合 PHP 字符串字面量，向 `config.inc.php` 注入任意代码实现操作系统命令执行。影响自托管 CRM 部署场景，当前技术栈未使用 Vtiger，关联度低。

- **CVSS**：7.2
- **影响组件**：Vtiger CRM <= 8.4.0（PHP）
- **与当前栈关联**：无直接关联
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-132773 — Attendize 活动票务授权绕过漏洞

Attendize 2.8.0 及之前版本中，`EventOrdersController::postCancelOrder()` 的取消订单逻辑未校验活动归属，已认证的 organiser 可携带他人活动的 attendee ID 取消订单，使该安装下任意活动的门票失效。属多租户授权隔离缺陷，当前技术栈未使用 Attendize，关联度低。

- **CVSS**：7.1
- **影响组件**：Attendize <= 2.8.0（Laravel 活动票务系统）
- **与当前栈关联**：无直接关联
- **来源等级**：official
- **来源名称**：NVD
