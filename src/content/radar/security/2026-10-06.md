## 今日高危漏洞

### 1. CVE-2026-88779 — Citrix NetScaler 操作限制不当

Citrix NetScaler 存在操作限制不当漏洞，已被 CISA 列入已知被利用漏洞目录（KEV），添加日期为 2026-10-04。攻击者可利用此漏洞绕过限制，可能导致远程代码执行或信息泄露。Citrix NetScaler 为企业级负载均衡和应用交付网关，广泛部署于网络边界。

- **CVSS**：未确认（CISA KEV 未标注具体分数）
- **影响组件**：Citrix NetScaler（网络负载均衡/应用交付网关）
- **与当前栈关联**：未确认。当前技术栈未使用 Citrix NetScaler，但同一网络环境中若存在该设备则需关注。
- **来源等级**：official
- **来源名称**：CISA KEV

### 2. CVE-2026-104286 — Fortinet FortiMail 路径遍历

Fortinet FortiMail 存在路径遍历漏洞，已被 CISA 列入已知被利用漏洞目录，添加日期为 2026-10-01。攻击者可通过构造恶意路径访问任意文件，可能导致敏感信息泄露。FortiMail 为企业邮件安全网关产品。

- **CVSS**：未确认（CISA KEV 未标注具体分数）
- **影响组件**：Fortinet FortiMail（邮件安全网关）
- **与当前栈关联**：未确认。当前技术栈未使用 FortiMail，但若网络环境中存在该设备则需关注。
- **来源等级**：official
- **来源名称**：CISA KEV

### 3. CVE-2026-105223 — kubernetes-client TLS 证书验证禁用

maclof kubernetes-client 0.17.0 至 0.32.0 之前版本在 parseKubeconfig() 和 parseKubeconfigFile() 函数中禁用了 TLS 证书验证。这可能导致中间人攻击，攻击者可在与 Kubernetes API Server 通信时拦截或篡改数据。该漏洞影响 PHP 生态的 Kubernetes 客户端库。

- **CVSS**：7.4
- **影响组件**：maclof kubernetes-client（PHP Kubernetes 客户端，0.17.0 - <0.32.0）
- **与当前栈关联**：未确认。当前后端技术栈为 Java，不直接使用 PHP kubernetes-client。若运维侧使用该库管理 K8s 集群则需关注。
- **来源等级**：ecosystem
- **来源名称**：NVD

### 4. CVE-2026-105293 — Legcord 路径遍历

Legcord 1.1.0 至 1.3.0 版本在 theme IPC 处理器中存在路径遍历漏洞，允许 Discord 页面中的脚本访问任意文件。攻击者可通过恶意 Discord 内容触发此漏洞，可能导致敏感文件读取。

- **CVSS**：8.1
- **影响组件**：Legcord 1.1.0 - 1.3.0（Discord 第三方客户端）
- **与当前栈关联**：不相关。Legcord 为桌面端 Discord 客户端修改版，不在当前技术栈范围内。
- **来源等级**：ecosystem
- **来源名称**：NVD

### 5. CVE-2026-20521 — Android Video HAL 权限提升

Android Video HAL 组件因缺少边界检查存在权限提升漏洞，可导致本地权限提升。此漏洞为 Android 系统组件漏洞，影响 MediaTek 芯片组的 Android 设备。NVD 同期还披露了多个类似的高分漏洞（CVE-2026-20522/20523/20524/20531，CVSS 均为 8.4），涉及 neuropilot、apu 等组件。

- **CVSS**：8.4
- **影响组件**：Android Video HAL / neuropilot / apu（MediaTek 芯片组组件）
- **与当前栈关联**：不相关。为 Android 移动端系统漏洞，与当前后端服务栈无关。
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-105295 — GitAhead 更新机制不安全

GitAhead 2.5.0 至 2.7.1 版本的更新机制存在安全隐患，在安装下载的更新时未进行完整性或签名验证。攻击者若劫持更新通道可植入恶意代码。

- **CVSS**：7.5
- **影响组件**：GitAhead 2.5.0 - 2.7.1（Git 图形客户端）
- **与当前栈关联**：未确认。GitAhead 为桌面端 Git 客户端，若开发环境中使用该工具则需关注。
- **来源等级**：ecosystem
- **来源名称**：NVD
