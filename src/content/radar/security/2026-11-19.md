## 今日高危漏洞

### 1. CVE-2026-40217 — BerriAI LiteLLM 未授权替代通道漏洞

CISA KEV 于 2026-11-18 新增此条目。LiteLLM 是常用的 LLM 网关/代理组件，该漏洞涉及未受保护的替代通信通道，攻击者可能借此绕过正常鉴权路径。当前环境若在任何 LLM 服务网关或 Agent 服务中使用了 LiteLLM，需确认版本并评估加固方案（关闭替代通道或补充鉴权）。未确认该漏洞在野利用的具体利用方式。

- **CVSS**：未确认
- **影响组件**：BerriAI LiteLLM
- **与当前栈关联**：未确认当前 LLM 服务栈是否使用 LiteLLM，若使用则需立即排查
- **来源等级**：official
- **来源名称**：CISA KEV

### 2. CVE-2024-10441 — Synology DiskStation Manager (DSM) 编码或转义不当

CISA KEV 于 2026-11-18 新增此条目（漏洞编号为 2024 年披露，KEV 收录时间以 CISA 官方日期 2026-11-18 为准）。该漏洞涉及编码或转义不当，攻击者可借此实施越权操作。若当前网络中存在 Synology NAS 设备（存储服务器常见），需确认 DSM 版本并打补丁。

- **CVSS**：未确认
- **影响组件**：Synology DiskStation Manager (DSM)
- **与当前栈关联**：未确认当前网络是否部署 Synology 存储设备
- **来源等级**：official
- **来源名称**：CISA KEV

### 3. CVE-2026-129892 — Perl IO::Socket::SSL::PublicSuffix 代码注入漏洞

IO::Socket::SSL::PublicSuffix 2.099 及之前版本的 Perl 模块存在代码注入漏洞（CVSS 9.8），攻击者可通过构造的获取列表行实现代码注入，另有相关 CVE-2026-129891（CVSS 7.5）涉及 on-path 攻击者选择已安装公共后缀。影响范围为使用 Perl 的 SSL 相关基础设施，若当前环境有 Perl 脚本或 CGI 依赖此模块需升级至修复版本。

- **CVSS**：9.8
- **影响组件**：Perl IO::Socket::SSL::PublicSuffix <= 2.099
- **与当前栈关联**：与当前 Java/Spring Boot 技术栈无直接关联，若存在 Perl 辅助服务需检查
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-126962 — open62541 Subscription Use-After-Free 远程代码执行

open62541 是 OPC-UA 协议实现库，订阅（Subscription）处理逻辑存在 Use-After-Free 漏洞（CVSS 8.8），远程攻击者可借此实现代码执行。该库主要用于工业协议通信场景，若当前项目通过 open62541 接入工业设备或 IoT 网关需升级。与当前 Web 后端栈无直接关联。

- **CVSS**：8.8
- **影响组件**：open62541（OPC-UA 实现库）
- **与当前栈关联**：与当前 Java/Spring Boot/Node.js 技术栈无直接关联
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-126969 — SmarterMail 熵不足认证绕过

SmarterTools SmarterMail 存在熵不足导致的认证绕过漏洞（CVSS 9.1），同系列还有文件编辑 API 目录遍历 RCE（CVE-2026-126967，CVSS 8.8）、缺失授权权限提升（CVE-2026-126966，CVSS 8.8）。若当前环境使用 SmarterMail 作为邮件服务需立即升级。与当前自研技术栈无直接关联。

- **CVSS**：9.1
- **影响组件**：SmarterTools SmarterMail
- **与当前栈关联**：与当前技术栈无直接关联，除非部署了 SmarterMail 邮件系统
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-126978 / CVE-2026-126979 / CVE-2026-126977 — Philips Hue Bridge 系列 RCE

Philips Hue Bridge 存在三处高危漏洞：hap_pair_setup_handler 堆溢出 RCE（CVSS 8.8）、HomeKit chacha20_decrypt 整数下溢 RCE（CVSS 8.8）、HomeKit 配对默认密码认证绕过（CVSS 8.1）。若家庭或办公室使用 Hue Bridge 智能照明设备且接入局域网，建议检查固件并隔离于独立网段。

- **CVSS**：8.8 / 8.8 / 8.1
- **影响组件**：Philips Hue Bridge
- **与当前栈关联**：与当前后端技术栈无直接关联，属物联网设备安全
- **来源等级**：official
- **来源名称**：NVD

### 7. CVE-2026-126974 / CVE-2026-126975 / CVE-2026-126976 — llama.cpp GGUF 解析漏洞

llama.cpp 在解析 GGUF 模型文件时存在整数溢出（CVSS 7.8）和堆溢出 RCE（CVSS 7.8），多模态 MTMD 分支也有整数溢出（CVSS 7.0）。若当前环境使用 llama.cpp 加载外部提供的模型文件（如本地推理服务接受用户上传模型），攻击者可构造恶意 GGUF 文件实现代码执行。本地固定模型场景下风险较低。

- **CVSS**：7.8
- **影响组件**：llama.cpp（GGUF 解析）
- **与当前栈关联**：若运行本地 LLM 推理且接受外部模型文件则需关注，否则风险未确认
- **来源等级**：official
- **来源名称**：NVD

KiCad 项目存在 Altium SCHLIB 文件解析越界写 RCE（CVSS 7.8）、工程归档目录遍历 RCE（CVSS 7.8）、插件目录遍历 RCE（CVSS 7.8）。主要影响硬件设计场景，与当前 Web/后端技术栈无关联。
