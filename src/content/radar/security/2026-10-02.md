## 今日高危漏洞

### 1. CVE-2026-104286 — Fortinet FortiMail Path Traversal Vulnerability

Fortinet FortiMail 存在路径穿越漏洞，已被 CISA 确认在野利用并列入 KEV 目录。攻击者可通过构造恶意路径访问受限文件，可能导致敏感信息泄露或进一步渗透。该漏洞于 10 月 1 日被 CISA 加入 KEV 目录。

- **CVSS**：未确认（NVD 数据源抓取失败，未获取到 CVSS 分数）
- **影响组件**：Fortinet FortiMail 邮件安全网关
- **与当前栈关联**：不直接相关。当前技术栈未使用 FortiMail 产品。
- **来源等级**：official
- **来源名称**：CISA KEV

### 2. CVE-2026-87902 — WordPress Core Remote File Inclusion Vulnerability

WordPress Core 存在远程文件包含漏洞，已被 CISA 确认在野利用。RFI 漏洞允许攻击者从远程服务器加载恶意代码执行，可能导致完全的服务器接管。WordPress 作为广泛部署的 CMS 平台，该漏洞影响面较大。CISA 于 9 月 25 日将其加入 KEV 目录。

- **CVSS**：未确认（NVD 数据源抓取失败）
- **影响组件**：WordPress Core
- **与当前栈关联**：不直接相关。当前后端技术栈基于 Java/Spring Boot，未使用 WordPress。如存在周边 WordPress 站点需关注。
- **来源等级**：official
- **来源名称**：CISA KEV

### 3. CVE-2026-88772 — Citrix NetScaler Improper Restriction of Operations

Citrix NetScaler（现 Citrix ADC）存在操作限制不当漏洞，已被 CISA 确认在野利用。NetScaler 作为常见的应用交付控制器和负载均衡设备，该漏洞可能影响网络边界安全。CISA 于 9 月 27 日加入 KEV。

- **CVSS**：未确认（NVD 数据源抓取失败）
- **影响组件**：Citrix NetScaler / Citrix ADC
- **与当前栈关联**：未确认。需核实当前基础设施是否使用 Citrix NetScaler/ADC 设备。
- **来源等级**：official
- **来源名称**：CISA KEV

### 4. CVE-2026-5430 — WSO2 Multiple Products Path Traversal Vulnerability

WSO2 多款产品存在路径穿越漏洞，已被 CISA 确认在野利用。WSO2 产品线（包括 API Manager、Identity Server 等）基于 Java 技术栈构建，路径穿越漏洞可能允许攻击者读取敏感配置文件或绕过访问控制。CISA 于 9 月 24 日加入 KEV。

- **CVSS**：未确认（NVD 数据源抓取失败）
- **影响组件**：WSO2 API Manager / Identity Server / 其他 WSO2 产品
- **与当前栈关联**：潜在关联。WSO2 基于 Java 技术栈，虽然当前后端使用 Spring Boot 而非 WSO2 中间件，但需确认基础设施中是否部署了 WSO2 产品（如 API 网关、身份认证服务等）。
- **来源等级**：official
- **来源名称**：CISA KEV

### 5. CVE-2026-65660 — Microsoft SharePoint Code Injection Vulnerability

Microsoft SharePoint 存在代码注入漏洞，已被 CISA 确认在野利用。攻击者可能通过注入恶意代码获取服务器执行权限。SharePoint 作为企业协作平台部署广泛。CISA 于 9 月 25 日加入 KEV。

- **CVSS**：未确认（NVD 数据源抓取失败）
- **影响组件**：Microsoft SharePoint
- **与当前栈关联**：不直接相关。当前技术栈未使用 SharePoint。
- **来源等级**：official
- **来源名称**：CISA KEV
