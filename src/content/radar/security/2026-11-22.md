## 今日高危漏洞

### 1. CVE-2026-120539 — WordPress "Restrictions for BuddyPress" 插件远程代码执行

WordPress 插件 "Restrictions for BuddyPress" 在所有未修复版本中存在远程代码执行（RCE）漏洞，攻击者可未授权访问并执行任意代码，可能导致网站被完全接管。CVSS 9.8 属于最高分区间，但今日抓取数据中未确认存在在野利用，也未确认与当前基础设施关联。

- **CVSS**：9.8
- **影响组件**：WordPress 插件 Restrictions for BuddyPress（所有已发布版本）
- **与当前栈关联**：未确认。当前基础设施（Java 后端 / Node.js 前端 / MySQL / Nginx）未确认部署该插件，若内部或第三方站点使用 WordPress 则需排查
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-19793 — WordPress "WP Import Export Lite" 插件受限代码注入

WordPress 插件 "WP Import Export Lite" 在所有未修复版本中存在受限代码注入漏洞，攻击者可借导入导出功能执行恶意代码。CVSS 8.8，今日未确认在野利用，当前基础设施未确认部署该插件。

- **CVSS**：8.8
- **影响组件**：WordPress 插件 WP Import Export Lite（所有已发布版本）
- **与当前栈关联**：未确认。与当前 Java / Node.js / MySQL / Nginx 技术栈无已知关联，若有 WordPress 站点需排查
- **来源等级**：official
- **来源名称**：NVD
