## 今日高危漏洞

### 1. CVE-2026-134401 — Google Chrome Variations 模块输入校验不当

Google Chrome 158.0.8127.88 之前的版本中，Variations 模块存在输入校验不当漏洞，远程攻击者可能借此执行任意代码。CVSS 9.6 为当日最高分，属于浏览器核心组件高危 RCE。当前环境使用 Node.js 技术栈，不直接依赖 Chrome 内核，但若部署环境存在基于 Chromium 的无头浏览器（如 Puppeteer、Playwright），需评估升级。

- **CVSS**：9.6
- **影响组件**：Google Chrome < 158.0.8127.88
- **与当前栈关联**：未确认。若使用 Chromium 系无头浏览器需评估
- **来源等级**：official
- **来源名称**：NVD

### 2. Tanium 2026-11 批量漏洞（约 15 个 CVE）

Tanium 当日集中披露约 15 个漏洞，涉及 Comply、Tanium Server、Threat Response、Core Content、Engage 等模块，类型包括命令注入、代码执行、访问控制不当、路径遍历等，CVSS 多为 7.1-8.8。Tanium 为企业级终端管理/威胁响应平台，非当前 Java/Spring/MySQL/Nginx/Node.js 技术栈组件，若企业内未部署 Tanium 可忽略。

- **CVSS**：7.1 - 8.8（批量）
- **影响组件**：Tanium Comply / Server / Threat Response / Core Content / Engage
- **与当前栈关联**：无关，当前技术栈未使用 Tanium
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-132165 — Drupal Core 远程代码执行（CISA KEV）

Drupal Core 存在远程代码执行漏洞，已于 2026-11-24 被 CISA 收录进 KEV 目录，确认存在在野利用。若当前基础设施使用 Drupal 站点需立即升级。当前 Java 后端技术栈与 Drupal 无关，但若存在 PHP 站点需排查。

- **CVSS**：未确认
- **影响组件**：Drupal Core
- **与当前栈关联**：未确认。当前核心栈不含 Drupal
- **来源等级**：official
- **来源名称**：CISA KEV

### 4. CVE-2026-135686 — Trilium SQL 注入

Trilium 0.107.0 之前的版本中，updateNormalEntity() 存在 SQL 注入漏洞，恶意同步伙伴可借此注入。CVSS 7.4。Trilium 为个人笔记管理工具，非当前技术栈组件。

- **CVSS**：7.4
- **影响组件**：Trilium <= 0.107.0
- **与当前栈关联**：无关
- **来源等级**：official
- **来源名称**：NVD
