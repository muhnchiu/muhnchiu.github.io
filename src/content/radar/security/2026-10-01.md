## 今日高危漏洞

### 1. CVE-2026-103088 — Handlebars.java 目录遍历

Handlebars.java 4.5.5 之前版本存在目录遍历漏洞。在 handlebars-springmvc 4.5.3 和 4.5.4 中，路径包含检查可被绕过，攻击者可能通过构造恶意模板路径访问预期目录之外的文件。该漏洞直接影响使用 Handlebars.java 作为模板引擎的 Spring MVC 应用。

- **CVSS**：7.5
- **影响组件**：Handlebars.java（handlebars-springmvc 4.5.3、4.5.4）
- **与当前栈关联**：直接关联 — 当前 Java 后端技术栈若使用 Handlebars.java 模板引擎则受影响，需确认项目依赖
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-103056 — AiSOC 命令注入

AiSOC 7.2.0 至 12.0.0 之前版本的 actions 服务中存在命令注入漏洞。该服务在构建 CrowdStrike 相关操作时未正确过滤输入，已认证的攻击者可注入任意命令。CVSS 9.0，属于严重级别。

- **CVSS**：9.0
- **影响组件**：AiSOC（7.2.0 <= version < 12.0.0）
- **与当前栈关联**：未关联 — AiSOC 为安全编排平台，不在当前技术栈中
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-103055 — AiSOC JWT 硬编码常量

AiSOC 7.5.0 至 12.0.0 之前版本在实时 WebSocket 和 SSE 服务中使用硬编码常量进行 JWT 验证，攻击者可伪造 JWT 令牌绕过认证。

- **CVSS**：7.5
- **影响组件**：AiSOC（7.5.0 <= version < 12.0.0）
- **与当前栈关联**：未关联 — 不在当前技术栈中
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-102793 — Ziroom ZHOME 时区设置漏洞

Ziroom ZHOME A0101 1.0.1.0 的 set_time_zone 函数存在漏洞，具体细节待确认。CVSS 9.1，属于严重级别。

- **CVSS**：9.1
- **影响组件**：Ziroom ZHOME A0101 1.0.1.0
- **与当前栈关联**：未关联 — IoT 智能家居设备，不在当前技术栈中
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-102874 — HKUDS AnyTool 命令注入

HKUDS AnyTool 0.1.0 的 subprocess.run 函数存在命令注入漏洞，攻击者可通过构造恶意输入执行任意命令。

- **CVSS**：7.3
- **影响组件**：HKUDS AnyTool 0.1.0
- **与当前栈关联**：未关联 — Python 工具，不在当前技术栈中
- **来源等级**：official
- **来源名称**：NVD
