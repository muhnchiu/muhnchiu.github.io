## 今日高危漏洞

### 1. CVE-2026-105080 — ConvertX 任意文件执行

ConvertX 0.19.0 之前版本中，converters/calibre.ts 未阻止 recipe 文件，而是将其传递给 ebook-converter，导致攻击者可通过上传恶意 recipe 文件实现任意文件执行。该漏洞 CVSS 达 9.9，属于极高危级别，但 ConvertX 是自托管文档转换工具，当前技术栈中未使用该组件。

- **CVSS**：9.9
- **影响组件**：ConvertX < 0.19.0
- **与当前栈关联**：无关联，当前 Java 后端技术栈和前端技术栈均未使用 ConvertX
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-97644 — Groundhogg WordPress 插件权限提升

Groundhogg CRM 插件存在权限提升漏洞，未授权用户可获取更高权限。CVSS 8.8，影响 WordPress 站点。当前基础设施中未部署 WordPress，无直接关联。

- **CVSS**：8.8
- **影响组件**：Groundhogg WordPress 插件
- **与当前栈关联**：无关联
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-92536 — ProfileBuilder WordPress 插件权限提升

Paid Membership ProfileBuilder 插件存在权限提升漏洞，CVSS 8.8。同样为 WordPress 生态插件，与当前技术栈无关联。

- **CVSS**：8.8
- **影响组件**：ProfileBuilder WordPress 插件
- **与当前栈关联**：无关联
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-101923 — Photo Reviews for WooCommerce 任意内容删除

Photo Reviews for WooCommerce 插件存在任意内容删除漏洞，攻击者可删除站点内容。CVSS 8.1，影响 WordPress WooCommerce 站点，与当前技术栈无关联。

- **CVSS**：8.1
- **影响组件**：Photo Reviews for WooCommerce WordPress 插件
- **与当前栈关联**：无关联
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-104433 — Mooncake 传输引擎越界读取

Mooncake 传输引擎 0.3.12 之前版本的 readString 函数存在越界读取漏洞，CVSS 7.5。Mooncake 是数据传输框架，当前技术栈中未使用该组件。

- **CVSS**：7.5
- **影响组件**：Mooncake transfer engine < 0.3.12
- **与当前栈关联**：无关联
- **来源等级**：official
- **来源名称**：NVD
