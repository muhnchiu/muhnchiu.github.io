## 今日高危漏洞

以下为 NVD 近 24 小时收录窗口内的 CVSS >= 7.0 条目，披露与发布日期以 NVD 官方记录为准，不等于今日披露。

### 1. CVE-2026-108540 — OpenSpug Spug /exec/transfer 高危漏洞

开源运维平台 Spug 在 3.4.0/4.0.1 及之前版本中，/exec/transfer 接口所在功能存在高危缺陷，公开细节尚不完整，具体触发条件与利用链有待进一步确认。该类自托管运维平台一旦失陷，通常直接意味着服务器级权限丢失。

- **CVSS**：9.9
- **影响组件**：OpenSpug Spug 3.4.0/4.0.1 及之前版本
- **与当前栈关联**：当前环境使用类 Unix 服务器与 Nginx/Java 后端；是否部署 Spug 未确认
- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-108707 — Wukong_HRM 认证绕过漏洞

开源人力资源系统 Wukong_HRM 在 commit 186115e 及之前版本中，ParamAspect 组件存在认证绕过，攻击者可以未认证身份访问受限接口。HRM 系统通常集中存储员工个人信息，主要风险为未授权数据访问与泄露。

- **CVSS**：9.8
- **影响组件**：Wukong_HRM（commit 186115e 及之前）
- **与当前栈关联**：属 Java 生态开源系统，与当前 Java 后端技术栈同类；当前环境是否部署未确认
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-104028 — Anton Extensions WordPress 插件缺少权限校验

WordPress 插件 Anton Extensions 1.2.2 及之前版本未做能力校验、nonce 验证与文件类型检查，攻击者可能借助任意文件上传实现远程代码执行，属于典型的插件级高危组合缺陷。

- **CVSS**：9.8
- **影响组件**：Anton Extensions WordPress 插件 1.2.2 及之前版本
- **与当前栈关联**：当前技术栈不含 WordPress；是否存在使用该插件的边缘站点未确认
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-108708 — Wukong_HRM 缺失授权漏洞

同一系统 EmployeeAspect 组件将候选人数据分配给所有用户，缺失授权检查，低权限用户可读取本不属于自己的候选人数据。与 CVE-2026-108707 组合可形成从未认证到数据泄露的完整路径。

- **CVSS**：8.8
- **影响组件**：Wukong_HRM（commit 186115e 及之前）
- **与当前栈关联**：同 CVE-2026-108707；当前环境是否部署未确认
- **来源等级**：official
- **来源名称**：NVD

### 5. CVE-2026-103695 — Mobile builder WordPress 插件 SQL 注入

WordPress 插件 Mobile builder 1.4.2 及之前版本未对用户参数做消毒与转义即拼入 SQL 语句，已登录用户可实施 SQL 注入，可能导致数据库数据泄露。

- **CVSS**：8.6
- **影响组件**：Mobile builder WordPress 插件 1.4.2 及之前版本
- **与当前栈关联**：当前技术栈不含 WordPress；影响范围未确认
- **来源等级**：official
- **来源名称**：NVD

### 6. CVE-2026-108693 — ImageMagick Windows 版搜索路径劫持

ImageMagick Windows 版本（7.1.2-33 及更早、6.9.13-58 及更早）在 NTGhostscript 相关功能中存在不可控搜索路径问题，本地攻击者有机会通过放置恶意库文件实现代码执行或提权，前提是能影响目标主机的文件系统或 PATH。

- **CVSS**：7.0
- **影响组件**：ImageMagick on Windows 7.1.2-33 / 6.9.13-58 及之前版本
- **与当前栈关联**：若存在使用 ImageMagick 处理图片的 Windows 主机则相关；当前主要服务器环境是否涉及未确认
- **来源等级**：official
- **来源名称**：NVD
