## 今日最值得关注

### 1. Claude 平台故障：claude.ai / Claude Code / platform.claude.com 错误率升高

Claude 官方状态页报告 claude.ai、Claude Code 与 platform.claude.com 出现错误率升高故障（官方一手来源，故障时间线以状态页为准）。HN 首页 482 分/382 评，讨论集中在故障影响面。

- **Cask**：`claude` 已在台账（mini m 在用，待收编）
- **价值判断**：故障类事件，非工具变化；若依赖 Claude Code 工作流需确认恢复时间。
- **与台账关联**：Claude 为 mini 在用工具，当日事件直接影响使用。
- **来源等级**：official
- **来源名称**：Claude Status

### 2. Mole：从开源清理工具到付费 Mac 应用

少数派报道 Mole（开源清理工具转型付费 Mac 应用）1.13 到 1.19 迭代，新增 AI 工具清理与系统数据清理，并提及 Windows 端。作者复盘在快 AI 时代如何做「慢产品」。媒体报道，定价与渠道待官方确认。

- **Cask**：`mole`（Homebrew formula 存在，同名；cask 未确认）
- **价值判断**：与清理类工具方向相同，作者产品化路径有参考价值；是否付费换功能未确认。
- **与台账关联**：台账清理项为 CleanMyMac X（p13）/ CleanMyMac_5（p14），功能重叠；暂不收编，仅观察。
- **来源等级**：media
- **来源名称**：少数派

### 3. 苹果新应用 Harbor：多台 Mac 组网运行本地大模型

小众软件转述 X 用户爆料：苹果正在开发应用 Harbor，通过 Thunderbolt 5 连接多台 Mac 协同运行本地大模型。媒体报道的爆料，未确认官方发布。

- **Cask**：无 cask（harbor-cli 为 Homebrew 同名不同产品，勿混淆）
- **价值判断**：Apple 本地模型集群路线，与端侧/本地推理方向相关；当前为爆料阶段。
- **与台账关联**：本地模型工具（LM Studio / Ollama）在 p14 在用；Harbor 为长期观察项。
- **来源等级**：media
- **来源名称**：小众软件

- **来源等级**：media
