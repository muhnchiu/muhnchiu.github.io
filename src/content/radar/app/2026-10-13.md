## 今日最值得关注

### 1. Codex CLI 被指默认安装自更新后台守护进程

HN 热帖（428 分 / 222 评）：OpenAI Codex CLI 默认安装一个持久化、自更新的后台守护进程，引发透明度与供应链安全讨论。该说法目前来自社区 issue，是否为默认行为及影响范围待官方确认。

- **Cask**：无（Codex CLI 走官方 CLI/npm 分发；注意台账有记录：brew 的 `codex` cask 是别的产品，勿混装）
- **价值判断**：agent CLI 的常驻进程直接影响环境审计与供应链安全基线，属于需要持续跟进的议题。
- **与台账关联**：台账 p14 机装有 Codex (OpenAI)，mini 机是另一产品 Codex++；建议对在用机器做一次常驻进程排查。
- **来源等级**：community
- **来源名称**：Hacker News / GitHub Issue

### 2. FSearch for macOS：开源全盘文件搜索工具

小众软件报道 FSearch 的 macOS 版本，定位 Everything 式全盘文件搜索，宣称比 Finder 快 17000 倍（该数字为开发者宣称，未经独立实测确认）。媒体称其为开源项目，具体许可证未确认。同周小众软件发现频道热榜还有同类产品 Lokii（Mac 原生亚毫秒级文件搜索，开源自荐），两者定位重叠。

- **Cask**：无（brew search 无精确匹配）
- **价值判断**：全盘索引式搜索是 Alfred 文件检索短板的补位方案；FSearch 与 Lokii 需择一试用。
- **与台账关联**：台账目前没有 Everything 类全盘搜索工具，属于功能空白位。
- **来源等级**：media
- **来源名称**：小众软件

### 3. Strata：宣称 8GB 显存运行千亿参数模型

小众软件报道 Strata 可在 8GB 显存的消费级显卡上运行千亿参数大模型，博主称在 RTX 5070、RTX 3060 等多款显卡上验证可行。此为媒体报道与博主自述，无独立复现，量化方案与实际性能未确认。

- **Cask**：无
- **价值判断**：若属实会显著降低本地推理门槛，但先看项目文档与技术方案再下结论。
- **与台账关联**：台账 p14 机已有 Ollama、LM Studio 承担本地推理，目前无替换证据。
- **来源等级**：media
- **来源名称**：小众软件

### 4. iTerm2 Buddy 自托管中继服务器

小众软件介绍为 iTerm2 官方 iPhone 应用 iTerm2 Buddy 自建中继服务器的方法：异地通过 iOS 连回 Mac 上已打开的 iTerm2 标签页，自托管可减少对公共中继的依赖并提升速度与私密性。

- **Cask**：无（iTerm2 已在台账；此为中继自托管配置，非新软件）
- **价值判断**：对已有 iTerm2 加 iPhone 的组合是低成本增强，配置一次长期受益。
- **与台账关联**：iTerm2 三机在用，直接相关。
- **来源等级**：media
- **来源名称**：小众软件

### 5. Google EmbeddingGemma 2 页面出现在 Product Hunt

今日 Product Hunt 列表出现 Google EmbeddingGemma 2 页面。页面上架不等于官方发布声明，具体规格、许可证与发布范围需以 Google 官方公告为准，本次抓取未包含独立官方公告链接。

- **Cask**：无（模型权重走 HuggingFace 等渠道，非桌面应用）
- **价值判断**：端侧嵌入模型是本地 RAG 与检索组件，值得持续跟踪。
- **与台账关联**：不直接涉及装机，属 local-ai 技术栈观察项。
- **来源等级**：ecosystem
- **来源名称**：Product Hunt

### 6. omdrop-owl：AirDrop 被逆向并移植到普通电脑

小众软件报道开发者逆向 AirDrop 协议的项目 omdrop-owl，尝试把隔空投送搬到非苹果设备。项目处于早期，实现完成度、稳定性与账号风控风险均未确认。

- **Cask**：无
- **价值判断**：跨平台文件传输的有趣方向，但逆向协议存在兼容与安全不确定性，先观察。
- **与台账关联**：台账传输链路已有 Keka、Motrix 与网盘，暂无增量需求。
- **来源等级**：media
- **来源名称**：小众软件

### 7. Agent37（YC F26）：低成本 agent 沙箱

HN Launch HN：Agent37 提供运行 AI agent 的低成本沙箱环境（84 分 / 60 评）。可对照同日 Show HN 的 Popcorn（一次性 microVM 安全工作台，开源）作为自托管替代。

- **Cask**：无（云服务形态）
- **价值判断**：agent 沙箱是 agent 基础设施的关键环节，价格与隔离强度待验证。
- **与台账关联**：不涉及本机装机；若有自托管需求可对照 Popcorn 等开源方案。
- **来源等级**：community
- **来源名称**：Hacker News

## 建议动作

**立即试用：**
1. FSearch for macOS（对照 Lokii 择一）：全盘搜索是台账空白，在 mini 机试用，验证索引速度与后台资源占用。
2. iTerm2 Buddy 自托管中继：已有 iTerm2 加 iPhone 组合，按文档自建中继并对比公共中继的连接速度。

**跟踪观察：**
- Codex CLI 后台守护进程 issue 的官方回应；顺带对在用机器做一次 agent CLI 常驻进程排查。
- Strata 的独立复现、技术文档与许可证。
- EmbeddingGemma 2 是否有 Google 官方公告与规格。
- omdrop-owl 的稳定性与安全反馈。
- Agent37 定价与隔离模型；Popcorn 开源方案成熟度。
- GLM-Legal 开源权重与许可证。

**收藏：**
- Popcorn（一次性 microVM 安全工作台）备查。
- chkit（ClickHouse schema/迁移/回填工具）备查。
- Vibecheck（合并前检查你是否理解 AI 生成代码的门禁）备查。
- SolidCraft（Rust 开源参数化 CAD，带 MCP 支持）备查。

**不收编：** MicYou（iPhone 变电脑麦克风，早期未上架 App Store，需求不明确）、Agent37（云服务非本机软件）、GLM-Legal 与 EmbeddingGemma 2（模型非应用）、PS2-WASM 重编译（娱乐向）、Ever/Yagi 等语言与库项目（暂无使用场景）均不进入台账。
