## 今日最值得关注

### 1. 1Password 安全事件

1Password 官方发布 2026 年 11 月安全事件说明，Hacker News 首页热度 1052 分、455 条评论，是当日最高热度条目之一。官方公告描述了事件性质与应对措施，影响范围与修复细节以官方说明为准。台账中未登记 1Password，但作为 macOS 环境常见密码管理器，该事件值得所有使用 1Password 的团队关注。

- **Cask**：无（1Password 本身已有官方 cask，此处为安全事件，非新软件）
- **价值判断**：当前正在使用的核心安全工具出现安全事件，需立即核实是否影响本地环境。
- **与台账关联**：台账未登记 1Password；若三机有使用，需评估事件影响。
- **来源等级**：official
- **来源名称**：1Password 官方博客

### 2. Superlist（Microsoft To Do 替代）

微软宣布关闭 To Do，Superlist 是 To Do 创始人团队推出的替代品，支持任务管理、多端同步，功能定位直接对标 To Do。小众软件报道指出 To Do 用户开始向 Superlist 迁移。macOS 有官方 cask `superlist`，当前版本 1.59.1，支持 macOS 12+。

- **Cask**：`superlist`（官方 cask，自动更新）
- **价值判断**：To Do 关闭后，Superlist 是最直接的官方替代方案，适合替代效率类需求。
- **与台账关联**：台账未登记 Superlist；若三机有 To Do 使用习惯，可考虑试用。
- **来源等级**：media
- **来源名称**：小众软件

### 3. Yab 开源 AI 友好双内核浏览器

Yab 是开源双内核浏览器（支持 Chromium + Firefox 内核），专为 AI 工作流设计，继承 Arc 浏览器的交互理念。少数派 App+1 专栏介绍其功能与使用场景。macOS 无官方 cask，需从 GitHub 下载。

- **Cask**：无（GitHub 发布，需手动安装）
- **价值判断**：开源、AI 友好、双内核，适合需要多浏览器内核环境的开发者；当前处于早期阶段，稳定性待观察。
- **与台账关联**：台账未登记 Yab；主力浏览器为 Chrome/Edge，Yab 可作为补充工具试用。
- **来源等级**：media
- **来源名称**：少数派

### 4. Ladybird 独立内核开源浏览器

Ladybird 是独立内核开源浏览器，不基于 Chromium 或 WebKit，由 Ladybird 团队独立开发。小众软件报道介绍其设计理念与当前进展。macOS 有官方 cask `ladybird`，当前版本 2026.47.7，要求 macOS 14+ 且 arm64 架构。

- **Cask**：`ladybird`（官方 cask，自动更新，要求 arm64 + macOS 14+）
- **价值判断**：独立内核浏览器在开源领域具有技术价值，适合关注浏览器内核生态的开发者；日常使用稳定性待观察。
- **与台账关联**：台账未登记 Ladybird；三机均为 arm64 环境（mini 为 Mac Mini，p13/p14 为 MacBook Pro），可试用。
- **来源等级**：media
- **来源名称**：小众软件

### 5. HealthBar 开源 macOS 菜单栏应用

HealthBar 是开源 macOS 菜单栏应用，用于追踪服务状态页（status page）。Hacker News Show HN 发布，热度较低（1 分/16 评论），属于新工具早期发布。GitHub 仓库可查。

- **Cask**：无（GitHub 发布，需手动安装或 brew tap）
- **价值判断**：开源、菜单栏轻量应用，适合需要追踪服务健康状态的场景；当前热度低，稳定性待观察。
- **与台账关联**：台账未登记 HealthBar；与 Stats（core 已装）功能有部分重叠，Stats 侧重系统监控，HealthBar 侧重服务状态追踪，可并存。
- **来源等级**：ecosystem
- **来源名称**：Hacker News / GitHub

### 6. 开源输入法大爆发（5 款对比评测）

小众软件报道开源输入法近期密集发布，5 款输入法对比评测，关注稳定性与功能完整性。macOS 开源输入法生态近年来有显著进展。

- **Cask**：无（各输入法独立项目，需查各自 cask 状态）
- **价值判断**：开源输入法生态活跃度提升，若有输入法需求可关注；与当前系统自带输入法并行使用。
- **与台账关联**：台账未登记开源输入法；当前无统一输入法需求，作为参考。
- **来源等级**：media
- **来源名称**：小众软件

### 7. Koofr 云存储 1TB 终身特价（129.99 美元）

Koofr 云存储 1TB 终身订阅特价 129.99 美元，2026 年 11 月 24 日再次开启优惠（非今日新增，为近期促销）。支持 WebDAV、Rclone，免费 10GB。

- **Cask**：无（Web 服务，非本地软件）
- **价值判断**：终身 1TB 云存储在云存储市场中价格有竞争力；若需长期云存储且偏好 WebDAV 协议，可考虑。
- **与台账关联**：台账未登记 Koofr；当前云存储使用 Cyberduck（已退役）/Transmit，无 WebDAV 需求，作为参考。
- **来源等级**：media
- **来源名称**：小众软件

### 8. Upload2Shell 高危漏洞（CVE-2026-125396）

安全研究人员公开 Upload2Shell 漏洞研究，影响 WordPress、Roundcube、MediaWiki、DokuWiki、CUPS 等广泛使用的服务，CVSS 8.5 分。涉及图像上传功能的安全问题，需检查相关服务是否受影响。

- **Cask**：无（安全事件，非软件）
- **价值判断**：影响面广的高危漏洞，若三机或公司服务器使用相关服务，需及时排查。
- **与台账关联**：台账中未见相关服务登记；若公司内部使用 WordPress 等服务，需安全团队跟进。
- **来源等级**：research
- **来源名称**：小众软件（转引安全研究）

### 9. WinGet 支持 MCP（Windows 端）

微软 WinGet 开始支持 MCP（Model Context Protocol），可在 Windows 终端中直接通过 AI 安装软件。macOS 无直接对应，但反映 AI 与包管理器融合趋势。

- **Cask**：无（Windows 平台特性）
- **价值判断**：对 macOS 开发环境无直接影响；若三机有 Windows 环境使用场景，值得关注。
- **与台账关联**：台账无 Windows 软件登记；作为趋势参考。
- **来源等级**：media
- **来源名称**：小众软件

### 10. Gemini 黑五促销（AI Pro/Plus 年费五折）

Google 官方开启 Gemini 黑五促销，AI Pro/Plus 年费五折（约 99.99 美元/年）。媒体来源，具体价格以官方结算页为准。

- **Cask**：无（Web 服务）
- **价值判断**：若使用 Gemini API 或 Web 界面，黑五促销是合适的订阅时机；需确认是否符合个人使用需求。
- **与台账关联**：台账未登记 Gemini；当前 AI 工具链使用 ChatGPT/Claude，Gemini 作为补充参考。
- **来源等级**：media
- **来源名称**：小众软件

## 建议动作

**立即试用：**
1. 核实 1Password 安全事件对三机的影响（若使用 1Password 作为密码管理器，查看官方修复说明）
2. 排查公司内部是否有 WordPress / CUPS / Roundcube 等 Upload2Shell 漏洞影响的服务

**跟踪观察：**
- Yab 浏览器：AI 友好双内核设计，稳定性待观察，可加入试用队列
- Ladybird 浏览器：独立内核开源项目，技术价值高，日常使用成熟度待确认
- Superlist：To Do 关闭后的官方替代方案，关注迁移体验
- 开源输入法生态：5 款对比评测，关注哪款稳定性最佳
- HealthBar：开源菜单栏应用，服务状态追踪场景

**收藏：**
- Koofr 1TB 终身特价（129.99 美元）：云存储备选方案
- Gemini 黑五促销：AI 订阅时机参考
- WinGet MCP 支持：AI 与包管理器融合趋势参考

**不收编：**
- HealthBar（功能与 Stats 部分重叠，当前服务状态追踪需求不强，watch 即可）
- Yab / Ladybird（主力浏览器已稳定，新内核项目处于早期，暂不替换主力）
- WinGet MCP（Windows 平台特性，对 macOS 无直接影响）
