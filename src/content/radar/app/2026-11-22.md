## 今日最值得关注

### 1. Inkling 2 Mini 官方开源：5.4GB 内存占用，本地可运行

Thinking Machines Lab 官方发布 Inkling 2 Mini，一个采用 looped transformer 架构的小型模型，总参数 26.4B（激活 3.4B），每个 token 权重激活 5.4B。官方声明内存占用约 20GB（NVFP4 + MXFP8 量化），实际运行内存约 5.4GB，可在消费级笔记本离线运行。模型以开放权重发布，在 DeepSWE v1.1（48.2%）和 Vals Index v2.2（46.5%）等基准上领先同类（<100B 参数）开放权重模型。官方演示了在 MacBook Pro（M5 Pro, 48GB）上离线构建并运行飞行模拟器的视频。Hacker News 同日出现"5.4GB 内存"量化项目（ShinMegamiBoson/lookatmyquant），与 Inkling 2 Mini 直接相关。

- **Cask**：无（官方模型权重，通过 Tinker 平台获取；本地推理需 Ollama / LM Studio 等工具）
- **价值判断**：小型本地推理模型，5.4GB 内存占用在 Apple Silicon 环境可运行，对本地 AI 编码场景有实用价值。
- **与台账关联**：台账中 p14 有 Ollama 和 LM Studio，可作为本地推理底座测试 Inkling 2 Mini；mini/p13 无相关工具，暂不装。
- **来源等级**：official（Thinking Machines Lab 官方发布）
- **来源名称**：Thinking Machines Lab

### 2. Alfred 6 升级跟进：台账在用 v5，官方 cask 已就绪

Alfred 6 正式发布，核心变化是 Alfred UI Toolkit：工作流可显示自己的操作窗口，支持输入框、按钮、表格和预览内容，还能调用 AI 模型。台账当前在用 Alfred 5（三机均手动安装，cask token `alfred` 已存在，另有 `alfred@5` 冻结版）。`brew search alfred` 确认 `alfred` cask 可用。昨日（11-21）日报已建议升级，今日执行检查确认 cask 就绪，可执行升级。

- **Cask**：`alfred`（`brew upgrade --cask alfred`，先在一台机器试用确认工作流兼容性）
- **价值判断**：同产品版本升级，UI Toolkit 显著扩展自动化能力，配合 AI 调用有增量价值。
- **与台账关联**：台账在用 Alfred 5，升级路径明确；三机均需同步。
- **来源等级**：official（Alfred 官网 / 小众软件报道官方发布）
- **来源名称**：小众软件 / Alfred 官网

### 3. GPGME 2.3.1 修复 RCE 漏洞（CVE-2026-129975）

GnuPG 官方发布 GPGME 2.3.1 安全公告，修复所有先前版本中的严重 RCE 漏洞。任何使用 GPGME 2.3.0 以下版本的软件（共享库、DLL 或静态链接）均受影响，包括 Gpg4win、Kleopatra 等。修复版本 GPGME 2.3.1 已发布。`brew list --formula | grep -iE "gpg|gnupg"` 在三台机器上均无结果，台账无 GPG 相关条目，但需确认是否有间接依赖（如 git、gh CLI 等工具链）使用 GPGME。

- **Cask**：无（GPGME 为系统级组件，非 GUI 应用；`brew install gnupg` 可获得最新版）
- **价值判断**：严重安全事件，涉及 RCE 路径；台账无直接条目，需核查是否有间接依赖。
- **与台账关联**：台账无 GPG/GnuPG 条目；若开发工具链有 GPG 签名需求需确认版本。
- **来源等级**：official（GnuPG 官方安全公告）
- **来源名称**：GnuPG 官方公告

### 4. KeyLayers：macOS 免费开源键盘分层工具，MIT 许可证

KeyLayers 是一个轻量 macOS 键盘分层工具，免费开源（MIT），当前版本 v0.0.2，要求 macOS 26（Tahoe）或更新版本。支持通过按住修饰键切换键盘布局层，将 HJKL 映射为方向键、媒体键映射到 F1-F12 等。支持多键盘映射、宏录制、紧急停止（Left Control + Left Option + Left Command + Escape 暂停所有重映射）。隐私设计：无网络请求（除 GitHub 更新检查），无账号，无遥测，密钥数据本地存储。通过 GitHub Release 直接下载 ZIP 安装，无官方 cask（`brew search keylayers` 无结果）。

- **Cask**：无（GitHub Release 直接下载；`brew search keylayers` 确认无 cask）
- **价值判断**：轻量、免费、MIT 开源，适合 MacBook 内置键盘场景；macOS 26 要求限制了可用性，暂观察。
- **与台账关联**：台账无键盘映射工具条目；若使用 MacBook 内置键盘且需要分层布局，可评估收编。
- **来源等级**：official（KeyLayers 官网 / GitHub，MIT 许可证）
- **来源名称**：KeyLayers 官网 / GitHub

### 5. KeepPlain：Agent 代码 git blame 工具，追溯每次 AI 改动来源

KeepPlain 是一个开源工具，为 AI 编程智能体（Claude Code、Codex、Cursor、Pi、Antigravity）生成的代码提供 git blame 追溯：不仅显示 commit 和作者，还能追踪到具体的 agent session——用户请求内容、agent 尝试路径、代码变更原因。安装方式：`curl -fsSL https://keepplain.com/install.sh | sh`（macOS/Linux）或 `irm https://keepplain.com/install.ps1 | iex`（Windows）。项目处于早期阶段（HN Show HN，热度 1分/0评），概念有价值但成熟度未确认。

- **Cask**：无（脚本安装，未确认是否有官方 cask）
- **价值判断**：AI 编程工具链配套，概念有价值；项目早期，暂观察。
- **与台账关联**：台账有 Claude（mini）、Codex（p14）等 AI 编程工具；KeepPlain 是配套追溯工具，可评估收编。
- **来源等级**：community（Hacker News Show HN，开源项目）
- **来源名称**：Hacker News Show HN / GitHub

### 6. Upload2Shell（CVE-2026-125396）：Ghostscript Type 1 字体加载器 RCE

pwn.ai 研究团队公布 Upload2Shell 漏洞详情：Ghostscript Type 1 字体加载器中的 use-after-free 漏洞，允许攻击者构造恶意文档突破 `-dSAFER` 沙箱，在渲染进程中执行任意命令。受影响路径包括 print、email、upload、preview 工作流。Ghostscript 10.08.0 已修复上游漏洞；Debian 13、Ubuntu 已发布补丁。影响面较广（Google、Roundcube、Plesk、WordPress 等均有确认的下游路径）。台账无 Ghostscript 直接条目，但若有文档处理服务需确认版本。

- **Cask**：无（Ghostscript 为系统级组件；`brew install ghostscript` 可获得最新版）
- **价值判断**：严重安全事件，涉及文档处理 RCE 路径；有文档处理服务的团队需确认 Ghostscript 版本。
- **与台账关联**：台账无 Ghostscript 条目；多乐士测试环境若有文档处理服务需核查。
- **来源等级**：research（pwn.ai 研究团队，官方 CVE 已发布）
- **来源名称**：pwn.ai / Hacker News

### 7. Straum：Postgres 实时物化视图，无需触发器或扩展

Straum（janbjorge/straum）是一个开源 Postgres 扩展，实现"永远不会过期的物化视图"——通过 Live Postgres aggregates 实现实时数据聚合，无需触发器或额外扩展。项目处于早期阶段（HN Show HN，热度 1分/0评），概念有趣，适合有 Postgres 实时数据需求的场景。

- **Cask**：无（开源 Postgres 扩展，通过源码或包管理器安装）
- **价值判断**：有潜力，项目早期，暂观察。
- **与台账关联**：台账有 DBX（Postgres 客户端），Straum 是数据库侧扩展，可评估。
- **来源等级**：community（Hacker News Show HN，开源项目）
- **来源名称**：Hacker News Show HN / GitHub
