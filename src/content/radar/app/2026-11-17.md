## 今日最值得关注

### 1. Jiff 1.0 发布：Rust 时间日期库官方 1.0

BurntSushi（Rust 生态核心人物）官方博客宣布 Jiff 1.0，这是 Rust 生态中专注正确性与易用性的 datetime 库（chrono 的替代定位），首个正式 1.0 意味着 API 稳定承诺。brew 已有 `jiff` formula（crate 工具链场景可配合 cargo）。与三机 macOS 台账无直接重叠（台账无 Rust 桌面工具），属于开发者生态信号。

- **Cask**：无（CLI 库，经 cargo/crates.io 使用；brew 可查 `jiff` formula，未验证安装路径）
- **价值判断**：做 Rust 项目时可作为 chrono 的低风险替代，值得跟踪。
- **与台账关联**：无重叠，不影响现有工具链。
- **来源等级**：official
- **来源名称**：BurntSushi 官方博客（jiff.rs 项目页）

### 2. Cal.com v7 发布

Product Hunt 今日条目，开源排期/会议链接平台 Cal.com 发布 v7。开源（MIT，未逐条确认），有云托管与自托管两种形态。台账无 Cal.com 条目；若需管理多人协作排期/面试/客户会议，自托管可用，但非当前刚需。

- **Cask**：无 cask（自托管走 docker；官方无桌面 cask，未确认）
- **价值判断**：功能成熟但属细分场景，按需再评估。
- **与台账关联**：与 Keynote/腾讯会议等无重叠；非当前工作流需要。
- **来源等级**：ecosystem
- **来源名称**：Product Hunt
- **来源 URL**：https://www.producthunt.com/products/cal

### 3. Stela：在普通 PC（Intel/AMD）上安装 macOS 27

小众软件报道开源项目 Stela，目标是在非 Apple 芯片的普通 PC 上安装 macOS 27（macOS 26 是最后一个支持 Intel Mac 的大版本，黑苹果停更于 macOS 26）。媒体报道，项目成熟度与可用性未确认。对 Apple Silicon 环境无直接价值，仅作为黑苹果生态信号。

- **Cask**：无（非 macOS 原生项目，无 cask）
- **价值判断**：与当前 Apple Silicon 三机环境无关，仅观察。
- **与台账关联**：无重叠。
- **来源等级**：media
- **来源名称**：小众软件（appinn.com）
- **来源 URL**：https://www.appinn.com/stela/

- **Cask**：`opencode`（官方 cask 存在，已 brew search 确认；另有 anomalyco/tap 第三方 tap，安装前需核对来源）
