## 今日最值得关注

### 1. AWS Emulator 本地模拟器

GitHub 开源项目 aws/aws-emulator 出现在 Hacker News 首页，605 分 205 评。该项目允许在本地模拟 AWS 服务，帮助开发者离线构建与调试云应用。

- **Cask**：无（开源工具，以 GitHub 分发为主）
- **价值判断**：为本地开发环境提供 AWS 仿真，适合微服务与 Lambda 测试。
- **与台账关联**：当前三机未部署本地 AWS 仿真工具，属于新增开发工具。
- **来源等级**：ecosystem
- **来源名称**：GitHub / Hacker News

### 2. Atuin Threads 多机 agent 会话同步

Atuin 官方博客发布 Threads 功能，将 agent 会话同步到多机。Hacker News 185 分 67 评。

- **Cask**：atuin（已装或可装）
- **价值判断**：增强 agent 会话连续性，适合多机协作开发流程。
- **与台账关联**：台账中无 atuin 记录，本次为首次出现。
- **来源等级**：official
- **来源名称**：Atuin 官方博客 / GitHub

### 3. Yogurt 开源 Granola 替代品

FrigadeHQ 发布 Yogurt，宣称免费、私有、开源的 Granola 替代品，支持 AI 笔记与会议记录。Hacker News Show HN 150 分 69 评。

- **Cask**：无
- **价值判断**：为注重隐私的会议记录提供本地化开源方案。
- **与台账关联**：当前未装 Granola 或同类工具，可作替代候选。
- **来源等级**：ecosystem
- **来源名称**：GitHub / Hacker News

### 4. 微软 Process Explorer 支持 macOS

小众软件报道，微软将 Windows 经典工具 Process Explorer 移植到 macOS，功能比活动监视器更强。

- **Cask**：无（官网渠道）
- **价值判断**：为 macOS 进程与资源排查提供更细粒度工具。
- **与台账关联**：当前无同类进程管理工具，可补强调试能力。
- **来源等级**：media
- **来源名称**：小众软件

### 5. 苹果 Harbor 多机本地模型集群

据小众软件报道，苹果新应用 Harbor 曝光，可通过 Thunderbolt 5 连接多台 Mac，协同运行本地大模型。

- **Cask**：无（未确认是否已开放下载）
- **价值判断**：若正式发布，将降低多机本地大模型部署门槛。
- **与台账关联**：p14 已装 Ollama / LM Studio，Harbor 可能作为多机集群补充。
- **来源等级**：media
- **来源名称**：小众软件

小众软件发现频道报道，小渔排班自 2026 年 10 月起永久免费，无广告、无订阅。
