## 今日最值得关注

### 1. 据报道苹果将推出 Mac 应用简化本地 AI 模型运行

9to5mac 11 月 10 日报道，苹果正在开发一款新 Mac 应用，目标是让运行本地 AI 模型更简单。据报道该应用可降低本地模型使用门槛，具体功能、模型支持范围、是否开源及发布时间待苹果官方确认。

- **Cask**：未确认（官方未发布 cask 信息）
- **价值判断**：若属实，对 Apple Silicon 环境运行本地模型有直接价值，但与现有工具重叠度高，暂不动手。
- **与台账关联**：台账 p14 已装 LM Studio（手动）和 Ollama（手动），苹果官方应用一旦发布，两者存在直接功能重叠，届时需评估是否退役。
- **来源等级**：media
- **来源名称**：9to5mac（据报道，待苹果官方确认）

### 2. 微软发布 Process Explorer for macOS（HN 118 分 / 45 评）

微软官方 GitHub 仓库 `microsoft/Procexp-Mac` 出现 Process Explorer 的 macOS 版本，HN 首页 118 分。项目为微软官方 GitHub 发布，具体功能完成度和是否已稳定可用待官方仓库 README 与 Release 页确认。

- **Cask**：未确认（brew search 未见 procexp-mac 官方 cask，安装渠道以 GitHub Release 为准）
- **价值判断**：微软官方出品，对开发者排查 macOS 进程有直接价值，值得试用。
- **与台账关联**：台账已有 Stats（core，mini/p13 在用，菜单栏系统监控）和 Monitoring Helper（mini 保留，macmon），Process Explorer 侧重进程树排查而非系统监控，功能不直接重叠。
- **来源等级**：official
- **来源名称**：Microsoft GitHub（microsoft/Procexp-Mac）

### 3. Blender 5.3 发布，新增 Gaussian Splat 支持（HN 414 分 / 58 评）

Blender 官方发布 5.3，新增 Gaussian Splat 支持（blender.org 官方下载页，HN 414 分 / 58 评）。Gaussian Splat 为当前 3D 重建和场景表示方向，对 3D 内容制作有实质意义。

- **Cask**：`blender`（brew search 确认，cask 可用；台账三机均未装 Blender）
- **价值判断**：开源免费，官方 cask 可收编，3D/创意制作工具，台账无重叠项，按需安装。
- **与台账关联**：台账 p14 有 Final Cut Pro（重件，媒体制作），Blender 与其无功能重叠；若需 3D/Gaussian Splat 工作流可收编到 p14。
- **来源等级**：official
- **来源名称**：Blender 官方（blender.org/download/releases/5-3/）

### 4. Ableton Live 13 发布（HN 265 分 / 286 评）

Ableton Live 13 官方上线（ableton.com，HN 265 分 / 286 评）。具体新功能、定价、是否对现有 Live 11/12 用户免费升级待 Ableton 官方页面确认。

- **Cask**：`ableton-live-lite`（brew search 确认 Lite 版有 cask，完整版为官网渠道）
- **价值判断**：音乐制作工具，台账无重叠项，按需评估。
- **与台账关联**：台账 p14 有 iMovie/GarageBand（mas），定位不同（GarageBand 为入门创作），无直接重叠。
- **来源等级**：official
- **来源名称**：Ableton 官方（ableton.com/live）

### 5. Windows Paint 曝高危漏洞 CVE-2026-83844，CVSS 8.1（媒体报道）

小众软件报道，微软披露通过官方商店安装的 Windows Paint 存在安全漏洞 CVE-2026-83844，CVSS 评分 8.1（高危），攻击者无需用户操作即可远程攻击。漏洞影响版本和补丁状态待微软官方确认。

- **Cask**：无（Windows 系统安全事件，与 macOS 无直接关联）
- **价值判断**：与三台 Mac 无直接关联，仅作安全情报跟踪。
- **与台账关联**：台账无 Windows Paint 条目；三机环境为 macOS，不涉及。
- **来源等级**：media
- **来源名称**：小众软件（报道，待微软官方确认）

### 6. QNAP Plex2Shell 漏洞链安全公告（11 月 6 日发布，仍在跟进）

小众软件 11 月 11 日再次报道 QNAP 11 月 6 日发布的 Plex2Shell 安全公告，黑客正利用该漏洞链攻击运行 Plex Media Server 的 NAS 设备，已有设备疑似遭入侵。该事件昨日已标记为 watch，今日媒体再次提及，修复进展待 QNAP 官方确认。

- **Cask**：无（NAS 安全事件）
- **价值判断**：若团队内网有 QNAP NAS 运行 Plex，需立即检查是否已应用修复。
- **与台账关联**：台账无 Plex / QNAP 条目；需在团队基础设施清单中确认。
- **来源等级**：media
- **来源名称**：小众软件（报道，修复状态待 QNAP 官方确认）

### 7. 双 11 正版软件大促，150+ 款低至 6 折（小众软件）

小众软件 11 月 11 日介绍年度双 11 软件促销，150+ 款商品参与，低至 6 折，涉及 AdGuard、Typora、PixPin、思源笔记、Mole 等。促销为媒体报道，具体折扣力度和截止时间待各平台确认。

- **Cask**：视具体软件而定（AdGuard / 思源笔记有 cask 渠道，Typora 有 mas 渠道）
- **价值判断**：促销期补全已有工具成本较低，但需评估实际使用需求。
- **与台账关联**：AdGuard（网络安全类别，台账无条目）、思源笔记（办公文档，台账无条目）、Typora（已退役，与 marktext 同属 Markdown 编辑器，不建议重新收编）。
- **来源等级**：media
- **来源名称**：小众软件（报道）

### 8. FilmCraft：Rust 开源视频编辑器（Show HN，功能与 Premiere 相近）

HN Show HN 新作，FilmCraft 为 Rust 编写的免费开源视频编辑器，功能定位类似 Adobe Premiere。项目较新（1 分 / 0 评），成熟度和稳定性未确认，具体功能覆盖范围待项目页确认。

- **Cask**：未确认（brew search 未见 filmcraft cask，安装渠道待确认）
- **价值判断**：开源免费，若功能成熟对 p14 的剪映（VideoFusion，手动装）有替代潜力，暂不建议收编，跟踪观察。
- **与台账关联**：台账 p14 有剪映（VideoFusion，手动）和 Final Cut Pro（手动，重件），FilmCraft 若成熟可作轻量替代；当前阶段仅探索。
- **来源等级**：community
- **来源名称**：Hacker News Show HN（filmcraft.tech）
