## 今日最值得关注

### 1. Tailscale SSH 安全漏洞调查与修复说明

Tailscale 今日发布官方调查与修复说明（HN 首页 170 分/96 评，小众软件同日亦独立报道）。安全研究员 Erica Windisch 公布 Tailworm 系列漏洞，影响 11 项组件，核心风险：一台设备失守后可获取其他服务器 root 权限。官方确认漏洞存在，修复方案已发布，建议立即更新 Tailscale 至最新版本。

- **Cask**：`tailscale-app`（台账已有，pkg 型）
- **价值判断**：当前在用组网骨干工具，安全影响直接且严重，需立即执行升级。
- **与台账关联**：mini 在用，p13/p14 需要时单独装；升级全三机。
- **来源等级**：official
- **来源名称**：Tailscale 官方博客

### 2. Ghostty 1.4 发布

Ghostty（Ghostty 1.4 发布说明，HN 首页 690 分/211 评）发布 1.4 大版本，官方 Release Notes 已上线。Ghostty 是 Rust 编写的高性能 GPU 加速终端，是当前台账主力终端（mini 和 p14 在用，p13 手动装）。1.4 属于跨大版本更新，建议三机统一升级后验证行为一致性。

- **Cask**：`ghostty`（台账已有，cask 型，mini/p13 待收编）
- **价值判断**：主力终端大版本更新，常规升级操作，收益为性能改进和 bug 修复。
- **与台账关联**：mini 手动装待收编（cask `ghostty` 已可 `brew install --cask --adopt`）；三机同步升级。
- **来源等级**：official
- **来源名称**：Ghostty 官方文档

### 3. Cloudflare Tunnel cloudflared 紧急安全更新

Cloudflare 邮件通知所有 Tunnel 用户尽快升级 cloudflared（小众软件报道）。旧版 cloudflared 仍信任此前由 eMudhra 颁发的 4 张已被吊销的 CA 证书，存在中间人攻击风险。影响所有通过 Cloudflare Tunnel 暴露服务的环境，建议检查并升级 cloudflared 至最新。

- **Cask**：`cloudflared`（非台账软件，CLI 工具）
- **价值判断**：网络基础设施安全更新，若有 Cloudflare Tunnel 使用场景需立即处理；无使用场景可忽略。
- **与台账关联**：当前台账无 cloudflared 记录；ngrok 在用但为不同产品。
- **来源等级**：official
- **来源名称**：Cloudflare（经小众软件报道）

### 4. Microsoft Authenticator 高危漏洞 CVE-2026-80097

小众软件报道：Microsoft Authenticator Android 版存在高危漏洞（CVSS 8.6），攻击者诱导用户安装恶意 App 即可窃取已登录的微软账户令牌，无需系统权限。当前 macOS 侧暂无公开确认影响，但 Android 用户应立即检查 Authenticator 版本。

- **Cask**：`microsoft-authenticator`（非台账软件）
- **价值判断**：若 Android 设备在用 Microsoft Authenticator，属需关注级别；macOS 用户影响待确认。
- **与台账关联**：台账未登记 Microsoft Authenticator，当前三机无此软件。
- **来源等级**：ecosystem
- **来源名称**：小众软件（appinn.com）

### 5. Jog - GitHub runners 低价替代方案

HN Show HN 发布（6 分/2 评，usejog.com），宣称以 80% 更低价格提供 GitHub Actions runners。属早期新品，尚无社区验证记录，适合有 CI 成本压力时做 POC 测试。

- **Cask**：无（Web SaaS 服务）
- **价值判断**：价格优势明确但产品成熟度未确认，不宜直接替换现有 CI 基础设施。
- **与台账关联**：当前使用 GitHub Actions 官方 runners；Jog 属可选替代方案，watch 级别。
- **来源等级**：ecosystem
- **来源名称**：Hacker News Show HN

- **来源等级**：ecosystem
