## 今日最值得关注

### 1. Atuin Desktop — Shell 历史同步与终端 Runbook 编辑器

Atuin 是广受欢迎的 shell 历史管理工具（zsh/bash/fish/nushell），支持跨设备同步、模糊搜索命令历史。今天 HN 显示其 Desktop 版本已更新至 0.2.20，提供 GUI runbook 编辑器，可把常用终端工作流编排成可复用脚本。MIT 开源，免费。

- **Cask**：`atuin-desktop`（GUI 编辑器）+ `atuin`（formula，CLI 核心）
- **价值判断**：终端历史跨设备同步对三机工作流有实际价值，Desktop GUI 降低 runbook 编写门槛，与 Ghostty/iTerm2 互补而非替代。
- **与台账关联**：台账主力终端为 Ghostty（mini/p13/p14），Atuin CLI 可作为 shell 层增强跨设备同步命令历史，不冲突；Desktop 是独立 GUI app。

### 2. Obscura VPN — 无法记录你活动的 VPN

HN 首页讨论热度较高（71 分）。主打零日志架构，服务端无法记录用户活动。客户端开源，基于 WireGuard。cask 已上架 Homebrew。

- **Cask**：`obscura-vpn`（1.170，auto_updates）
- **价值判断**：隐私导向的轻量 VPN，适合作为临时网络出口的补充选项，开源客户端可审计。
- **与台账关联**：台账网络类已有 Clash Verge Rev（代理）、Tailscale（组网），Obscura 属于不同场景（隐私出口），功能不重叠但 ClashX Pro 待清理后可考虑用此类轻量工具替代。

### 3. Native Apps in TypeScript and CSS (GEA Stack)

GitHub 项目 geastack/examples，用 TypeScript + CSS 编写原生应用，绕过 Electron 重量级方案。HN 72 分。

- **Cask**：无（npm 库，开发者工具）
- **价值判断**：对前端开发者有吸引力，是 Electron 的轻量替代思路，但目前生态早期。
- **与台账关联**：台账无 Electron 跨平台 GUI 框架记录，此项目偏开发框架而非终端用户软件，跟踪观察。

### 4. QuickLook Pro — macOS Quick Look 增强，支持 300+ 格式

Show HN 项目，扩展 macOS Quick Look 预览能力，支持 Markdown、SQLite、ZIP 等 300+ 格式。付费应用。

- **Cask**：无（独立销售，非 Homebrew）
- **价值判断**：Quick Look 增强对开发者在 Finder 快速预览文件有实际帮助，但非开源且无 cask，收编门槛高。
- **与台账关联**：台账无 Quick Look 增强工具，属新类别；与 marktext（停更 Markdown 编辑器）场景不同但可互补。

### 5. Tim's Markdown Reader — 离线 Swift 构建 Markdown 查看器

Show HN 项目，用 Swift 原生开发的 macOS Markdown 查看器，离线可用，轻量快速。GitHub 开源。

- **Cask**：无（GitHub 开源，需手动构建或下载 release）
- **价值判断**：原生 Swift + 离线 + 轻量，符合对 macOS 工具偏好；但无 cask 不便管理，且 marktext 已停更但仍在装。
- **与台账关联**：台账有 marktext（停更状态），此工具可作为 marktext 的轻量替代候选（仅查看不编辑），但优先级不高。

### 6. DynamicNotch — 可交互自定义 macOS 刘海工具

Show HN 项目，GitHub 开源。让 MacBook 刘海区域变得可交互、可自定义，显示通知、快捷操作等。类似 DynamicIsland 概念。

- **Cask**：无（GitHub 项目）
- **价值判断**：趣味性高、实用价值中等，对刘海屏 Mac 有场景。开源免费。
- **与台账关联**：台账无此类工具，属效率系统类新增。mini 为 Mac mini（无刘海屏），p14 有刘海屏可能受益。优先级低。

### 7. Morloc — 类型化多语言编译器，CLI/API/MCP 生成

Show HN 项目，GitHub 开源。一个 polyglot 编译器，可从单一规范生成多语言 CLI、API、MCP 工具。对 AI Agent 工具链有潜在价值。

- **Cask**：无（开发者工具，pip/npm 安装）
- **价值判断**：MCP 工具生成器在当前 AI Agent 生态中有实际需求，值得跟踪。
- **与台账关联**：台账有 Claude/ChatGPT/Codex++ 等 AI 工具，Morloc 属于开发框架层，不直接冲突。

### 8. PGSTY Silo — MinIO 无缝替代品

小众软件报道，从 MinIO fork 而来，只改一行代码即可无缝替代 MinIO。开源 S3 对象存储。在 MinIO 许可证变更和安全漏洞频发的背景下，提供了平滑迁移路径。

- **Cask**：无（服务端软件，Docker/二进制部署）
- **价值判断**：对使用 MinIO 的后端项目有直接价值；个人 Mac 上无直接部署场景。
- **与台账关联**：台账无 MinIO/S3 服务端条目；oss-browser 是阿里云客户端，不冲突。工作项目中如有 MinIO 依赖可关注。

### 9. HTTPS Capture — Apple 全平台抓包与 API 调试工具

小众软件报道，支持 iPhone/iPad/Mac 的 HTTPS 抓包、解密、API 调试、URL 重写、Mock、Hosts、断点调试。当前 App Store 终身限免（非国区）。

- **Cask**：无（App Store 上架，非 Homebrew）
- **价值判断**：全平台抓包 + 限免，对移动端调试有实际价值；Mac 端与 Proxyman 功能重叠。
- **与台账关联**：台账有 Proxyman（mini+p13 在用）和 Postman（API 调试），HTTPS Capture 在移动端有增量价值但 Mac 端无必要新增。

### 10. Riftri — 面向 Agent 并行运行的 Git Worktree 工具

Show HN 项目，基于 copy-on-write 的 Git worktree 管理，让多个 AI Agent 在同一仓库并行工作而不冲突。尚在早期（Twitter 发布）。

- **Cask**：无（开发者工具，早期阶段）
- **价值判断**：多 Agent 并行是当前工作流痛点，copy-on-write 思路正确，但项目太早期。
- **与台账关联**：台账有 git-guardrails 和 orchestration skill，Riftri 属于 Agent 基础设施层，跟踪观察。

## 与已装重复 / 功能重叠

| 新品 | 台账中重叠软件 | 重叠度 | 判断 |
|------|---------------|--------|------|
| Obscura VPN | Clash Verge Rev / Tailscale | 中 | 场景不同（隐私出口 vs 代理/组网），可共存；ClashX Pro 待清理后更不需要再加 |
| HTTPS Capture | Proxyman | 高（Mac端） | Mac 端完全重叠，Proxyman 已在用且更成熟；移动端有增量但限免工具质量待验证 |
| Tim's Markdown Reader | marktext | 低 | marktext 是编辑器（停更），此为查看器，场景不同；但 marktext 停更后清理优先级高于新增 |
| Atuin Desktop | Warp（待退役） | 低 | Atuin 是 shell 历史层，Warp 是终端 emulator，层级不同；Warp 退役后 Atuin 反而更值得装 |

## 建议动作

**立即试用：**
1. `atuin`（formula）+ `atuin-desktop`（cask）：跨设备 shell 历史同步 + GUI runbook，开源免费，与 Ghostty 工作流互补。mini 上先试 CLI 版，验证同步体验后再装 Desktop。
2. HTTPS Capture：当前限免，用非国区 Apple ID 下载，手机端抓包场景用得上。Mac 端不替代 Proxyman。

**跟踪观察：**
- Morloc：MCP 工具生成器，AI Agent 工具链有需求，等项目成熟度提升。
- Riftri：多 Agent 并行 worktree 管理，痛点匹配但项目太早期。
- GEA Stack（TypeScript 原生应用框架）：生态早期，关注后续发展。
- DynamicNotch：p14 有刘海屏可试，但优先级低。

**收藏：**
- PGSTY Silo：工作项目中如有 MinIO 依赖，收藏备用。
- Obscura VPN：cask 已上架，ClashX Pro 退役后可作为轻量隐私 VPN 的备选。

**不收编：**
- QuickLook Pro（非开源、无 cask、付费，收编门槛高）、Tim's Markdown Reader（无 cask 且 marktext 未清，先清后增）、各种 Show HN 早期项目（Birthed/Livenerf/Palette/Jade Email/LARP Capital 等均无成熟度或 macOS 关联）。
