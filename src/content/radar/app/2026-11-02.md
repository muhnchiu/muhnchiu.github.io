## 今日最值得关注

### 1. OmniDiff：Rust 实现的内容感知 Git diff 工具

HN 首页出现的项目（143 分/38 评），开源，用 Rust 实现的超级快速、内容感知的 Git difftool。适合频繁处理大文件 diff 的开发者。

- **Cask**：无官方 cask，GitHub 直接下载或 cargo 安装
- **价值判断**：替代 git difftool，提升大文件 diff 性能，值得试用
- **与台账关联**：补充 Git 工具链，不冲突现有软件
- **来源等级**：community
- **来源名称**：Hacker News

### 2. Strata 0.2.9：本地大模型推理引擎，Prefill 提速最高 88%

小众软件报道，本地运行 AI 大模型的 Strata 更新到 0.2.9 版本，在 Windows + AMD Strix Halo 上运行 Qwen3.8 模型时 prefill 提速最高 88%，还支持 1 比特 DeepSeek。

- **Cask**：无（Strata 为 Windows 工具，macOS 未确认）
- **价值判断**：若主要跑在 Apple Silicon 上，需确认 macOS 支持情况；性能提升显著值得关注
- **与台账关联**：与 Ollama/LM Studio 功能重叠（p14 在用），若支持 macOS 可作备选
- **来源等级**：media
- **来源名称**：小众软件

### 3. Synology DSM 勒索病毒事件：利用 2024 年 12 月已修复漏洞

群晖官方公告确认勒索病毒攻击利用了 2024 年 12 月已完成修复的安全弱点（Synology-SA-24:20），攻击仍运行旧 DSM 版本的设备。最新 DSM 版本也有受害报告，入侵原因未确认。

- **Cask**：不适用（服务器/NAS 系统更新）
- **价值判断**：若使用群晖 NAS，需立即检查 DSM 版本并升级到最新
- **与台账关联**：台账未登记群晖 NAS，若有则需紧急处理
- **来源等级**：official
- **来源名称**：群晖安全公告（Synology-SA-25:06 待确认编号）
- **来源 URL**：https://www.synology.com/en-us/security_advisory

- **Cask**：不适用（系统功能）

- **与台账关联**：台账未登记 LXD，若在某台机器运行则需处理
