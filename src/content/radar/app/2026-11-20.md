## 今日最值得关注

### 1. Nginx HTTP/2 未认证远程代码执行（CVE-2026-123007）

Nginx 于 2026-11-18 披露多个安全漏洞，其中两项涉及 HTTP/2，据报道攻击者可在无需认证的情况下远程执行代码，CVSS 评分 8.1。开启 HTTP/2 的 Nginx 实例需尽快更新到修复版本。

- **Cask**：无（服务端组件，不适用 Homebrew cask）
- **价值判断**：安全补丁优先级最高，影响面大。
- **与台账关联**：三机本地服务（nginx 反代 9099→8080 等）与测试环境（多乐士测试机）若使用 Nginx，需核查版本并打补丁。
- **来源等级**：media（小众软件报道，CVE 编号与评分来自 Nginx 官方公告，待官方补丁页确认细节）
- **来源名称**：小众软件 / Nginx Security

### 2. Kiiwi：Mac 机械键盘音

Show HN 上架的 macOS 小工具，为键盘敲击添加机械键盘音效，定位轻量的输入体验增强。

- **Cask**：无（官网渠道，未见官方 cask）
- **价值判断**：小工具，趣味性大于实用性。
- **与台账关联**：三机无同类工具，不与任何在项重叠；可试用但不建议收编。
- **来源等级**：community
- **来源名称**：Hacker News Show HN

### 3. 微软 To Do 宣布 2027 年关闭

据报道，微软 To Do（含当年收购的 Wunderlist）将于 2027 年停止服务。待办类工具用户需提前迁移数据。

- **Cask**：无
- **价值判断**：存量工具退出，属信息跟踪，无直接行动。
- **与台账关联**：三机台账未登记 To Do/Wunderlist，无迁移影响。
- **来源等级**：media（媒体报道，微软官方公告细节待确认）
- **来源名称**：小众软件

### 4. Itsycal 0.29.0：菜单栏日历新增 1 小时计时器

经典免费 macOS 菜单栏日历工具 Itsycal 更新到 0.29.0，新增简单的 1 小时计时器功能。

- **Cask**：有官方 cask `itsycal`（已用 brew search 验证）
- **价值判断**：轻小工具，功能增量有限。
- **与台账关联**：三机台账无日历/计时器类工具，无重叠；有需求可装，优先级低。
- **来源等级**：media
- **来源名称**：小众软件

### 5. ALTRun：不到 1MB 的开源启动器

开源轻量启动器，支持拼音首字母、Everything 文件搜索、Listary 模式、剪贴板历史，单文件不到 1MB。

- **Cask**：无（开源项目，官方安装渠道待确认）
- **价值判断**：有潜力替代重量级启动器，需实测。
- **与台账关联**：与在用的 Alfred 5 功能重叠（启动器+剪贴板），Alfred 为成熟主力，暂不建议替换。
- **来源等级**：community
- **来源名称**：小众软件 / 开发者自荐

### 6. UU 远程开始收费：VIP 24元/月起

网易 UU 远程结束三年免费，推出付费会员：VIP 每月 24 元起、SVIP 每月 88 元起；原免费的 4K 144 帧高级功能划入会员权益，免费用户最高仅 1080P 30 帧（据报道，待官方页面确认）。

- **Cask**：无
- **价值判断**：存量远控工具涨价，无直接行动。
- **与台账关联**：三机远控栈为 AnyDesk / ToDesk / Windows App，不使用 UU 远程，无影响。
- **来源等级**：media
- **来源名称**：小众软件

Show HN 上架的 Rust 编辑器项目，定位轻量版 PyCharm，短期热度（1分/0评），成熟度未确认。

- **价值判断**：早期项目，观察即可。
- **与台账关联**：与 VS Code / Sublime 同域但形态不同，无重叠行动。
- **来源等级**：community
- **来源名称**：Hacker News Show HN / GitHub

### 8. Onlook（YC W25）：开源设计师开发者工具（Launch HN）

Launch HN 项目，面向设计师的开源开发工具，GitHub 仓库 onlook-dev/onlook。

- **Cask**：无（开源 CLI/Web 工具）
- **价值判断**：细分赛道，与设计工作流相关才值得深入。
- **与台账关联**：三机无设计向工具，无重叠。
- **来源等级**：community
- **来源名称**：Hacker News / GitHub

### 9. PHP 8.6 发布，同时修复旧版本严重安全漏洞

PHP 8.6 正式发布；8.2.36、8.3.37、8.4.28、8.5.13 同时修复安全漏洞，服务端应优先安装当前分支补丁。

- **Cask**：有官方 formula `php@8.6`（Homebrew 生态源，待验证）
- **价值判断**：后端语言例行更新+安全修复。
- **与台账关联**：三机台账无 PHP 服务；测试环境若运行 PHP 需同步补丁。
- **来源等级**：official（php.net 官方发布页）
- **来源名称**：Hacker News / php.net / 小众软件
