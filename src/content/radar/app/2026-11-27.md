## 今日最值得关注

### 1. 1Password 安全事件（官方确认）

1Password 于 11 月 25 日发布安全公告，确认黑客通过一名员工的企业 GitHub 账号入侵。泄露数据包括：姓名、邮箱、用户 ID、部分邀请与恢复令牌、登录时间。官方确认：密码库、主密码、账户私钥、恢复私钥均安全。HN 首页 1628 分，热度极高。若本机使用 1Password（台账未登记，需确认是否使用），应检查账号异常并留意官方后续公告。

- **Cask**：`1password`（若使用）
- **价值判断**：核心密码管理器安全事件，需确认本机是否使用并采取响应。
- **与台账关联**：台账未登记 1Password；若使用需确认账号状态，若未使用则无需操作。
- **来源等级**：official
- **来源名称**：1Password 官方博客

### 2. YAB 双内核开源浏览器

少数派 App+1 推荐：开源、AI 友好的双内核浏览器，继承 Arc 的交互设计，同时支持 AI 集成。适合对浏览器交互有较高要求的用户。

- **Cask**：待确认（未验证）
- **价值判断**：双内核架构（WebKit + Chromium）有差异化价值，AI 友好是加分项。
- **与台账关联**：台账有 Chrome/Edge，YAB 为替代选项，不重复。
- **来源等级**：community
- **来源名称**：少数派

### 3. Ladybird 独立内核开源浏览器

小众软件介绍：Ladybird（瓢虫）是独立内核开源浏览器，不基于 Chromium 或 WebKit，目标"只做浏览器"。项目有独立内核（WebKit 衍生），开发活跃。

- **Cask**：待确认（未验证）
- **价值判断**：独立内核是稀缺价值，适合关注浏览器架构的用户跟踪。
- **与台账关联**：与台账 Chrome/Edge 不重复，属新内核类别。
- **来源等级**：community
- **来源名称**：小众软件

### 4. Moat 自托管 LLM 网关

HN 244 分，136 评。Moat 是 OpenRouter 的自托管替代方案，可作为本地 LLM 网关统一管理多个模型后端。对本地推理场景有实用价值。

- **Cask**：无（自托管服务，非桌面 App）
- **价值判断**：自托管 LLM 网关，适合已有本地模型（LM Studio/Ollama）的用户。
- **与台账关联**：台账有 LM Studio、Ollama（p14），Moat 可统一管理，无冲突。
- **来源等级**：community
- **来源名称**：Hacker News

### 5. NFS2ROOT 严重漏洞（NAS 侧）

小众软件报道：Linux NFS 服务端曝出 CVE-2026-99362（CVSS 9.8），开启 NFSv4.1/4.2 共享的 NAS 和自建服务器需检查更新并限制访问。与本机 Mac 开发工具链无直接关系，但若有 NAS 应关注。

- **Cask**：无
- **价值判断**：基础设施安全漏洞，非 macOS App，仅跟踪。
- **与台账关联**：无直接关联。
- **来源等级**：community
- **来源名称**：小众软件

- **价值判断**：自托管协作场景补充，非通用办公需求。
- **与台账关联**：台账无 Nextcloud，属新工具，不冲突。

## 建议动作

**立即试用：**
1. 确认本机是否使用 1Password；若使用，检查账号异常并留意官方后续公告
2. YAB 浏览器（若有 cask，`brew install --cask yab` 或官网下载试用）
3. Moat 自托管 LLM 网关（若已有本地模型，部署试用）

**跟踪观察：**
- Ladybird 独立内核浏览器（等成熟度提升再考虑安装）
- Olumino Markdown 笔记 + 间隔复习（与 Obsidian 功能重叠，不急于替换）
- Nextcloud Office 桌面版（自托管用户增量）
- Chrome 官方 Skills: Modern Web Guidance（AI 前端开发参考）
- 开源输入法生态变化（5 款对比，不急于安装）
- NFS2ROOT 漏洞（若有 NAS，检查更新）

**收藏：**
- YouTube Ad Punisher（HN 230 分，Chrome 扩展，自动重载有广告的页面）
- Rvoip 0.5（Rust VoIP 完整栈，开发者工具）
- Single Calendar（多 Google 日历同步，实用工具）

**不收编：** Kaju（Claude Code 注解工具，与现有开发工具链重叠）；DataFluxor（SEO 抓取工具，非核心需求）；Glassveil（iPhone 照片传输，Windows 向，Mac 不适用）；LbDMF（SourceForge 项目，热度低）；OIM（Apache-2.0 多语言交互 PNG，小众）
