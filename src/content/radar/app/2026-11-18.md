## 今日最值得关注

### 1. Java4Shell：Java 17 处理 Base64 的 pre-auth RCE（CVE-2026-114938）

calif.io 安全团队报告，Java 17 在解析 Base64 输入时存在 pre-auth 远程代码执行漏洞（CVE-2026-114938），HN 410分/107评居首页第5。Aikido 同日发布分析（140分）。这是当前 Java 17 运行环境的安全高危项，但官方补丁/修复版本与受影响的 JVM 完整范围，以 Oracle/OpenJDK 官方公告为准，尚未在抓取数据中确认。台账中 dulux 后端 jar 等 Java 运行环境与本机 brew `java`/`java11` formula 均需核查版本与暴露面。

- **Cask**：`java`、`java11`（brew search 已确认存在；漏洞修复需等官方补丁版本，暂不盲目升级）
- **价值判断**：核心安全信号，需立即核查在用 Java 版本的 Base64 输入暴露面。
- **与台账关联**：台账未列 Java/JDK 为桌面软件，但服务端/测试环境 Java 运行环境存在，需单独审计。
- **来源等级**：community（安全团队博客 + 媒体分析；官方公告待确认）
- **来源名称**：Hacker News / calif.io / aikido.dev

### 2. ONNX Runtime 仓库在 GitHub 404，官方迁移去向待确认

HN 48分帖子指称 Microsoft ONNX Runtime 仓库在 GitHub 上返回 404。本机通过代理访问该仓库页确认 404 属实，但 404 原因（迁移、改名、访问限制或平台故障）官方尚未说明，待确认。brew 公式 `onnxruntime` 当前仍可在 Homebrew 中检索到（formula 指向上游源码，若上游仓库迁移可能影响后续构建）。ONNX Runtime 是推理引擎，与本地 AI 工具链（台账 p14 的 Ollama/LM Studio 为本地推理相关项，但 ONNX 侧暂无台账条目）有一定关联。

- **Cask**：`onnxruntime`（brew 公式，brew search 已确认存在；是否需跟进上游迁移未确认）
- **价值判断**：若在用 ONNX 推理链路，需跟踪官方渠道确认仓库去向，暂不动作。
- **与台账关联**：台账无 ONNX Runtime 条目；p14 本地推理工具（Ollama/LM Studio）与 ONNX 无关，暂无直接冲突。
- **来源等级**：ecosystem
- **来源名称**：GitHub / Hacker News
