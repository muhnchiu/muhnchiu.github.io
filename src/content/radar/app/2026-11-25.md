## 今日最值得关注

### 1. Mason 列式 Postgres 只读复制品

HN Show HN 展示，基于列式存储的轻量 Postgres 只读复制方案。面向分析型负载，与行式主库配合。

- **Cask**：无（开源项目，无官方 cask，GitHub 部署）
- **价值判断**：分析型工作负载的轻量复制方案，对现有 Postgres 栈是增量价值，暂不安装。
- **与台账关联**：台账中 DBX / DBeaver 为数据库客户端，无复制方案，属新增方向。
- **来源等级**：community
- **来源名称**：Hacker News Show HN

### 2. Rhebok 本地编码 RAG

HN Show HN 展示，面向编码 agent 的免费本地 RAG 引擎。强调"本地"与"免费"，可替代部分云服务检索。

- **Cask**：无（开源，GitHub 部署）
- **价值判断**：本地化检索有价值，若 agent 工作流需要 RAG 可试用。
- **与台账关联**：台账无 RAG 类工具，属新增方向，不影响现有开发工具链。
- **来源等级**：community
- **来源名称**：GitHub（HN Show HN）

### 3. Upload2Shell 高危漏洞 CVE-2026-125396

小众软件报道，CVSS 8.5，影响 WordPress、Roundcube、MediaWiki、DokuWiki、CUPS 及图像上传组件。图片上传即可触发 shell。

- **Cask**：无（安全事件，非软件）
- **价值判断**：若自托管 WordPress/网盘/打印服务，需立即排查升级。
- **与台账关联**：台账无相关自托管服务，对三机无直接影响，但提醒对外暴露的 Web 服务注意。
- **来源等级**：media
- **来源名称**：小众软件

### 4. 微软 WinGet 支持 MCP

小众软件报道，WinGet 开始支持 MCP 协议，可通过 AI 自然语言描述安装 Windows 软件。据报道，微软官方确认，待官方完整文档确认。

- **Cask**：无（Windows 平台，macOS 不适用）
- **价值判断**：对 Windows 用户有生态意义，对 macOS 台账无影响。
- **与台账关联**：无直接关联，macOS 侧 brew 体系不受影响。
- **来源等级**：media
- **来源名称**：小众软件

### 5. Koofr 云存储终身 1TB 特价 129.9 美元

小众软件报道，Koofr 2026-11-24 再次开放 1TB 终身订阅 129.9 美元（含优惠码），支持 WebDAV / Rclone。据报道，为黑五期间限时。

- **Cask**：无（SaaS，非本地软件）
- **价值判断**：若需 WebDAV 存储可关注，但价格与 iCloud / 阿里云 OSS 重叠，暂不推荐。
- **与台账关联**：台账已有 iCloud / oss-browser / cosbrowser，Koofr 属额外选项，不收编。
- **来源等级**：media
- **来源名称**：小众软件

- **Cask**：无（iOS / Web 服务）
- **价值判断**：若使用 To Do 需关注迁移，当前台账无 To Do，不影响。
- **与台账关联**：无直接关联。
- **来源等级**：media
- **来源名称**：小众软件
