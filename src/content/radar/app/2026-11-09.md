## 今日最值得关注

### 1. OpenSSH 十年老漏洞 CVE-2026-123158：超长密码绕过SSH登录

OpenSSH 存在一个隐藏约十年的严重漏洞（CVE-2026-123158），攻击者无需私钥，只需输入超长密码即可绕过 Linux 账户密码锁定机制，直接登录系统甚至获得 root 权限。小众软件 11 月 5 日报道此事件，具体修复方案和时间线待官方确认。台账中 OpenSSH 为系统自带，不在 brew 管理范围内，但三台 Mac 均通过 SSH 连接多乐士测试环境（172.102.10.93），需确认该系统是否已应用补丁。

- **Cask**：无（系统自带 OpenSSH，不在 cask 管理范围）
- **价值判断**：高危安全事件，影响所有使用 OpenSSH 密码登录的系统，需确认修复状态。
- **与台账关联**：台账中无 OpenSSH 条目（系统组件），但与多乐士测试环境 SSH 接入相关。
- **来源等级**：media
- **来源名称**：小众软件（报道），修复状态待官方确认

### 2. Claude Code 密码泄露事件：1122份GitHub公开文件含密码

Hacker News 高分文章（579分/392评）指出，Claude Code 的 "Don't Ask Again" 功能导致 1122 份公开 GitHub 文件中泄露了密码。该事件由 Apiiro 发布于 2026 年 11 月，文章称泄露文件可通过公开搜索定位。台账中 Claude 为手动装（mini 在用），需检查 Claude Code 配置中是否有敏感信息已写入公开仓库。

- **Cask**：无（Claude 为手动装 app，无 cask）
- **价值判断**：开发工具安全事件，影响 Claude Code 用户，需自查配置。
- **与台账关联**：台账中 Claude（手动，mini 在用）和 Claude Code URL Handler（~/Applications）均与 Claude 生态相关。
- **来源等级**：community
- **来源名称**：Hacker News（Apiiro 博客文章）

### 3. 少数派两篇M6 MacBook Pro报道，待官方确认

少数派 11 月 8 日左右发布两篇文章：《更高能效比，带来新惊喜：M6 款 MacBook Pro 初探》（sspai.com/post/118570）和《开启 Mac 的下一世代：MacBook Pro (PROLED XDR) 首发体验》（sspai.com/post/118546）。两篇文章均提及 M6 芯片 MacBook Pro，但均为媒体报道，未确认是否为 Apple 正式发布，产品规格和上市时间待官方确认。

- **Cask**：无（硬件设备，不在软件台账范围）
- **价值判断**：媒体报道，待 Apple 官方确认 M6 MacBook Pro 规格和发布时间，暂不据此调整装机规划。
- **与台账关联**：台账基线为 mini（2026-08-27）/ p13/p14（2026-08-25），M6 发布后需重新评估三机硬件基线。
- **来源等级**：media
- **来源名称**：少数派

### 4. Itsycal 0.28.0：菜单栏日历现支持苹果提醒事项

Itsycal 0.28.0 发布（11 月 7 日左右），新增对苹果 Reminders 的支持，菜单栏日历可同时显示日程和待办。Itsycal 为经典 macOS 免费菜单栏日历工具，功能轻量。台账中无 Itsycal 条目，三台 Mac 均未安装；若需菜单栏待办展示，可考虑试用，但与 Alfred 5（已装）部分功能重叠。

- **Cask**：`itsycal`（brew search 确认可用）
- **价值判断**：轻量免费，有实用价值，但与 Alfred 部分重叠，暂不需收编。
- **与台账关联**：台账中无 Itsycal；与 Alfred 5（手动，三台在用）功能部分重叠（待办提醒）。
- **来源等级**：media
- **来源名称**：小众软件（报道）
