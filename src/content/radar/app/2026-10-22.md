## 今日最值得关注

### 1. Strata 0.2 测试版：降低本地大模型运行门槛

据小众软件报道，开源本地 AI 推理工具 Strata 发布 0.2.0 测试版，进一步降低本地大模型运行门槛，可运行 Qwen3.8-Flash-Next、Qwen3.6-35B-A3B 等模型。同日，另一款开源推理工具 Splash 发布 1.4.0，据开发者宣布在相同 Mac 配置下性能提升 30%，并直接对比 Strata。两款工具竞争格局形成，是否持续迭代待观察。

- **Cask**：无（据媒体报道为开源工具，brew 可安装性未确认）
- **价值判断**：低配设备本地推理门槛降低，但与现有 Ollama/LM Studio 功能重叠，暂不安装。
- **与台账关联**：p14 已装 Ollama（手动）和 LM Studio（手动），本地推理功能有重叠。
- **来源等级**：media
- **来源名称**：小众软件

### 2. LiteLLM 1.107.0 PyPI 供应链安全事件

Hacker News 报道 LiteLLM 1.107.0 在 PyPI 上的发布包被植入凭证窃取器和后门（社区报告，未官方确认具体影响范围）。台账中未记录 LiteLLM 为已装软件，但若 Python 开发环境中使用过该版本，需检查 `pip show litellm` 确认版本并升级至安全版本。

- **Cask**：无（Python 包，非 cask）
- **价值判断**：需主动检查已装 Python 环境是否受波及。
- **与台账关联**：与当前开发工具链的 Python 包管理相关，台账未登记 LiteLLM。
- **来源等级**：community
- **来源名称**：Hacker News（Safedep 报告）

### 3. DuckDB 2.0.0 LTS "Cinnamon Teal" 发布

DuckDB 官方宣布 2.0.0 LTS 版本，是嵌入式列式分析数据库的里程碑版本，支持 SQL 分析查询、内存优化、并行扩展。官方公告为 primary source。

- **Cask**：`duckdb`（formula，已有 brew 条目）
- **价值判断**：轻量级本地分析数据库，适合数据管道场景，与 DBX 的 GUI 数据库管理互补。
- **与台账关联**：台账已有 DBX（数据库统一工具），DuckDB 可作为本地分析补充，暂观察。
- **来源等级**：official
- **来源名称**：DuckDB 官方公告

### 4. Vitals：更直观的 Mac 系统监控工具

少数派推荐 Vitals 为比「活动监视器」更直观易用的 Mac 系统监控工具，支持整合式监控与 AI 协作能力，适合在 Mac 上进行开发和本地 AI 推理的场景。

- **Cask**：未确认（未通过 brew search 验证）
- **价值判断**：与台账已有 Stats（菜单栏实时系统监控，免费开源）功能重叠，Vitals 优势在 AI 协作，暂不安装。
- **与台账关联**：Stats 已在 mini 和 p13（core 条目），Vitals 与其重叠度较高。
- **来源等级**：media
- **来源名称**：少数派

### 5. Show HN: Lasso - 免费 Mac 应用，为 AI Agent 提供屏幕标注

Hacker News Show HN 新发 Lasso（trylasso.online），一款免费 Mac 应用，允许用户为 AI Agent 提供屏幕标注，帮助 Agent 更精确地理解用户指向的界面元素。项目为新，热度低（1分/0评），可先观察。

- **Cask**：无（新发项目，brew 可安装性未确认）
- **价值判断**：AI Agent 交互增强工具，与当前 AI 辅助开发工作流相关，有潜力。
- **与台账关联**：与 Claude、Codex 等 AI 工具链互补，暂观察。
- **来源等级**：community
- **来源名称**：Hacker News

### 6. Claude Duet 产品页面上线

Anthropic 官方页面发布 Claude Duet 产品（claude.com/product/claude-duet），HN 热度 293分/249评。具体产品形态和功能待官方说明确认。

- **价值判断**：AI 协作产品新动向，与现有 Claude 工具链相关，观察产品落地形态。
- **与台账关联**：mini 已装 Claude（手动），新产品需待落地后再评估。
- **来源等级**：official
- **来源名称**：Anthropic 官方

### 7. OpenAI 模型即将登陆 Google Cloud

OpenAI 官方宣布其模型将登陆 Google Cloud 平台（openai.com 官方公告，HN 热度 222分/96评）。据官方说明，这是模型提供商的渠道扩展，非本地部署工具。

- **Cask**：无
- **价值判断**：云端 AI 服务渠道扩展，对本地开发工具链无直接影响，仅关注。
- **与台账关联**：与当前开发工具链的 AI 服务调用相关，无直接收编需求。
- **来源等级**：official
- **来源名称**：OpenAI 官方

### 8. PHP 8.2.35 发布 + 安全加固

PHP 官方发布 8.2.35，HN 首页热度 957分/529评（今日最热）。同日 PHP 官方发布安全加固公告，提及 PHP 9.2 两项 CVSS 9.2 严重漏洞（据小众软件报道，待官方确认完整影响范围）。当前开发工具链是否使用 PHP 未确认。

- **Cask**：无（PHP 为 scripting language，非 macOS 应用）
- **价值判断**：安全相关，但需确认当前开发工具链是否依赖 PHP。
- **与台账关联**：台账未记录 PHP 相关工具，无直接收编。
- **来源等级**：official
- **来源名称**：PHP 官方 / ThePHP Foundation
