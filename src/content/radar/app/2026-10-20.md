## 今日最值得关注

### 1. Strata 支持 Apple Silicon，可本地运行 Qwen3.6-35B-A3B

小众软件报道 Strata 这款本地推理工具近期连续更新：开始支持 Apple Silicon Mac，并可运行更轻量的 Qwen3.6-35B-A3B 模型。此前该工具主要面向普通显卡，主打 125B 级 Qwen3.8-Flash-Next（激活参数 6B）。据报道，当前官方支持 Apple Silicon 后本地部署门槛降低，具体在 Apple Silicon 上的内存占用与性能未确认，需实测验证。

- **Cask**：官方渠道下载（cask 名称未确认，未检索到 homebrew-cask 收录）
- **价值判断**：本地大模型推理场景的新选项，对已有 Ollama/LM Studio 的机器可作对照，暂不替换。
- **与台账关联**：台账 p14 已有 Ollama 与 LM Studio，mini 无本地推理工具；如有需要可先在 mini 测试。
- **来源等级**：media
- **来源名称**：小众软件

### 2. Typora 2.0 预告发布，V1 可免费升级

小众软件报道 Typora 发布了 2.0 预告：经典 Markdown 编辑器即将更新，官方页面确认 V1 可免费升级至 V2。新版将支持 Markdown 相关增强功能，具体清单以预告页为准。台账中 marktext 已停更，Typora 当前以手动方式安装在 mini，属于主力 Markdown 编辑器。

- **Cask**：`typora`（cask 存在，当前版本 1.14.10 auto_updates；2.0 是否通过 cask 更新未确认）
- **价值判断**：现有工具大版本升级，免费迁移路径明确，值得跟进安装验证。
- **与台账关联**：mini 已有 Typora 手动安装；2.0 可用后应通过 cask 收编并三机拉取。
- **来源等级**：media
- **来源名称**：小众软件

### 3. Karakeep 0.34 发布，网页抓取与离线阅读增强

小众软件报道开源网络书签工具 Karakeep（GitHub 约 29700 星）于 2026-10-18 发布 v0.34.0：改进网页抓取能力、支持移动端自动离线阅读、降低服务器内存占用。Stars 高代表短期热度，不代表部署成熟度；未确认具体 license 与自托管门槛。

- **Cask**：无（brew 检索无同名 cask，需自托管或手动安装）
- **价值判断**：网络书签/资料收集工具，与现有 Obsidian 工作流方向不同，可跟踪。
- **与台账关联**：台账无对应项；Obsidian 为现有知识管理主力，Karakeep 属可选补充。
- **来源等级**：media
- **来源名称**：小众软件

### 4. Spacebar 发布，Finder 内预览 sqlite/geojson/ipynb 等格式

HN Show HN 出现 Spacebar：在 Finder 内预览 .sqlite3、.geojson、.ipynb 等格式。1 分/0 评，属早期项目，功能稳定性未确认，无 cask 收录。

- **Cask**：无
- **价值判断**：数据库与 notebook 文件的 Finder 预览需求较细分，价值待观察。
- **与台账关联**：台账 DBX 覆盖数据库管理，Shottr/Kap 覆盖截图，无 Finder 文件预览工具；重叠低。
- **来源等级**：community
- **来源名称**：Hacker News

### 5. Mac.apk：Android 应用 macOS 原生运行

HN 首页 241 分：Mac.apk 项目实现 Android 应用在 macOS 原生运行（GitHub 开源）。未确认是否稳定可用、支持应用范围及性能；属于生态实验阶段。

- **Cask**：无
- **价值判断**：方向有趣但工程成熟度未确认，仅跟踪。
- **与台账关联**：台账中 Windows App / Microsoft Remote Desktop 覆盖 Windows 远控，Android 无对应需求；不收编。
- **来源等级**：community
- **来源名称**：Hacker News

### 6. Craig：并行运行 coding agent 的 TUI

HN Show HN 的 Craig（craig-cli.com）：终端 UI 并行运行多个 coding agent，3 分/2 评。早期项目，无 cask，许可与稳定程度未确认。

- **Cask**：无
- **价值判断**：coding agent 编排方向有潜力，当前热度极低，先收藏观察。
- **与台账关联**：台账已有 Claude/Codex 等 coding agent 单点工具，编排工具可作为下一轮观察项。
- **来源等级**：community
- **来源名称**：Hacker News
