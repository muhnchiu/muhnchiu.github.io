## 今日最值得关注

### 1. QNAP Plex2Shell漏洞链：运行Plex的NAS正被黑客利用

小众软件 11 月 10 日报道，QNAP 于 11 月 6 日发布安全公告，称黑客正在利用名为 Plex2Shell 的漏洞链攻击运行 Plex Media Server 的 NAS 设备，已有设备疑似遭入侵。漏洞涉及运行 Plex Media Server 的 QNAP NAS，具体影响范围和修复方案待 QNAP 官方公告确认。台账中无 Plex 条目，三机软件基线不含 NAS 相关工具，但内网公司专用工具清单中未提及 Plex，需确认团队 NAS 环境是否受影响。

- **Cask**：无（NAS 安全事件，不涉及 macOS cask）
- **价值判断**：高危安全事件，QNXAS 用户需立即确认是否受影响并应用补丁。
- **与台账关联**：台账中无 Plex / QNAP 条目；若团队 NAS 运行 Plex，需确认该环境是否已应用 QNAP 官方修复。
- **来源等级**：media
- **来源名称**：小众软件（报道），修复状态待 QNAP 官方确认

### 2. Claude Fable 5.2 / Mythos 5.2 发布，据报道获 Artificial Analysis 65 分

Anthropic 官方发布 Claude Fable 5.2 和 Mythos 5.2（HN 859 分 / 517 评）。Artificial Analysis 数据（HN 256 分）称 Claude Fable 5.2 得 65 分，为该模型系列最高记录。两模型具体能力差异和性能基准数据待官方完整文档确认。

- **Cask**：无（Claude 为手动装 app，台账 mini 在用；Claude Code 生态与台账 Claude 条目相关）
- **价值判断**：Anthropic 新模型发布，对使用 Claude 生态的用户值得关注，具体能力提升待官方确认。
- **与台账关联**：台账中 Claude（手动，mini 在用）和 Claude Code URL Handler 均与 Claude 生态相关。
- **来源等级**：official
- **来源名称**：Anthropic（官方发布）；Artificial Analysis（性能数据为第三方评估）

### 3. Claude Opus 5.5 据报道推理模式 11 月 3 日变更，社区讨论是否"降权"

HN 高分文章（722 分 / 468 评）指 Anthropic Opus 5.5 在 11 月 3 日推理模式发生变化，社区讨论该变更是否属于性能调整。变更具体内容、官方说明和实际影响待 Anthropic 确认。

- **Cask**：无（模型服务端变更，不涉及本地 cask）
- **价值判断**：模型行为变更待官方确认，使用 Claude Opus 的用户可观察实际效果。
- **与台账关联**：台账中 Claude（手动，mini 在用），变更影响 Claude 生态用户。
- **来源等级**：community
- **来源名称**：Hacker News（社区讨论）

### 4. Itsycal 0.28.0：菜单栏日历新增苹果提醒事项支持

Itsycal 0.28.0 发布，新增对苹果 Reminders 的支持，菜单栏日历可同时显示日程和待办事项。Itsycal 为经典 macOS 免费菜单栏日历工具，功能轻量。台账中无 Itsycal 条目，三台 Mac 均未安装；若需菜单栏待办展示，可考虑试用，但与 Alfred 5（已装）部分功能重叠。

- **Cask**：`itsycal`（brew search 确认可用）
- **价值判断**：轻量免费，新增强待办展示有价值，但与 Alfred 5 部分功能重叠，暂不需收编。
- **与台账关联**：台账中无 Itsycal；与 Alfred 5（手动，三台在用）功能部分重叠（待办提醒）。
- **来源等级**：media
- **来源名称**：小众软件（报道）
