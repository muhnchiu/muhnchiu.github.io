## 今日最值得关注

### 1. eMudhra 证书链风险：Apple git 与 Cloudflare Tunnel 均受波及

- HN 首页显示 "Apple's git still trusts the compromised eMudhra certificates"（1025分/375评），指向 emudhra.we-have-a-problem.com/apple.html；小众软件同日报道 Cloudflare 紧急通知 Tunnel 用户尽快升级 cloudflared，原因是旧版仍信任 eMudhra 颁发的 4 张证书，存在 MITM 风险。
- 这与台账 ③ 网络安全类的 cloudflared（core 声明）直接相关；Apple git 的影响范围待确认（未确认是否影响 Xcode CLT 日常操作）。
- Cask：`cloudflared`（core 已声明；需确认版本并升级）
- 价值判断：安全事件，优先级高于常规更新。
- 与台账关联：`cloudflared` 在 core；若本地已装需立即升级并验证证书链。
- 来源等级：media
- 来源名称：HN + 小众软件
- 说明：媒体报道与社区讨论，需以 Apple / Cloudflare 官方通告为准；当前未确认官方影响清单。

### 2. Ghostty 1.4 发布

- Ghostty 官方 release notes（https://ghostty.org/docs/install/release-notes/1-4-0），HN 1292分/412评。
- 台账 ① 开发工具中 `ghostty` 为 mini/p13 手动装（待收编）、p14 cask 在用；这是主力终端升级，应验证后收编。
- Cask：`ghostty`
- 价值判断：主力终端版本升级，低风险，建议先在 mini 测试。
- 与台账关联：p14 已 cask 装；mini/p13 手动装待 `brew install --cask --adopt ghostty` 收编。
- 来源等级：official
- 来源名称：Ghostty

### 3. 微软 Authenticator 高危漏洞（CVE-2026-80097）

- 小众软件报道：Microsoft Authenticator Android 版被发现高危漏洞（CVSS 8.6），恶意 App 无需系统权限即可窃取已登录微软账户令牌。
- 台账无该应用；若使用 Microsoft Authenticator（macOS/Android）需关注；Windows App（mas，台账 ③）是否为同一认证链未确认。
- Cask：无
- 价值判断：安全事件，影响范围未确认；若三机使用相关 MFA 客户端，应立即检查更新。
- 来源等级：media
- 来源名称：小众软件
- 说明：CVE 编号需以微软官方通告为准；未确认 macOS 端是否同样受影响。

### 4. Strata 0.2.7.1 发布

- 小众软件报道：Strata 0.2.7.1 支持 12GB 及以下显存加速、NVIDIA DGX Spark；DeepSeek-V4.1-Flash 可在 Apple 芯片 Mac 上运行。
- 台账无 Strata；与 Ollama / LM Studio 等本地推理工具同生态，但 Strata 侧重 GPU 加速与代码生成。
- Cask：无（当前未确认官方 cask；需以官网为准）
- 价值判断：本地推理性能优化，适合有 GPU 或 Apple Silicon 的用户测试；与台账 Ollama（p14 手动）功能重叠但路线不同。
- 来源等级：media
- 来源名称：小众软件
- 说明：性能提升数据来自媒体转述，未确认官方 benchmark。
