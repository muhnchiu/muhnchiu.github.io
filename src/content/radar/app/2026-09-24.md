## 今日最值得关注

### 1. HTTPS Capture 终身限免

小众软件报道，HTTPS Capture 是一款支持 iPhone、iPad 和 Mac 的抓包与 API 调试工具，目前在 App Store 限时终身免费，但未上架国区。功能包括 HTTPS 解密、局域网抓包、API 调试、URL 重写、JS 脚本、Mock、Hosts、断点调试等。

- **Cask**：无（App Store 应用）
- **价值判断**：据报道限时终身免费，跨 Apple 平台抓包能力完整，适合作为备用工具领取。
- **与台账关联**：与台账中 Proxyman（mini+p13，在用）功能高度重叠，可作为轻量备选。
- **来源等级**：media
- **来源名称**：小众软件

### 2. Radicle 网络协议漏洞披露

Radicle 官方博客发布安全公告，披露其点对点代码协作网络协议中存在漏洞。Radicle 是基于 Git 的去中心化代码协作平台，在 HN 获得 116 分/45 评讨论。

- **Cask**：无（可通过 cargo 安装 radicle-cli）
- **价值判断**：官方安全公告，使用 Radicle 的开发者应及时更新。
- **与台账关联**：台账中无 Radicle，但安全公告值得开发者关注。
- **来源等级**：official
- **来源名称**：Radicle 官方博客

### 3. AI 编程助手遥测读取 AGENTS.md 争议已修复

HN 讨论揭露某 AI 编程助手读取 AGENTS.md 文件的行为与遥测开关关联，引发隐私争议。该问题已在最新版本中修复，HN 获得 440 分/250 评。

- **Cask**：无
- **价值判断**：已修复的隐私问题，使用相关 AI 编程工具的开发者应了解此事件。
- **与台账关联**：台账中 AI 助手类应用（手动安装，在用），相关工具用户需留意。
- **来源等级**：community
- **来源名称**：Hacker News

### 4. Atuin - Shell 命令历史搜索与同步

Atuin 是一款开源命令行工具，提供 shell 命令历史的搜索、同步和管理功能。小众软件在 GitHub 免费工具合集中推荐，支持多设备同步。基于 Rust 构建，使用 SQLite 存储历史记录。

- **Cask**：`atuin`（formula）和 `atuin-desktop`（cask，GUI 版）
- **价值判断**：开源免费，brew 可装，命令行效率增强工具有实际价值。
- **与台账关联**：台账中无直接重叠，与现有命令行工具链互补。
- **来源等级**：ecosystem
- **来源名称**：小众软件 / GitHub

Tailscale 官方博客发布文章说明其性能优化措施，涉及连接建立、数据传输等方面的改进。Tailscale 是台账中已登记的组网工具。

- **Cask**：`tailscale-app`（已装，core）
- **价值判断**：官方技术文章，了解已装工具的性能改进方向，无需额外操作。
- **与台账关联**：台账中 Tailscale（core，在用），直接相关。
- **来源等级**：official
- **来源名称**：Tailscale 官方博客
