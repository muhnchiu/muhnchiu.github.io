## 今日最值得关注

### 1. scrcpy 5.0 新增硬件解码

安卓投屏工具 scrcpy 5.0 正式发布，新增硬件解码功能，手机画面传到电脑后可直接交给显卡处理，CPU 占用最高降低约 10 倍，功耗也随之下降。硬件解码默认开启，升级后直接生效。据小众软件报道，该版本为重大更新。

- **Cask**：`scrcpy`（formula，非 cask；brew install scrcpy 直装）
- **价值判断**：硬件解码是质变级改进，对经常投屏开发的场景价值显著。
- **与台账关联**：台账无安卓投屏工具，不冲突，可直接安装。
- **来源等级**：official
- **来源名称**：小众软件 / GitHub

### 2. Docker Agent 官方项目

Docker 官方 GitHub 仓库 docker/docker-agent 出现在 HN 首页（172 分），表明 Docker 正式推出了 Agent 相关工具。具体功能细节待确认，但从官方仓库和社区讨论热度看，这是 Docker 生态的一个重要新项目。

- **Cask**：无（GitHub 项目，无 cask）
- **价值判断**：Docker 官方出品，开发者工具链潜在变化，值得跟踪。
- **与台账关联**：台账无容器管理工具（Docker Desktop 未在台账），需观察是否影响现有工作流。
- **来源等级**：official
- **来源名称**：Hacker News / GitHub

### 3. Snow Shot 开源截图工具

社区驱动的开源截图工具 Snow Shot，由社区共同开发，拥有完善的截图功能并通过插件系统保持应用简洁。据开发者自荐于小众软件论坛，强调社区反馈驱动迭代。当前已具备标注、贴图、滚动截图等常用功能。

- **Cask**：无（社区开发，无 cask）
- **价值判断**：开源免费，插件架构有扩展潜力，可与 Shottr 对比试用。
- **与台账关联**：与台账中 Shottr（截图）功能重叠，可做对比评估。
- **来源等级**：community
- **来源名称**：小众软件论坛

### 4. Convkit 离线文件转换 CLI

Convkit 是一个命令行文件转换工具，支持图片、视频、文档的离线批量转换，由 HN Show HN 发布。开源项目，无需联网，适合自动化脚本集成和隐私敏感场景。

- **Cask**：无（GitHub 项目，无 cask）
- **价值判断**：离线批量转换实用，CLI 可融入自动化工作流。
- **与台账关联**：台账无文件转换工具，不冲突。
- **来源等级**：community
- **来源名称**：Hacker News

### 5. 2Do 新版完全重构

据少数派详解报道，经典任务管理软件 2Do 完成完全重构，新版从界面到交互逻辑全面重做。报道评价为"心目中最佳的任务管理工具"。支持多平台同步，功能包括智能列表、标签、子任务等。

- **Cask**：无（App Store 发行，无 brew cask）
- **价值判断**：老牌工具重构，功能成熟，适合需要结构化任务管理的场景。
- **与台账关联**：台账无任务管理工具，不冲突。
- **来源等级**：media
- **来源名称**：少数派

### 6. Vaultwarden + Keyguard 自托管密码管理

少数派分享了基于 Vaultwarden 和 Keyguard 的自托管密码管理实践。Vaultwarden 是 Bitwarden 服务端的开源实现，Keyguard 是跨平台客户端。组合方案可完全自托管密码数据，适合注重隐私的用户。

- **Cask**：无（Vaultwarden 为服务端部署，Keyguard 为 Android 客户端）
- **价值判断**：自托管方案数据可控，但需运维成本，适合特定需求。
- **与台账关联**：台账无密码管理工具，不冲突。
- **来源等级**：media
- **来源名称**：少数派

### 7. RemoveMacAI 精简 macOS 27

小众软件报道，RemoveMacAI 是开源工具，可一键关闭 Apple 智能、删除已下载的模型文件并阻止再次下载，部分设备可释放超过 10GB 磁盘空间。macOS 27 有一定几率自动下载 Apple 智能相关大模型文件，无论是否开启。

- **Cask**：无（GitHub 工具，无 cask）
- **价值判断**：磁盘空间回收实用，但涉及系统文件操作需谨慎。
- **与台账关联**：台账无同类系统清理工具（CleanMyMac 侧重通用清理）。
- **来源等级**：media
- **来源名称**：小众软件

### 8. TraceUX 自托管会话回放

TraceUX 是用 Go 编写的自托管会话回放工具，单个二进制文件即可部署，出现在 HN Show HN。适合 Web 应用开发者进行用户行为分析和调试。

- **Cask**：无（GitHub 项目，无 cask）
- **价值判断**：单二进制部署轻量，但当前开发流程无会话回放需求。
- **与台账关联**：台账无会话回放工具，不冲突。
- **来源等级**：community
- **来源名称**：Hacker News
