## 今日最值得关注

### 1. Telegram Desktop 一键文件窃取漏洞披露

安全研究者披露 Telegram Desktop 存在允许任意用户文件被窃取的漏洞，HN 讨论 401 分 / 255 评论。官方修复与版本发布状态待确认。

- **Cask**：无（台账未装 Telegram，未做 cask 验证）
- **价值判断**：跨平台 IM 桌面端的高危漏洞披露，属今日最高关注度的安全信号；但与自身环境无直接交集。
- **与台账关联**：台账协作通信类无 Telegram，三机均未安装，无直接暴露面；若日后收编需先确认修复版本。
- **来源等级**：community
- **来源名称**：Hacker News（研究者博客 beaksec 披露文）

### 2. FSearch for macOS：开源全盘文件搜索工具

小众软件报道 Railway 工程师发布的 macOS 全盘文件搜索工具 FSearch，宣称比 Finder 快 17000 倍（宣传口径，未实测确认）。开源免费，brew search 无同名官方 cask，需从项目仓库安装。

- **Cask**：无（brew search 无精确匹配，GitHub 项目分发）
- **价值判断**：若速度宣称属实可补足 Spotlight 结构化全盘搜索短板；"17000 倍"为宣传数字，待实测。
- **与台账关联**：台账效率系统类无专门全盘搜索工具（当前依赖系统 Spotlight），属功能空白位。
- **来源等级**：media
- **来源名称**：小众软件

### 3. RemoveMacAI：关闭 Apple 智能并删除模型文件

开源小工具，一键关闭 Apple 智能、删除已下载的模型文件并阻止再次下载，据小众软件报道部分设备可释放超 10GB 磁盘。当前环境为 macOS 27，存在系统自动预下载模型文件的可能，工具与平台版本相关，效果未确认。

- **Cask**：无（GitHub 开源项目，brew search 无匹配）
- **价值判断**：磁盘空间优化向工具；涉及删除系统模型文件与关闭系统功能，需先确认副作用与可逆性再决定是否使用。
- **与台账关联**：台账清理类为 CleanMyMac X / DaisyDisk，均不覆盖 AI 模型文件场景，属互补而非替代。
- **来源等级**：media
- **来源名称**：小众软件

### 4. REA Reverse：浏览器内逆向工程工具

HN 首页 689 分 / 300 评论热帖，宣称可在浏览器中对任意目标做逆向工程分析，无需本地环境。免费额度与许可证细节未确认。

- **Cask**：无（Web 工具）
- **价值判断**：开发者学习与二进制分析场景的新形态工具，热度高但项目成熟度未确认；浏览器内即开即用，试错成本低。
- **与台账关联**：台账开发工具类无逆向工程工具，属空白位；无安装负担。
- **来源等级**：community
- **来源名称**：Hacker News

### 5. Talorys：Cloudflare 免费额度上的自托管个人 AI Agent

开源项目，HN 首页 235 分 / 119 评论，主打在 Cloudflare 免费额度上运行自托管个人 AI Agent。架构细节与许可证未在抓取数据中确认。

- **Cask**：无（自托管服务，非桌面应用）
- **价值判断**：零成本自托管 Agent 的参考实现，对个人基础设施设计有借鉴价值；直接部署价值待评估。
- **与台账关联**：台账 AI 类为 ChatGPT / Claude 桌面客户端，自托管 Agent 属新场景，无重叠。
- **来源等级**：community
- **来源名称**：Hacker News（GitHub 项目 rociiu/talorys）

### 6. Microsoft Execution Containers 1.0.0 正式发布

微软官方博客宣布 Mxc（Microsoft Execution Containers）1.0.0，面向 AI Agent 的策略驱动容器化隔离，Windows 平台专属。

- **Cask**：无（Windows 平台）
- **价值判断**：AI Agent 沙箱隔离的官方方案落地，隔离思路值得跟踪；平台不适用，仅作方向观察。
- **与台账关联**：无直接交集（Windows 平台），不涉及三机安装。
- **来源等级**：official
- **来源名称**：Microsoft Windows Developer Blog

### 7. iTerm2 Buddy 自托管中继服务器

小众软件介绍 iTerm2 Buddy（iTerm2 官方 iPhone 应用）支持自托管中继服务器，加速异地手机连回 Mac 终端的同步速度，替代默认公共中继。

- **Cask**：无（iTerm2 生态配套，非独立应用）
- **价值判断**：iTerm2 生态的能力延伸，异地运维场景实用；属配置教程而非新装软件。
- **与台账关联**：iTerm2 三机在用（台账开发工具类），属现有工具的配套增强。
- **来源等级**：media
- **来源名称**：小众软件

### 8. Anyway.Fonts：更适合中文的字体预览工具

少数派 App+1 栏目推荐的字体预览工具，主打"所得即所见"与中文场景优化。开源与许可证状态未确认。

- **Cask**：无（brew search anyway-fonts 无匹配）
- **价值判断**：中文字体预览小工具，设计场景可选；非刚需，先记录。
- **与台账关联**：台账无字体管理/预览工具，属空白位，暂无对应需求方。
- **来源等级**：media
- **来源名称**：少数派
