## AI 编程工具更新

Claude Code（anthropics/claude-code）近 7 天有三个 release：

- **v2.1.325（2026-11-13）**：修复 zstd 压缩响应解码安全漏洞；修复 subagent 模型切换、worktree 中 git 命令、session 恢复等多个稳定性问题；新增 Notebook cell 重运行提示、组织策略阻止请求时的说明等。
- **v2.1.323（2026-11-12）**：新增 Code Mode 实验特性（Claude 写 JavaScript 调用工具）；新增 plugin.json 版本范围检查、TypeScript hooks 类型检查、`CLAUDE_CODE_AUTO_MODE_MODEL` 支持、hooks 长任务 30 秒心跳等；修复 `/compact` 误删未回答消息、大文件编辑内存尖峰、worktree 路径错误等多个问题。
- **v2.1.322（2026-11-10）**：在 Vertex 全球、us、eu 区域新增 fast mode。

Cursor（getcursor/cursor）与 OpenAI Copilot（openai/openai-copilot）在抓取范围内无 releases 记录。
