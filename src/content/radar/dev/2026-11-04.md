### 3. Balanov/uncut 无头 coding agent 静态二进制

Go 语言编写的 7MB 静态二进制，描述为"lossless, headless coding agent harness"，支持本地优先（local-first）运行，可接任意模型、MCP 和 Agent Skills。同类项目还有作者的另一作品 Balanov/shim（432 stars，tiny local-first AI harness）。592 stars 短期热度明显，项目实际能力与成熟度未确认。

- **类型**：CLI / 本地 AI harness
- **价值判断**：单二进制 + local-first 的定位对离线/隐私敏感场景有吸引力
- **与当前栈关联**：可作为本地 AI coding 备选工具了解
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending
