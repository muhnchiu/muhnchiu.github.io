## 今日最值得关注

### 1. CVE-2026-109618/109619 PHP session.upload_progress 漏洞与 PoC 扩散

近 7 天 GitHub 上出现至少 5 个与 CVE-2026-109618/109619（PHP session.upload_progress）相关的仓库，包括 PoC（ikow/php2shell-poc，938 stars）、shell 版 PoC（eness/php2shell-CVE-2026-109618-CVE-2026-109619-PoC，577 stars）、ASLR bypass 利用（9bie/php2shell-bypass-aslr-exp，438 stars）以及官方检查工具（openai/php2shell-checker，379 stars）。漏洞涉及可上传恶意 PHP 会话文件的攻击面，PoC 密集出现说明利用研究活跃，具体影响面和官方补丁状态待确认。

- **类型**：安全漏洞 PoC / CLI 检查工具
- **价值判断**：若当前技术栈使用 PHP 且存在文件上传入口，应立即核查受影响版本
- **与当前栈关联**：当前开发工具链无 PHP 依赖，但涉及 PHP 服务的协作环境需排查
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending
- **来源 URL**：https://github.com/ikow/php2shell-poc

### 2. Claude Code 连发 v2.1.305-307，新增安全事件遥测

官方 Releases 显示 10 月 20-21 日连发三个版本。v2.1.307 新增 `/claude-api api-version` 与 `claude_code.safety_event` OpenTelemetry 事件（记录工具调用被权限规则/auto 模式/安全检查/hook/沙箱拦截的事件）；v2.1.305 新增 `sandbox.allowNestedUserNamespaces`（Linux 沙箱内命令可创建用户命名空间以绕过沙箱文件保护，如 Chromium、rootless podman）与无人值守重试模式的 watchdog 参数；v2.1.306 修复云端会话下 `claude -p` 报 "Not logged in" 及多 MCP 工具会话中 API 错误被替换为 "prompt is too long" 的问题。

- **类型**：AI 编程工具
- **价值判断**：安全遥测与沙箱行为变更直接影响 Agent 工具调用的可观测性与隔离强度，当前使用者应升级并核实行为
- **与当前栈关联**：当前 AI Coding 工作流核心依赖该工具
- **来源等级**：official
- **来源名称**：GitHub Releases (anthropics/claude-code)
- **来源 URL**：https://github.com/anthropics/claude-code/releases
