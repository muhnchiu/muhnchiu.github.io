## 今日最值得关注

### 1. Claude Code v2.1.299 / v2.1.300 官方 Release

anthropics/claude-code 于 2026-10-14 连续发布两个版本（v2.1.299 与 v2.1.300），官方 Release 说明可查证。v2.1.299 新增 idle compaction：200K+ token 的终端会话闲置约 54 分钟后自动压缩，避免一小时 prompt cache 过期后重新处理全部上下文，可通过 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 调阈值。v2.1.300 面向 mod 体系：prompt 装饰的 virtualText、OpenTelemetry api_request 事件拆分 5m/1h 缓存写入指标、mod 的 $.ui.view({ agentId }) 查看 agent 转录、/advisor 命令（AWS Claude Platform，可经 advisorModel、--advisor 或 CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1 控制）。属于当前 AI Coding 工作流核心工具的官方演进。

- **类型**：AI 编程工具
- **价值判断**：官方核心工具两个版本的连续迭代，idle compaction 与 mod/可观测性扩展直接影响长会话成本与扩展开发
- **与当前栈关联**：当前 AI Coding 工作流的核心工具之一，建议升级到 v2.1.300 并留意 idle compaction 行为
- **来源等级**：official
- **来源名称**：GitHub Releases (anthropics/claude-code)
