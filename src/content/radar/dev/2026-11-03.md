## 今日最值得关注

### 1. MiniMax mcode-stack：MiniMax Code 官方工作流开源

MiniMax-AI 组织于 2026-10-28 开源 mcode-stack（MIT 许可，创建 6 天获 513 stars，当前为 513）。这是 MiniMax Code 团队自身构建 MiniMax Code 所用的工作流与技能集合，官方描述为"Open source, install and use"。对正在使用 AI coding 工作流的开发者，直接安装并对照自身工作流做差异比较是有价值的。

- **类型**：AI 编程工具（工作流/技能集）

### 2. Claude Code v2.1.316 及近三日连续版本发布

anthropics/claude-code 官方 Release 于 10-27 至 10-31 连发三个版本（v2.1.312 / v2.1.314 / v2.1.316）。v2.1.316 新增 `CLAUDE_CODE_DISABLE_ULTRATHINK`（关闭 ultrathink 关键词）、Claude apps gateway 的 `pooled_budget` 组月度预算、内网 CA 场景的 `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP`、以及 `CLAUDE_CODE_SUBAGENT_EFFORT`。v2.1.314 引入 `permissions.blockWritesOutsideWorkingDirectories`（所有权限模式下拒绝工作目录外的写/编辑/notebook 操作）。

- **类型**：AI 编程工具
- **价值判断**：权限模型收紧是安全正向变更，建议升级到最新
- **与当前栈关联**：直接服务于当前 AI Coding 工作流，建议验证 `blockWritesOutsideWorkingDirectories` 是否影响现有脚本
- **来源等级**：official（GitHub 官方 Release）
- **来源名称**：GitHub Releases（anthropics/claude-code）

## AI 编程工具更新

**Claude Code（anthropics/claude-code）**：10 月 27 日至 31 日连发三版：

- **v2.1.312（10-27）**：新增 `oidc.user_id_claim`（支持 Microsoft Entra ID 的 `oid` claim）；VS Code 扩展中登录后 managed settings 获取修复；修复大 CLAUDE.md/rule 文件被覆写问题
- **v2.1.314（10-30）**：新增 `permissions.blockWritesOutsideWorkingDirectories`——所有权限模式下拒绝工作目录外的 Write/Edit/NotebookEdit；Claude apps gateway 上游支持 `groups` IdP 列表；Bedrock 上游 `guardrail_trace` 日志（记录触发的 guardrail 过滤器，不记录匹配文本）
- **v2.1.316（10-31）**：新增 `CLAUDE_CODE_DISABLE_ULTRATHINK`；gateway 新增 `pooled_budget` 组月度预算；`CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP`（内网 CA 场景）；`CLAUDE_CODE_SUBAGENT_EFFORT`（子代理 effort 控制）
