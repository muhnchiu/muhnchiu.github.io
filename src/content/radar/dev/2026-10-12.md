## 今日最值得关注

### 1. agenvo：自托管 MCP 中继（Xuanwo/agenvo）

为原生编码运行时提供自托管 MCP（Model Context Protocol）中继。多个编码 agent 运行环境可以经由同一个中继点共享工具接入，而不必在每台机器上重复配置。近 7 天 125 stars。成熟度与生产可用性未确认，需阅读仓库文档自行评估。

- **类型**：开发者工具（自托管服务）
- **价值判断**：把 MCP 接入从逐机配置收敛为单点中继，直击多机环境下工具链不一致的痛点
- **与当前栈关联**：当前多机开发环境同样面临 MCP 配置同步成本，思路值得直接实测
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending

### 2. effortless：编码 agent CLI 自动推理档位 mod（HeyCubit/effortless）

面向主流编码 agent CLI 的第三方 mod：为每个 prompt 自动选择推理强度档位并显示当前选择，目标是简单任务不过度推理、复杂任务不欠推理。近 7 天 127 stars。

- **类型**：extension（第三方 mod）
- **价值判断**：推理档位是 agent 使用成本的最大变量之一，自动选择有真实价值；第三方 mod 稳定性待验证
- **与当前栈关联**：若实测有效，可直接压低当前 AI Coding 工作流的日常推理开销
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending

### 3. Agent 执行安全工具在 Hacker News 集中曝光（DeadBolt / Tracon / Plimsoll / Cordium）

同一批 Show HN 中出现多个"agent 执行边界"方向的项目：DeadBolt 做本地 agent 工具调用执行门，Tracon 做 subagent 调度（自称 subagent 的空中交通管制），Plimsoll 与 Cordium 提供自托管沙箱运行 agent 生成代码，后者对标 Codespaces/E2B/Daytona。需要强调：各条目热度都很低（1-3 分、0-1 评），属早期曝光而非社区共识。

- **类型**：AI 编程工具（沙箱与调度）
- **价值判断**：方向契合"让 agent 放心执行代码"的长期需求，但单点热度与完成度均不足
- **与当前栈关联**：agent 执行隔离是当前 AI Coding 工作流的持续关注点，保持跟踪即可
- **来源等级**：community
- **来源名称**：Hacker News

### 4. DigUp：macOS 本地文件内容搜索（ARahim3/DigUp）

按内容检索 Mac 上的照片、PDF、录音、视频等文件。近 7 天 993 stars，是本期榜单中星标最高的效率类项目。索引性能与隐私处理方式未确认，仓库描述未说明是否完全本地运行。

- **类型**：开发者工具（macOS 桌面应用）
- **价值判断**：本地内容检索实用价值明确，但实现细节与数据安全未确认，试用前需自查
- **与当前栈关联**：macOS 日常工具链候补项，与编码工作流无直接耦合
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending

### 5. big-arrow-on-the-screen：agent 屏幕标注（franzenzenhofer/big-arrow-on-the-screen）

让 AI agent 直接在 Mac 屏幕上绘制大箭头、方框和文字。把 agent 输出从文本终端扩展到屏幕可视化，可用于演示与调试 agent 行为。近 7 天 625 stars。

- **类型**：AI 编程工具周边（可视化）
- **价值判断**：趣味性大于实用性，但"agent 输出上屏"的思路有启发；实际场景未确认
- **与当前栈关联**：仅在 macOS 与 agent 工作流组合下有意义，观察向
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending

### 6. ai-promo-video-maker：编码 agent 做非编码任务（liyupi/ai-promo-video-maker）

把产品名或网址交给编码 agent（Cursor、Codex 等），由 agent 自行调研产品并产出宣传视频。近 7 天 139 stars。本质是"编码 agent 作为通用自动化引擎"的工作流示范。

- **类型**：AI 编程工作流示例
- **价值判断**：价值在 prompt 编排与任务分解思路，而非成品工具本身
- **与当前栈关联**：与当前 AI Coding 工作流的 agent 编排方法相通，可作参考实现
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending
