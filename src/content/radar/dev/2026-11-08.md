- **来源等级**：official
- **来源名称**：GitHub

### 2. devvm（项目级隔离虚拟机）

devvm 是 Go 语言开发的开发者工具，核心理念是"一个项目一台虚拟机"，为每个项目提供独立沙箱环境，附带项目所需工具链。当前 358 stars，处于上升期。

- **类型**：CLI
- **价值判断**：项目级隔离沙箱在 AI 编程 Agent 场景下价值高，可减少环境污染
- **与当前栈关联**：可替代或补充当前本地开发环境隔离方案
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending

### 3. terminal-mac（终端运行 macOS）

terminal-mac 是 Swift 语言项目，将完整 macOS 运行在终端中。当前 2241 stars，属于高热度项目，但"终端运行 macOS"的实现机制未确认（可能是模拟器、模拟器+终端 UI，或其他方案）。

- **类型**：CLI
- **价值判断**：star 数高，但实际可用性未确认，建议观察
- **与当前栈关联**：若实现可行，可为 CI/本地开发提供轻量 macOS 环境
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending

### 4. agent-autoloop（后台 Agent 自动跟进）

agent-autoloop 是 TypeScript 项目，让命令行 Agent 在后台自动接活、跟进任务，只在拿不准时发卡片给用户拍板。当前 3952 stars，是今日 GitHub Trending 中 star 数最高的开发者工具。

- **类型**：AI 编程工具
- **价值判断**：star 数高说明社区关注度高，"自动跟进+按需拍板"模式符合当前 AI Agent 工作流趋势
- **与当前栈关联**：与当前 AI Coding 工作流直接相关，可评估其 Agent 编排能力
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending

### 5. sandbox-mcp（Windows 临时沙箱 MCP）

sandbox-mcp 是 JavaScript MCP server，提供全新的一次性 Windows 机器用于测试应用。当前 263 stars，面向需要 Windows 测试环境但本地无 Windows 的开发者。

- **类型**：IDE 扩展 / MCP
- **价值判断**：MCP 生态持续扩展，跨平台沙箱需求明确，适合观察
- **与当前栈关联**：若当前工作流涉及 Windows 测试，可作为备选方案
- **来源等级**：ecosystem
- **来源名称**：GitHub Trending
