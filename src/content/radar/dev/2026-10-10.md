## 今日最值得关注

### 1. Leviathan（Rust，711 stars）

面向 Agent 的"深度记忆"库，用于在大数据集上为 Agent 提供长程记忆能力。连续第二日进入 GitHub 热门（昨日快照 695 stars，今日 711），是本周期与 AI Coding 工作流关联度最高的新项目。项目处于早期，成熟度未确认。

- **类型**：库（Rust）
- **价值判断**：Agent 长程记忆是当前 AI Coding 的核心痛点，连续两日热度说明方向受关注
- **与当前栈关联**：与当前 AI Coding 工作流的上下文与记忆管理直接相关
- **来源等级**：ecosystem
- **来源名称**：GitHub

### 2. big-arrow-on-the-screen（Swift，449 stars）

让 AI Agent 直接在 macOS 屏幕上绘制大箭头、方框和文字的小工具，用于 agent 在人机协作演示中指向屏幕元素进行讲解或标注。

- **类型**：桌面工具 / CLI
- **价值判断**：Agent 输出可视化的小切口，演示与讲解场景有用
- **与当前栈关联**：macOS 环境可用，可作为当前 AI Coding 工作流的演示辅助
- **来源等级**：ecosystem
- **来源名称**：GitHub

### 3. better-statusline（TypeScript，170 stars）

为 anthropics/claude-code 提供状态栏，以点阵风格展示会话数据。面向重度 CLI agent 用户的会话信息可视化。

- **类型**：IDE 扩展 / CLI 配套插件
- **价值判断**：轻量级会话状态可视化，锦上添花类工具
- **与当前栈关联**：与当前 AI Coding 工作流直接配套
- **来源等级**：ecosystem
- **来源名称**：GitHub

### 4. p3-stack（Shell，143 stars）

将 pstack 重构为面向 T3 Code 的工作流栈，覆盖子代理委派、worktree 线程与 PR 流程。方向是多 agent 并行开发的工程化编排。

- **类型**：CLI / 开发者工具
- **价值判断**：多 agent 并行加 worktree 隔离的工作流参考实现
- **与当前栈关联**：与当前 AI Coding 工作流的子代理与并行任务编排相关
- **来源等级**：ecosystem
- **来源名称**：GitHub

### 5. ai-data-extractor（Python，149 stars）

开源的 AI 编码助手聊天历史提取工具，支持多家助手的会话记录导出。从数据自主权角度，把 AI 编码会话历史转为本地可用格式，兼具备份与隐私用途。

- **类型**：CLI 工具
- **价值判断**：AI 编码会话数据的本地化导出，实用且门槛低
- **与当前栈关联**：当前 AI Coding 工作流的历史数据管理与备份
- **来源等级**：ecosystem
- **来源名称**：GitHub

### 6. SpecWeave 3（Show HN，3 分）

在 anthropics/claude-code、Codex 与 Grok 等编码工具之间交接编码任务的开源工具，属多工具协作与任务交接方向。社区早期项目，讨论极少，成熟度未确认。

- **类型**：AI 编程工具
- **价值判断**：跨工具任务交接思路值得关注，项目本身太早期
- **与当前栈关联**：与当前 AI Coding 工作流的多工具协作潜在相关
- **来源等级**：community
- **来源名称**：Hacker News（Show HN）

### 7. Memdebug（Show HN，1 分）

查看 AI Agent 记忆变更并支持撤销的调试工具。与 Leviathan 同属 agent 记忆赛道，聚焦记忆的可观测性与回滚，项目刚发布、热度极低。

- **类型**：开发者工具
- **价值判断**：agent 记忆调试是真实痛点，项目极早期，观察即可
- **与当前栈关联**：当前 AI Coding 工作流的 agent 记忆可观测性
- **来源等级**：community
- **来源名称**：Hacker News（Show HN）

### 8. Cordium（Show HN，2 分）

自托管沙箱平台，定位为 Codespaces/E2B/Daytona 的开源替代。为 coding agent 提供隔离执行环境是当前明确需求，但项目刚发布、社区反馈尚未形成，成熟度未确认。

- **类型**：开发者工具 / 平台
- **价值判断**：自托管沙箱替代方案，等待社区验证
- **与当前栈关联**：agent 沙箱执行环境的潜在备选
- **来源等级**：community
- **来源名称**：Hacker News（Show HN）

### 9. wp2shell（Python，178 stars）

组合 CVE-2026-63030 与 CVE-2026-60137 的 WordPress RCE 利用链公开 PoC。连续第二日出现在 GitHub 热门（昨日快照 143 stars，今日 178），提示相关漏洞的公开关注度在上升。利用代码细节属社区发布，未经官方确认。

- **类型**：安全 PoC 工具
- **价值判断**：对运行 WordPress 的站点是持续的风险信号，非日常效率工具
- **与当前栈关联**：仅当工作流涉及 WordPress 相关服务时需核对官方补丁状态
- **来源等级**：ecosystem
- **来源名称**：GitHub
