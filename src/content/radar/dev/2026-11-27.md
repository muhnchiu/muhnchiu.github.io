## 今日最值得关注

### 1. fast-anything：把 5% 慢函数移植到 Rust 并自动验证

EL4CTEO/fast-anything（Rust，MIT，当前 4229 stars，仓库创建于 2026-11-21）是一个性能移植工具：对 Python/Node/Ruby/Go 等应用做 profile，找出最慢的几个函数，只把这 5% 的热点移植到 Rust，通过记录真实调用（最多 500 次）并回放验证移植结果与原始一致后才启用，且可随时一键回退。支持 Claude Code / Codex 等 coding agent 直接执行移植（`--agent` 参数），也提供 MCP server 和 CLI。其验证机制会派生边界用例（NaN、空输入、超大输入）并用原始程序比对，性能没有收益的移植不会启用。

- **类型**：CLI
- **价值判断**：热点函数级移植比整体重写成本低得多，且带自动化正确性验证，思路扎实，值得在自有慢服务上小范围试验。
- **与当前栈关联**：当前开发工具链中的 Python/Node 脚本若存在明确热点函数，可作为可选优化手段；需要本机装有 Rust 工具链。
- **来源等级**：official
- **来源名称**：GitHub (EL4CTEO/fast-anything)

### 2. Claude Code v2.1.332：MCP skills 与 PreSkillShellCommand 钩子

官方 Release v2.1.332（2026-11-25）的主要变更：MCP server 提供的 skills 进入 beta（在 `/` 菜单中以 `server:skill` 显示）；新增 `PreSkillShellCommand` 钩子，可在 skill 或命令加载时拒绝其中的内联 shell 命令（旧版本上该设置文件会触发启动对话框）；新增 OpenTelemetry `assistant_response` 事件；修复了 compaction 死循环、hook 输出失控导致内存暴涨、SSE MCP 断流后拒绝所有工具调用等若干卡死/冻结问题。

- **类型**：AI 编程工具
- **价值判断**：无重大功能转向，但 PreSkillShellCommand 对当前 AI Coding 工作流的 skill 安全控制有意义，大量稳定性修复建议随手升级。
- **与当前栈关联**：当前 AI Coding 工作流直接依赖该类工具，升级后 skill 加载路径与钩子行为变化需要注意。
- **来源等级**：official
- **来源名称**：GitHub (anthropics/claude-code)

### 3. skill-distill：把好会话蒸馏成开源模型可复现的 skill

sybil-solutions/skill-distill（Python，MIT，当前 917 stars，仓库创建于 2026-11-21）解决一个问题：前沿模型做对的任务，开源权重模型在给定正确指令时能否同样做对。用法是在一次成功会话结束后调用该 skill（作为 Claude Code / Codex 的 teacher），它会在 tmux 中启动指定"student"（harness + 开源模型），自动循环：写 skill 给 student -> 比对 student 与参考输出 -> 定位第一处走偏并修正 -> 每个版本跑三次直到匹配，最后由人工验收。产出是可复用的 operator skill 和针对单任务/单模型的 produced skill。

- **类型**：开发者工具（skill 工程方法）
- **价值判断**：把"会话经验沉淀为可复用指令"做成了自动化闭环，思路有参考价值；实际效果取决于 student 模型能力，未实测。
- **与当前栈关联**：与当前 AI Coding 工作流中的 skill 积累习惯直接相关，可作为方法论参考而非立即工具。
- **来源等级**：official
- **来源名称**：GitHub (sybil-solutions/skill-distill)

### 4. deslop-please：架构整洁度 linter（深模块、窄接口）

deterministic-machines/deslop-please（Rust，MIT，当前 1151 stars，仓库创建于 2026-11-22）是一个以《A Philosophy of Software Design》为准则的架构 linter，检查"深模块、窄接口"，例如报出某结构体字段在模块外被多少处引用（field-leak）。支持 allow 文件抑制告警，有 TypeScript 社区移植版（基于 Oxc）。

- **类型**：CLI
- **价值判断**：把架构设计原则变成可执行的 lint 规则是少见尝试，报告风格激进（示例输出"65535 errors, well done!"），实际可用性未确认，建议先读设计文档再看是否值得试。
- **与当前栈关联**：当前项目若已用 eslint 等工具，可作为架构审查的补充视角；非必须引入。
- **来源等级**：official
- **来源名称**：GitHub (deterministic-machines/deslop-please)

### 5. KuroCat：开源 3D 桌面宠物 + AI coding companion

qianyiai/KuroCat（TypeScript，MIT，当前 1348 stars，仓库创建于 2026-11-21）是基于 Tauri v2 + Rust 的开源桌面打字猫（Bongo Cat 替代），带 MCP server，可作为 AI coding 会话的桌面伴侣/状态展示。另有 C++ 原生轻量版（chanke17/KuroCat，802 KB）和皮肤工坊仓库。

- **类型**：开发者工具（桌面宠物/氛围工具）
- **价值判断**：纯氛围向，对开发效率无实质贡献，但开源实现可作为 Tauri 桌面小工具的样例；娱乐属性。
- **与当前栈关联**：无直接工具链关联，仅供了解。
- **来源等级**：official
- **来源名称**：GitHub (qianyiai/KuroCat)

### 6. safe-anything：Rust 编写的漏洞扫描器

erkamyaman/safe-anything（Rust，MIT，当前 787 stars，仓库创建于 2026-11-22）是纯 Rust 实现的安全扫描工具，覆盖 XSS、SQL 注入、泄露密钥等常见漏洞类型。

- **类型**：开发者工具（安全扫描）
- **价值判断**：Rust 原生实现利于分发，但扫描准确率与误报率未确认，需对比现有安全工具后再判断价值。
- **与当前栈关联**：当前工具链已有常规安全审查流程，此工具属于可选补充。
- **来源等级**：official
- **来源名称**：GitHub (erkamyaman/safe-anything)
