## 今日最值得关注

### 1. Claude Code v2.1.330

Anthropic 于 2026-11-20 发布 v2.1.330，这是近 48 小时内第三个版本（v2.1.328、v2.1.329、v2.1.330），迭代节奏密集。本次更新重点包括：

- 企业级：新增对 Anthropic Enterprise Admin Console 管理组织的登录支持，登录后自动应用组织设置
- 新增 `easel` 内置模块，在 Pro/Max/Team/Enterprise 计划下于 macOS 和 Linux 自动绘制图表（MCP 指标结果）
- 大量 Bug 修复：包括长对话 compact 后冻结数分钟、WebFetch 卡死、`/rewind` 恢复错误文件版本、多进程并发写设置文件丢失等
- 自托管 Runner 改进：新增 `--start-dir` 参数、多项 metrics 指标、多项修复
- VS Code 扩展：新增 `/fork`、`/workflows`、`claudeCode.escapeStopsClaude` 和 `claudeCode.pinPrompt` 设置
- 修复了 `rm` 指向根目录等危险命令的审批机制
- 修复了 MCP 工具 schema 无效时导致 JSON 错误与会话文件膨胀的问题

- **类型**：AI 编程工具
- **价值判断**：企业部署团队应关注组织管理登录和 Runner 改进；日常用户可升级获取大量稳定性修复
- **与当前栈关联**：当前 AI Coding 工作流核心工具，升级可获得企业级功能与稳定性改善
- **来源等级**：official
- **来源名称**：GitHub anthropics/claude-code

### 2. rust-anything

erkamyaman 于 2026-11-16 创建、MIT 许可的 CLI 工具，用于将 TypeScript、Python、C、Go、Ruby、Java 应用逐步重写为 Rust。核心机制：

- 通过 `record` 命令录制原始程序的输入输出行为，重写后逐步对照验证
- 支持 FFI 桥接（N-API、PyO3）保留混合语言过渡期
- 已发布 10 个版本（v1.1.0 至 v2.1.0），活跃开发中，GitHub 6635 stars（创建仅 5 天）
- npm 包 `rust-anything` 已发布，MCP 服务器已注册至官方 MCP Registry（`io.github.erkamyaman/rust-anything`）
- v2.1.0 新增浮点容差比较、Kotlin/JVM 支持

- **类型**：CLI
- **价值判断**：自动化测试驱动的语言迁移工具，适合有明确 Rust 迁移需求的大型项目
- **与当前栈关联**：与当前开发工具链互补，可在评估 Rust 迁移时作为脚手架参考
- **来源等级**：official
- **来源名称**：GitHub erkamyaman/rust-anything

- CLI 优先设计，支持模板构建、agent webhooks
- 最新 release v0.6.0.50（2026-11-09），持续迭代中
- 社区 727 stars，创建时间 2025-12-09

- **类型**：AI 编程工具
- **价值判断**：开源 agent 基础设施，适合评估或自建 Devin 类工具的团队
- **与当前栈关联**：可作为 agent 会话管理的开源替代方案研究
- **来源等级**：ecosystem
- **来源名称**：Hacker News / GitHub diggerhq/opencomputer
