## 今日最值得关注

### 1. fast-anything

EL4CTEO/fast-anything（Rust，MIT，创建 2026-11-21，约 1886 stars，7 天内）。定位是"不要整体重写 Rust，只重写慢的 5%"：对 Python / Node / Ruby 应用做 profiling，识别热点函数，配合 coding agent 把热函数移植为 Rust，并验证移植前后行为一致。这与当前 AI coding 工作流直接相关——把"性能优化"从人工重写变成 agent 可执行、可验证的窄任务。

- **类型**：CLI / Rust 工具链
- **价值判断**：将性能移植限定在可验证的热点函数上，比"整个应用重写 Rust"类工具务实得多
- **与当前栈关联**：可作为 agent 驱动的性能优化辅助；移植行为一致性验证是关键卖点，需实际验证
- **来源等级**：ecosystem（GitHub 生态数据；官方 README 与实测待确认）
- **来源名称**：GitHub

### 2. agy-fast

INK-Q/agy-fast（TypeScript，MIT，创建 2026-11-19，约 511 stars）。非侵入式 MCP 加速插件，面向 Google Antigravity（CLI / Desktop / IDE），声称在不影响原生 UI 与 diff 的前提下降低约 34% LLM 轮次、31% token 配额消耗、40% 上传流量。这些数字为项目自述，未经独立验证，待确认。

- **类型**：developer-tool / MCP 插件
- **价值判断**：如果 token 削减属实，对高频调用 coding agent 的团队有直接成本价值；数字待确认
- **与当前栈关联**：MCP 插件生态扩展；当前 AI coding 工作流若使用 Antigravity 或 MCP 类工具链可试装评估
- **来源等级**：ecosystem（GitHub；性能数字为项目自述，未确认）
- **来源名称**：GitHub

### 3. skill-distill

sybil-solutions/skill-distill（Python，MIT，创建 2026-11-21，约 454 stars，4 天内）。将一次成功的 Claude Code / Codex 会话蒸馏为"开放式权重模型也能遵循的 skill"。这与把 agent 经验固化为可复用资产的方向一致——会话级上下文 → 结构化 skill 文件。

- **类型**：AI 编程工具 / Python CLI
- **价值判断**：直接服务于"把一次好的 agent 交互沉淀为可复用 skill"的场景，对维护 agent 工作流有价值
- **与当前栈关联**：与当前 AI coding 工作流中 skill 沉淀方式可直接对比；值得实际跑一次蒸馏流程验证输出质量
- **来源等级**：ecosystem（GitHub；输出质量待确认）
- **来源名称**：GitHub

### 4. PlanBridge

ContextBridge 团队开源（TypeScript，GitHub 仓库创建于 2026-04-29，约 31 stars），今日在 Hacker News 重新被讨论。CLI 工具，利用 coding agent 标准 hooks（Claude Code 的 ExitPlanMode、Codex 的 Stop hook）在 agent 产出计划时本地打开浏览器渲染 markdown，支持选中文本内联批注。完全本地运行，计划内容不发远端。HN 帖 4 分 0 评，社区验证度低。

- **类型**：CLI
- **价值判断**：解决"终端里 review agent 计划体验差"的痛点，思路清晰；项目尚小，成熟度未确认
- **与当前栈关联**：可直接集成到当前 AI coding 工作流的 plan review 环节；低分讨论，先观察
- **来源等级**：community（Hacker News 讨论 + GitHub）
- **来源名称**：Hacker News

### 5. WinRust

Lemxy/WinRust（Rust，Apache-2.0，创建 2026-11-17，约 1230 stars，6 天内）。Rust 实现的 Windows 系统组件：任务栏、文件管理器、NTFS 搜索等，替代 Windows shell 组件。与 macOS / Linux 开发者日常无关，主要作为"系统级组件用 Rust 重写"的参考样本。

- **类型**：CLI / 系统工具
- **价值判断**：短期热度高（7 天 1230 stars），但目标平台为 Windows，对当前开发工具链无直接价值
- **与当前栈关联**：无直接关联，仅作为 Rust 系统编程案例关注
- **来源等级**：ecosystem（GitHub 生态数据）
- **来源名称**：GitHub
