## 今日新发现

### 1. agent-browser (vercel-labs)

Vercel Labs 出品的浏览器自动化技能，Linkly Worth-Installing Score 80.8 排名第一，Skills.sh 24h Trending 第 29 位（10.4K）。该技能为 AI 代理提供浏览器操作能力，支持页面导航、元素交互、截图等操作。在 Linkly Top 100 中安装量达 1,028,776。

- **来源**：Skills.sh Trending / Linkly Top 100
- **价值判断**：Linkly 榜首，安装量百万级，生态成熟度高，浏览器自动化是当前 AI 工作链中常见缺失环节
- **与当前栈关联**：可补充当前 AI Coding 工具链在浏览器交互场景下的能力空白，适合 Web 前端测试、页面数据抓取等场景
- **来源等级**：ecosystem（vercel-labs 为 Vercel 官方实验室组织）
- **来源名称**：Skills.sh / Linkly

### 2. azure-diagnostics (microsoft)

微软官方 Azure 技能系列之一，Linkly Worth-Installing Score 59.7，安装量 619,786。该技能系列覆盖 Azure 诊断、部署、合规、AI、资源管理等场景，共 12+ 个子技能。在 OfficialSkills.sh 中被列为 Microsoft 官方发布。

- **来源**：Linkly Top 100 / OfficialSkills
- **价值判断**：官方发布，安装量六十万级，与现有 Azure 监控工作流直接相关
- **与当前栈关联**：当前 AI 工作流中有 Azure 告警监控需求，azure-diagnostics 可为 AI Coding 工具链提供 Azure 资源诊断的标准化程序知识
- **来源等级**：official（Microsoft 官方发布）
- **来源名称**：Linkly / OfficialSkills

### 3. self-improving-agent (pskoett)

ClawHub 社区技能，Linkly Worth-Installing Score 65，安装量 482,621。该技能使 AI 代理记录自身发现以实现自我改进，支持结构化记忆和经验积累。概念上与现有工作流中的记忆文件机制有相似之处。

- **来源**：Linkly Top 100 / ClawHub
- **价值判断**：安装量较高，自我改进机制是 agent 系统设计中有潜力的方向，但来自社区个人开发者，成熟度未确认
- **与当前栈关联**：当前 AI 工作流已有记忆文件机制（日志+长期记忆），该技能提供了另一种结构化自改进思路，可作为设计参考
- **来源等级**：community
- **来源名称**：Linkly / ClawHub

### 4. cloudflare agents-sdk (Cloudflare)

Cloudflare 官方发布技能，在 OfficialSkills.sh 中列为 Cloudflare 官方技能。该技能指导构建基于 Cloudflare Workers 的有状态 AI 代理，支持持久化 SQLite 状态、WebSocket 连接、定时任务和持久化工作流。

- **来源**：OfficialSkills
- **价值判断**：Cloudflare 官方出品，覆盖 agent 基础设施层（持久化、调度、通信），对于理解 agent 系统架构设计有参考价值
- **与当前栈关联**：当前 AI 工作流以本地为主，该技能提供了云端 agent 部署的另一种架构思路，适合需要持久化运行的场景
- **来源等级**：official（Cloudflare 官方发布）
- **来源名称**：OfficialSkills
