## 今日新发现

### 1. agent-browser

Vercel Labs 出品的浏览器自动化 Skill，在 Skills.sh Trending 排名第 20 位（11.6K），Linkly 综合榜排名第 1 位（Worth-Installing Score 80.9），是当前生态中热度最高的 agent 浏览器交互能力之一。支持 agent 对网页进行自动化操作、内容提取和交互测试。

- **来源**：Skills.sh Trending / Linkly Top 100
- **价值判断**：浏览器自动化是当前 AI 工作流中明显缺失的一环，可补全 web 信息采集和交互能力
- **与当前栈关联**：可增强当前 AI 工作流中的 web 数据获取和页面交互能力，与现有的 web_search/web_fetch 形成互补
- **来源等级**：ecosystem（Vercel Labs 发布，通过 Skills.sh 生态平台分发）
- **来源名称**：Skills.sh

### 2. microsoft-foundry

Microsoft 官方 Azure Skills 系列中的核心 Skill，覆盖 Azure AI Foundry 的开发和管理。Linkly 综合榜排名第 12 位（Score 64），Skills.sh 排名第 162 位（2.3K）。Microsoft 官方发布了完整的 Azure 技能矩阵，包含 foundry、diagnostics、deploy、kubernetes 等 30+ 子 Skill。

- **来源**：Linkly Top 100 / OfficialSkills.sh
- **价值判断**：当前 AI 工作流涉及 Azure 监控和运维，官方 Skill 可提供标准化操作指引
- **与当前栈关联**：与现有的 Azure 告警监控工作流直接相关，可标准化 Azure 资源操作流程
- **来源等级**：official（Microsoft 官方发布）
- **来源名称**：Linkly / OfficialSkills.sh

### 3. agent-security

由 0xNyk 发布的防御性 agent 供应链安全 Skill，包含 scan-repo（密钥/恶意代码检测）、repo-guard（防止破坏性 GitHub 操作）、scan-content（不可信内容检测）和 vet-incoming（第三方模板/包审查）四个模块。SkillsMP 显示更新于 2026-09-22。

- **来源**：SkillsMP
- **价值判断**：当前 AI 工作流涉及代码仓库操作和外部内容处理，安全防护是刚需
- **与当前栈关联**：直接适用于当前 AI 工作流中的 git 操作安全和外部内容安全处理场景
- **来源等级**：community
- **来源名称**：SkillsMP

### 4. no-mistakes

kunchenguid 发布的代码变更验证流水线 Skill，集成代码审查、测试、lint、文档、推送、PR 和 CI 全流程。在 SkillsMP 上更新于 2026-10-04，是近期活跃维护的项目。

- **来源**：SkillsMP
- **价值判断**：提供了结构化的代码变更验证流程，但需评估与现有工作流的重叠度
- **与当前栈关联**：可与现有的 review、tdd、setup-pre-commit 等 Skill 形成互补或替代关系，需对比验证
- **来源等级**：community
- **来源名称**：SkillsMP

### 5. subagent-coordination

plori-ai 发布的多 agent 协调 Skill，支持将工作拆分为文件级独立单元分配给最多三个原生子 agent 和两个并行任务，完成后统一审查整合为一个 PR。SkillsMP 显示更新于 2026-10-03。

- **来源**：SkillsMP
- **价值判断**：多 agent 协调模式对复杂任务的并行处理有参考价值，但具体实现需评估
- **与当前栈关联**：与现有的 orchestration 和 sub-agent 使用模式相关，可借鉴其任务拆分和审查整合策略
- **来源等级**：community
- **来源名称**：SkillsMP
