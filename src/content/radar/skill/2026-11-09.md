## 今日新发现

### 1. Microsoft Azure Skills Suite（azure-diagnostics / azure-deploy / azure-storage 等）

微软官方在 Skills.sh 平台发布了一整套 Azure 技能，覆盖诊断、部署、存储、合规、Kubernetes、App Insights 插桩等 12+ 个细分方向。Linkly Top 100 中，microsoft-foundry（WIS 66.2）和 azure-ai（WIS 66.1）分别排名第 7、8，azure-diagnostics（WIS 65.9）排名第 11，azure-deploy（WIS 65.9）排名第 12，整组集中在 WIS 59-66 区间。这些技能由 microsoft 官方账号直接发布，属于官方级别。

- **来源**：Linkly Top 100 / Skills.sh（microsoft 官方）
- **价值判断**：azure-diagnostics 可与当前 Azure Monitor 告警监控链路直接对接，减少手动排查步骤；azure-deploy / azure-storage 可覆盖基础设施变更场景
- **与当前 AI 工作流关联**：当前已部署 Azure 告警邮件监控 cron 任务，azure-diagnostics 技能可补齐告警触发后的自动诊断环节
- **来源等级**：official
- **来源名称**：Skills.sh（microsoft 官方）

ClawHub 上 mcp-lark 技能（得分 5095，属于 ClawHub 高分区间）提供 Lark/Feishu 的 MCP 集成，声称覆盖 300+ 工具。同系列还有 lark-cli-setup（5095）和 agent-feishu-direct-tools-patch（5095）。当前飞书工作流已通过飞书插件打通消息通道，mcp-lark 是否提供互补能力（如多维表格、文档操作之外的扩展场景）未确认。

- **来源**：ClawHub
- **价值判断**：若当前飞书插件覆盖不够，可作为补充通道；若覆盖已足够，收编意义有限
- **与当前 AI 工作流关联**：当前飞书消息推送、Bitable 操作已通过插件完成，此技能是否带来增量能力未确认
- **来源等级**：ecosystem
- **来源名称**：ClawHub
