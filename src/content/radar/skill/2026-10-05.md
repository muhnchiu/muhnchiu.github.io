## 今日新发现

### 1. azure-diagnostics (microsoft/azure-skills)

Microsoft 官方发布的 Azure 诊断技能，覆盖 Azure 资源排查、部署验证、存储管理等功能。同一仓库还包含 appinsights-instrumentation（Application Insights 插桩）和 azure-ai 等多个子技能。在 Linkly Top 100 榜单中 Worth-Installing Score 达 60.5，OfficialSkills.sh 列为官方发布方。

- **来源**：OfficialSkills.sh / Linkly Top 100
- **价值判断**：官方维护、覆盖面广，与当前 Azure 告警监控工作流直接相关
- **与当前栈关联**：当前 AI 工作流已有 Azure Monitor 告警邮件监控和 App Insights 日志查询，此技能可补充原生 Azure 资源诊断能力
- **来源等级**：official
- **来源名称**：OfficialSkills.sh / Linkly

### 2. quarkus-tdd (affaan-m/ECC)

面向 Java Quarkus 3.x LTS 的测试驱动开发技能，使用 JUnit 5、Mockito、REST Assured、Camel Testing 和 JaCoCo。覆盖添加功能、修复 Bug 和重构事件驱动服务的 TDD 流程。来自 SkillsMP 搜索结果。

- **来源**：SkillsMP
- **价值判断**：Java 后端 TDD 流程完整，覆盖测试框架和覆盖率工具链
- **与当前栈关联**：当前工作流涉及 Java/Spring 后端开发，TDD 技能可补充现有测试流程
- **来源等级**：community
- **来源名称**：SkillsMP

### 3. mcp-lark (Feishu/Lark OpenAPI MCP)

ClawHub 上的飞书/Lark MCP 技能，通过 OpenAPI MCP Server 提供 300+ 工具。与当前已安装的 feishu-doc/drive/perm/wiki 插件技能不同，此技能基于 MCP 协议而非直接 API 调用，覆盖范围更广但集成方式不同。功能细节未确认。

- **来源**：ClawHub Search
- **价值判断**：工具覆盖面广，但与现有飞书插件技能功能可能重叠，需评估实际增量价值
- **与当前栈关联**：当前工作流深度使用飞书生态，MCP 方式可能提供更灵活的工具编排
- **来源等级**：community
- **来源名称**：ClawHub

### 4. threat-model-analyst (github/awesome-copilot)

STRIDE-A 威胁模型分析技能，支持全量分析和增量更新两种模式。可生成架构概览图、DFD 图、STRIDE 分析和优先级评估。增量模式可对比上次报告，追踪新增/已解决/仍存在的威胁。

- **来源**：SkillsMP / GitHub awesome-copilot
- **价值判断**：威胁建模流程完整，增量更新功能实用，适合后端服务安全审计
- **与当前栈关联**：当前工作流涉及后端服务安全，此技能可补充安全审计能力
- **来源等级**：ecosystem
- **来源名称**：SkillsMP / GitHub

### 5. feature-walkthrough (Stirling-Tools/Stirling-PDF)

分支全流程 walkthrough 技能，从 diff 中提取变更范围，追踪前端到后端每一层（Java controller/service/endpoint、Python engine、config、i18n、tests），生成包含 Mermaid 序列图/流程图/架构图的文档。

- **来源**：SkillsMP
- **价值判断**：Java 后端分支审查场景实用，自动化文档生成减少 hand-off 成本
- **与当前栈关联**：当前工作流涉及 Java 后端代码审查，此技能可补充分支审查文档化能力
- **来源等级**：community
- **来源名称**：SkillsMP
