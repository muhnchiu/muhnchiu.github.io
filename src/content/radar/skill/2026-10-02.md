## 今日新发现

### 1. SkillOpt (microsoft/SkillOpt)

微软研究院发布的 SkillOpt 是一个文本空间优化器，通过轨迹驱动的编辑来训练可复用的自然语言技能，适用于冻结 LLM 的 agent。GitHub Stars 17.9k，昨日有更新。该项目探索让 agent 自主学习和优化技能的方法，属于 self-evolving-agents 方向。

- **来源**：GitHub Explore（Stars 排序第一）
- **价值判断**：微软官方项目，研究方向前沿（agent 自进化），Star 数高且活跃更新，值得深入了解其技能训练方法论
- **与当前栈关联**：当前 AI 工作流依赖 Skills 体系，SkillOpt 的"训练可复用技能"思路可能对现有 Skills 的编写和优化有参考价值
- **来源等级**：official（微软研究院）
- **来源名称**：GitHub

### 2. agent-browser (vercel-labs)

Vercel Labs 出品的 agent-browser 技能，让 AI agent 具备浏览器操作能力。在 Skills.sh Trending 排名第 22 位（11.9K 分），Linkly 综合榜排名第 1（Worth-Installing Score 81.2），是该榜单当前最高分技能。

- **来源**：Skills.sh Trending + Linkly Top 100
- **价值判断**：Linkly 榜首，Worth-Installing Score 最高，Vercel 官方团队维护，生态成熟度高
- **与当前栈关联**：当前 AI 工作流缺少浏览器自动化能力，agent-browser 可补充 web 交互场景
- **来源等级**：ecosystem（Vercel Labs，通过 Skills.sh 平台分发）
- **来源名称**：Skills.sh / Linkly

### 3. frontend-design (anthropics)

Anthropic 官方发布的前端设计技能，在 Linkly 综合榜排名第 2（Score 75.8），Skills.sh Trending 榜上有 4.2K 分。该技能指导 agent 进行前端设计和 UI 实现。

- **来源**：Skills.sh Trending + Linkly Top 100 + OfficialSkills.sh
- **价值判断**：Anthropic 官方出品，双榜高位，设计类技能中排名领先
- **与当前栈关联**：当前已有 design-an-interface 技能，frontend-design 可作为补充或替代参考
- **来源等级**：official（Anthropic）
- **来源名称**：Linkly / Skills.sh

### 4. Microsoft Azure Skills 套件

微软在 OfficialSkills.sh 和 Linkly 上发布了完整的 Azure Skills 套件，包含 microsoft-foundry（Score 63.9）、azure-diagnostics（63.7）、azure-deploy（63.5）、azure-validate（63.4）、appinsights-instrumentation（63.3）、azure-kubernetes（61.7）等 20+ 个子技能，覆盖 Azure 开发运维全流程。Local 已安装的 Azure 告警监控工作流与之有直接关联。

- **来源**：OfficialSkills.sh + Linkly Top 100
- **价值判断**：微软官方出品，套件完整，覆盖 Azure 全链路，appinsights-instrumentation 与当前 Azure 告警监控工作流直接相关
- **与当前栈关联**：当前已有 Azure 告警邮件监控 + App Insights 查询流程，appinsights-instrumentation 技能可直接增强现有工作流
- **来源等级**：official（Microsoft）
- **来源名称**：OfficialSkills.sh / Linkly

### 5. self-improving (ivangdavila)

ClawHub 上的 self-improving 技能，让 agent 进行自我反思、自我批评、自我学习和自组织记忆。安装量 210K，Score 61.7。该技能与微软 SkillOpt 属于同一方向（agent 自进化），但来自社区。

- **来源**：ClawHub Search + Linkly Top 100（排名 41）
- **价值判断**：社区出品但安装量可观，self-improving 方向值得跟踪，与 SkillOpt 形成官方+社区对照
- **与当前栈关联**：agent 自反思和自组织记忆对当前 AI 工作流的持续改进有参考价值
- **来源等级**：community
- **来源名称**：ClawHub / Linkly
