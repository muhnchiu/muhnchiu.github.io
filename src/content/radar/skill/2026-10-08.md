## 今日新发现

### 1. no-mistakes

通过自动化流水线（代码审查、测试、lint、文档、推送、PR、CI）验证代码变更，确保变更在到达推送目标前通过完整检查。覆盖从提交到 PR 的全链路质量门控。

- **来源**：SkillsMP (kunchenguid/no-mistakes)
- **价值判断**：提供端到端代码变更验证流水线，与当前 AI 工作流中的 review/qa 体系互补，可作为变更安全推送的自动化护栏。
- **与当前栈关联**：当前已安装 review、qa、setup-pre-commit 等技能，no-mistakes 将这些离散步骤整合为统一流水线，形成完整的变更门控闭环。
- **来源等级**：community
- **来源名称**：SkillsMP
- **来源URL**：https://skillsmp.com/creators/kunchenguid/no-mistakes/skills-no-mistakes

### 2. self-improving-agent

记录自身发现以实现自我改进的 Skill。Agent 评估自身工作、发现错误并持续改进，配合自组织记忆机制。在 Linkly Top 100 综合榜排名第 5，Worth-Installing Score 68.2。

- **来源**：ClawHub (pskoett/skills/self-improving-agent) / Linkly 榜单
- **价值判断**：自我反思与持续改进机制对长期运行的 AI Agent 有实际价值，尤其在错误模式积累和避免重复犯错方面。
- **与当前栈关联**：当前 AI 工作流依赖 MEMORY.md 和 daily notes 做人工记忆维护，self-improving-agent 可将部分自我评估自动化，与现有记忆体系叠加。
- **来源等级**：ecosystem
- **来源名称**：ClawHub / Linkly
- **来源URL**：https://clawhub.ai/pskoett/skills/self-improving-agent

### 3. agent-security

面向 AI Agent 的供应链安全防护。包含 scan-repo（确定性无网络扫描，拦截密钥泄露、混淆代码执行、不可见 Unicode 注入）和 repo-guard（PATH 垫片 + 钩子，硬拦截破坏性 GitHub 仓库生命周期操作）。还包含 scan-content（针对不可信内容的已知模式触发器）和 vet-incoming（第三方模板/包入库前审查）。

- **来源**：SkillsMP (0xNyk/agent-security)
- **价值判断**：直接针对 AI Agent 操作仓库时的安全风险，scan-repo 和 repo-guard 是可落地的防护手段，与当前 AI 工作流中频繁的 git 操作直接相关。
- **与当前栈关联**：当前已安装 git-guardrails-claude-code 做 git 操作护栏，agent-security 补充了供应链层面的防护（密钥泄露、注入内容、第三方模板审查），形成更完整的安全体系。
- **来源等级**：community
- **来源名称**：SkillsMP
- **来源URL**：https://skillsmp.com/creators/0xnyk/agent-security/skill

### 4. subagent-coordination

在多步编码工作中进行上下文收集、规划和协调，使用显式模型分层。将工作拆分为文件不相交的单元分配给最多三个原生子代理和两个并行本地 CLI 任务，逐项审查交付物后整合为整体 PR。

- **来源**：SkillsMP (plori-ai/skills/subagent-coordination)
- **价值判断**：多子代理协调是复杂编码任务的编排方案，对大型重构或多功能开发场景有价值。功能描述较完整但缺乏独立验证。
- **与当前栈关联**：当前 AI 工作流已有 orchestration 技能做多步协调，subagent-coordination 更侧重文件级拆分和并行执行，可作为补充观察。
- **来源等级**：community
- **来源名称**：SkillsMP
- **来源URL**：https://skillsmp.com/creators/plori-ai/skills/subagent-coordination

### 5. ponytail

强制采用最简单可行方案的 Skill。YAGNI 原则的执行者，质疑任务是否需要存在，优先标准库而非自定义代码，优先原生平台功能而非依赖。支持 lite/full/ultra 三档强度。适用于编码、重构、修复、审查、选库等场景。

- **来源**：SkillsMP (DietrichGebert/ponytail)
- **价值判断**：YAGNI 理念实用，能减少过度工程化。但当前已有 caveman（压缩代码）和 request-refactor-plan（重构计划）等技能覆盖类似场景，叠加价值需评估。
- **与当前栈关联**：与 caveman 的极简风格和 improve-codebase-architecture 的架构改进有理念重叠，建议观察社区反馈后再决定是否收编。
- **来源等级**：community
- **来源名称**：SkillsMP
- **来源URL**：https://skillsmp.com/creators/dietrichgebert/ponytail/skills-ponytail
