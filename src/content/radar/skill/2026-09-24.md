## 今日新发现

### 1. larksuite/cli lark-* 官方技能套件

飞书官方在 Skills.sh 发布了完整 lark-cli 技能系列，涵盖 lark-doc、lark-im、lark-drive、lark-wiki、lark-whiteboard、lark-task、lark-markdown、lark-calendar、lark-mail、lark-slides、lark-approval 等十余个技能，总安装量约 10.9K。当前 AI 工作流已通过插件方式集成飞书文档/云盘/知识库，但 lark-cli 系列覆盖更广（即时消息、任务、日历、邮件、幻灯片、审批等），且由 larksuite 官方维护。

- **来源**：Skills.sh（open.feishu.cn 发布者）
- **价值判断**：官方维护，覆盖面远超当前插件，值得试用 lark-task / lark-im / lark-calendar 等未覆盖能力
- **与当前栈关联**：直接扩展飞书集成能力，弥补当前仅有 doc/drive/wiki/perm 的局限
- **来源等级**：official
- **来源名称**：Skills.sh

### 2. obra/superpowers requesting-code-review

obra/superpowers 是 Skills.sh 上热度很高的技能包，其中 requesting-code-review 于 2026-09-19 更新。该技能用于在完成任务、实现重要功能或合并前验证工作是否符合需求，与当前已安装的 review 技能形成互补——review 侧重审查代码变更，requesting-code-review 侧重从需求侧验证。

- **来源**：SkillsMP / Skills.sh
- **价值判断**：近期活跃更新，与现有 review 技能角度互补，值得试用
- **与当前栈关联**：增强代码审查工作流，形成"需求验证 + 代码审查"双轨
- **来源等级**：ecosystem
- **来源名称**：SkillsMP

### 3. microsoft/azure-skills 官方技能套件

微软在 OfficialSkills.sh 和 Skills.sh 上发布了 25+ 个 Azure 官方技能，涵盖 azure-diagnostics、azure-deploy、azure-monitor、appinsights-instrumentation、azure-cost、azure-kubernetes 等，Linkly 综合榜排名 13-36 位，Worth-Installing Score 62-64 分。当前 AI 工作流有 Azure 告警监控需求，官方技能可提供标准化操作指引。

- **来源**：OfficialSkills.sh / Linkly
- **价值判断**：官方维护，覆盖面广，与 Azure 告警监控场景直接相关
- **与当前栈关联**：可标准化 Azure 诊断和 App Insights 查询流程，但需评估是否适配当前自定义脚本方案
- **来源等级**：official
- **来源名称**：OfficialSkills.sh
