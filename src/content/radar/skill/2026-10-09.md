## 今日新发现

### 1. Microsoft Azure Skills 系列

微软官方（microsoft/azure-skills）发布的一组 Azure 开发技能，在 Linkly Top 100 榜单中占据多个席位（azure-diagnostics、azure-prepare、azure-ai、azure-deploy、azure-storage、appinsights-instrumentation、azure-validate、azure-compliance、azure-kusto、azure-messaging、azure-compute、azure-reliability 等，Worth-Installing Score 约 62-64 分，各技能安装量约 50 万）。

- **来源**：Linkly Top 100 / OfficialSkills.sh
- **价值判断**：官方一手技能，覆盖 Azure 诊断、部署、存储、监控（App Insights、Kusto）等完整生命周期，可信度最高。
- **与当前栈关联**：现有 Azure 告警邮件监控与 App Insights 日志排查流程高度相关，azure-diagnostics / appinsights-instrumentation / azure-kusto 可望直接增强该工作流。
- **来源等级**：official
- **来源名称**：Linkly / OfficialSkills.sh
- **参考**：https://github.com/microsoft/azure-skills

### 2. agent-security

面向被 AI 智能体与自动化脚本触碰的仓库，提供防御性的智能体供应链安全能力。内置 scan-repo（确定性、无网络的泄密/投放器门禁）、repo-guard（PATH shim + hook 硬阻断破坏性仓库生命周期操作）、scan-content（对不可信抓取内容的已知模式告警）以及 vet-incoming（入站供应链门禁）。更新于 2026-09-22。

- **来源**：SkillsMP
- **价值判断**：针对 AI 编码工具链的供应链安全防护，方向稀缺且有实用价值。
- **与当前栈关联**：与自动化 cron 任务、第三方 skill/模板引入场景直接相关，可作为安全护栏。
- **来源等级**：community
- **来源名称**：SkillsMP
- **参考**：https://skillsmp.com/creators/0xnyk/agent-security/skill

### 3. mcp-lark

通过 OpenAPI MCP servers 接入飞书/Lark 的技能，宣称提供 300+ 工具。ClawHub 搜索 "feishu lark" 时命中，另有 feishu-lark、feishu-lark-cli、lark-cli-setup、feishu-setup-troubleshooting 等同主题技能。

- **来源**：ClawHub
- **价值判断**：以 MCP 方式扩展飞书能力，覆盖面大，但成熟度与具体可用工具未确认。
- **与当前栈关联**：当前飞书已作为主要消息/推送通道，mcp-lark 可望补充更细粒度的飞书 API 操作。
- **来源等级**：ecosystem
- **来源名称**：ClawHub

### 4. agent-browser

Vercel Labs 发布的浏览器自动化技能，位列 Linkly Top 100 第 1 名，安装量约 105 万，Worth-Installing Score 80.8（全榜最高）。

- **来源**：Linkly
- **价值判断**：短期热度极高，定位为智能体的浏览器操作能力；实际能力与当前工作流的契合度需观察。
- **与当前栈关联**：与现有 computer-use / 浏览器操作技能可能重叠，先观察再决定是否收编。
- **来源等级**：ecosystem
- **来源名称**：Linkly
- **参考**：https://github.com/vercel-labs/agent-browser

### 5. no-mistakes

将代码变更通过自动化流水线（code review、测试、lint、文档、push、PR、CI）逐级校验后才到达目标分支的技能。更新于 2026-10-04，Stars 8.7k。

- **来源**：SkillsMP

- **与当前栈关联**：与现有 review / tdd / setup-pre-commit 技能存在功能重叠，可作补充参考。
- **来源等级**：community
- **来源名称**：SkillsMP
- **参考**：https://skillsmp.com/creators/kunchenguid/no-mistakes/skills-no-mistakes
