## 今日新发现

### 1. appinsights-instrumentation (Microsoft Azure Skills)

Microsoft 官方发布的 Azure Application Insights 埋点技能，属于 microsoft/azure-skills 仓库（含 30+ Azure 技能）。在 Linkly Top 100 综合 Worth-Installing Score 为 64.3，安装量约 61 万。该技能指导 AI 工具链完成 App Insights 的接入和配置，覆盖请求追踪、日志记录、依赖项监控等场景。当前 AI 工作流中已有 Azure 告警邮件监控（基于 App Insights 查询），该技能可直接补强告警排查链路的埋点能力。

- **来源**：Skills.sh Trending / Linkly Top 100 / OfficialSkills
- **价值判断**：官方发布，安装量高，与现有 Azure 监控工作流直接关联
- **与当前栈关联**：补强 Azure Monitor 告警链路的 App Insights 埋点环节
- **来源等级**：official
- **来源名称**：Skills.sh / Linkly / OfficialSkills

### 2. azure-diagnostics (Microsoft Azure Skills)

Microsoft 官方发布的 Azure 诊断技能，同样属于 microsoft/azure-skills 仓库。Linkly Top 100 Score 64.8，安装量约 61 万，在 Azure 技能集中排名靠前。覆盖 Azure 资源诊断设置、日志分析、故障排查等场景。与当前 AI 工作流中多乐士测试环境（Azure 托管）和 Azure 告警监控流程均可配合使用。

- **来源**：Linkly Top 100 / OfficialSkills
- **价值判断**：官方发布，诊断能力与现有 Azure 运维场景直接匹配
- **与当前栈关联**：Azure 告警触发后的根因诊断和资源排查
- **来源等级**：official
- **来源名称**：Skills.sh / Linkly / OfficialSkills

### 3. mcp-lark (ClawHub)

ClawHub 上可搜索到的飞书/Lark 技能，通过 OpenAPI MCP 服务器方式提供 300+ 工具，覆盖飞书开放平台的文档、多维表格、日历、消息等 API。与当前已安装的 4 个飞书插件技能（feishu-doc / feishu-drive / feishu-perm / feishu-wiki）形成互补，MCP 方式可覆盖更广泛的 API 调用场景。ClawHub 搜索排名靠前。

- **来源**：ClawHub Search
- **价值判断**：以 MCP 协议接入飞书全量 API，覆盖面显著超出当前插件技能
- **与当前栈关联**：扩展飞书集成能力，覆盖当前插件未涉及的多维表格操作、日历管理等场景
- **来源等级**：ecosystem
- **来源名称**：ClawHub

### 4. coderabbitai/autofix (CodeRabbit)

OfficialSkills 收录的 CodeRabbit 官方技能，功能是从 GitHub PR 拉取未解决的 CodeRabbit review 评论并自动应用修复。支持交互式或批量修复模式。SkillsMP 也有收录。适用场景为代码审查后的自动修复闭环。当前 AI 工作流中已有 code-review 相关技能，该技能可将审查反馈到修复的链路自动化。

- **来源**：OfficialSkills / SkillsMP
- **价值判断**：补全 code review 到 fix 的闭环，但依赖 CodeRabbit 服务接入
- **与当前栈关联**：代码审查工作流的自动化延伸
- **来源等级**：ecosystem
- **来源名称**：OfficialSkills / SkillsMP

### 5. intent-driven-development (affaan-m/ECC)

SkillsMP 收录的社区技能，功能是将模糊的产品和工程需求转化为可验证的验收标准。在需求不明确、高影响变更（安全/数据/迁移/集成）场景下触发，先定义可测试的验收条件再进入实现阶段。与现有的 triage / to-prd / qa 等技能形成互补，覆盖需求澄清到验收的中间环节。

- **来源**：SkillsMP
- **价值判断**：填补需求澄清到验收标准的流程空白，但需验证实际触发准确性
- **与当前栈关联**：与现有 to-prd / qa 技能形成需求-验收链路
