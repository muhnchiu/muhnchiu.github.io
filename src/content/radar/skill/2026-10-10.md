## 今日新发现

### 1. Microsoft azure-skills 系列（azure-diagnostics / appinsights-instrumentation / azure-kusto 等）

微软官方 azure-skills 仓库提供数十个 Azure 主题技能，覆盖诊断、App Insights 埋点、Kusto 查询、部署、合规等。在 Linkly 每日更新的 Top 100 榜单中该系列有 20 余个条目在榜，WIS 分数集中在 59-63 区间（azure-diagnostics 63.1、appinsights-instrumentation 62.8、azure-kusto 62.3）。具体各技能发布日期未确认，榜单只反映当前在榜状态，不代表今日新发布。

- **来源**：Linkly Top 100（发布方为微软官方 GitHub 组织）
- **价值判断**：与现有 Azure 告警邮件监控加 App Insights 查日志的流程高度相关，官方出品可信度高
- **与当前栈关联**：当前 AI 工作流每日定时分析 Azure 告警并查询日志，azure-kusto / appinsights-instrumentation 的官方查询与埋点实践可直接对照借鉴
- **来源等级**：official
- **来源名称**：Linkly / microsoft/azure-skills

### 2. agent-security

社区发布的 agent 供应链安全技能，SkillsMP 页面显示更新于 2026-09-22。自述包含三部分：scan-repo（离线扫描仓库中的密钥泄露、混淆执行代码、不可见字符）、repo-guard（对破坏性 GitHub 仓库操作做硬拦截并要求人工确认）、scan-content（对不可信抓取内容做已知模式检测）。实际效果未确认。

- **来源**：SkillsMP
- **价值判断**：当前环境多个自动化 agent 持有 GitHub 凭据，防泄露与防误删的防御思路契合
- **与当前栈关联**：可与现有 git 保护类技能互补，用作仓库公开前的泄露扫描层
- **来源等级**：community
- **来源名称**：SkillsMP（0xNyk/agent-security）

### 3. agent-browser

vercel-labs 出品的浏览器自动化技能，Linkly Top 100 排名第 1（WIS 80.9），Linkly 显示其 skills.sh 安装量约 107 万。定位为面向 agent 的浏览器控制能力。与本地已有浏览器操作能力是否重叠未确认。

- **来源**：Linkly Top 100
- **价值判断**：热度高、背靠 vercel-labs 官方组织，但浏览器操控非当前痛点
- **与当前栈关联**：未来出现需要真实页面操作的场景时可作为候选
- **来源等级**：ecosystem
- **来源名称**：Linkly / vercel-labs/agent-browser

- **来源**：SkillsMP
- **价值判断**：与现有 pre-commit 钩子加 review 技能方向一致，但功能重叠度较高
- **与当前栈关联**：当前仓库已有提交前校验和审查流程，边际收益有限，可观察其流水线编排方式
- **来源等级**：community
- **来源名称**：SkillsMP（kunchenguid/no-mistakes）

- **来源**：SkillsMP
- **价值判断**：本质是行为约束型提示词，试用成本低，可对冲过度工程倾向

- **来源等级**：community
- **来源名称**：SkillsMP（DietrichGebert/ponytail）
