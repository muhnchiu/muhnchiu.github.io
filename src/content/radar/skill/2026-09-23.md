## 今日新发现

### 1. microsoft/azure-skills (azure-diagnostics, appinsights-instrumentation, azure-deploy 等)

Microsoft 官方团队发布的 Azure 技能套件，涵盖诊断、部署、App Insights 接入、资源可视化、合规等 20+ 个子技能。在 Linkly Top 100 中占据 #13-#32 多个席位，Worth-Installing Score 60-63.5 分。其中 appinsights-instrumentation 和 azure-diagnostics 与当前 Azure 告警监控工作流直接相关。

- **来源**：OfficialSkills.sh / Linkly Top 100
- **价值判断**：官方团队出品，覆盖面广，与当前 Azure 运维场景直接匹配
- **与当前栈关联**：当前 AI 工作流已有 Azure 告警邮件监控和 App Insights 查询脚本，官方技能可标准化这些流程并提供更完整的 Azure 资源操作能力
- **来源等级**：official
- **来源名称**：OfficialSkills.sh / Linkly

### 2. obra/superpowers (requesting-code-review, receiving-code-review)

obra/superpowers 仓库提供的代码评审工作流技能对，分别处理"发起代码评审"和"接收评审反馈"两个场景。requesting-code-review 专注于任务完成或合并前的质量验证；receiving-code-review 强调对评审反馈的技术严谨验证，避免盲目接受。在 SkillsMP 上有较高展示量。

- **来源**：SkillsMP
- **价值判断**：与已安装的 review 技能形成互补，提供更细粒度的评审工作流拆分
- **与当前栈关联**：当前已安装 review 技能（mattpocock 版），obra 版将评审拆分为请求和接收两个独立流程，适合需要更结构化评审流程的场景
- **来源等级**：community
- **来源名称**：SkillsMP

### 3. cicd-pipeline (ClawHub)

ClawHub 上的 CI/CD 流水线技能，提供流水线配置和管理能力。ClawHub 搜索 "git workflow CI/CD" 关键词返回的结果之一。

- **来源**：ClawHub
- **价值判断**：功能描述较简略，需实际安装查看 SKILL.md 确认具体覆盖范围
- **与当前栈关联**：与 git workflow 和 CI/CD 场景相关，但当前已有 git-guardrails 和 setup-pre-commit 覆盖部分场景
- **来源等级**：ecosystem
- **来源名称**：ClawHub

### 4. microsoft/SkillOpt

GitHub 上 17.4K Stars 的研究项目，文本空间优化器，通过轨迹驱动编辑为冻结 LLM 智能体训练可复用的自然语言技能。属于自我进化智能体研究方向。

- **来源**：GitHub Explore
- **价值判断**：学术研究项目，非可直接安装的技能，但概念值得关注
- **与当前栈关联**：技能自动优化和自我进化理念与当前 AI 工作流的 skill 管理相关，但尚处于研究阶段
- **来源等级**：research
- **来源名称**：GitHub

### 5. self-improving-agent (ClawHub)

ClawHub 上的自我改进技能，记录自身发现以实现自我改进。Linkly Score 59.6，由 pskoett 发布。另一个变体 self-improving（ivangdavila）Score 62.5，提供自我反思、自我批评和自组织记忆。

- **来源**：ClawHub / Linkly
- **价值判断**：概念有趣但与当前优先级（Java/backend/test/review）关联度较低
- **与当前栈关联**：当前 AI 工作流已有 memory 管理和 heartbeat 机制实现部分自我改进功能，此技能提供更系统化的框架
- **来源等级**：ecosystem
- **来源名称**：ClawHub / Linkly
