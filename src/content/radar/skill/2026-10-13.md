## 今日新发现

### 1. azure-diagnostics

Microsoft 官方（microsoft/azure-skills 仓库）发布的 Azure 诊断技能。经 skills.sh API 直接核实，该技能由 Microsoft 官方组织发布，安装量约 55.2 万，在 Linkly 当前 Top 100 榜单第 96 位（WIS 55）。具体功能描述以仓库为准，定位为 Azure 资源与应用的诊断排查。

- **来源**：Linkly Top 100 + skills.sh API 交叉核实
- **价值判断**：官方来源、装机量大，且与当前 Azure 告警监控流程（告警邮件解析后查日志定位）直接相关，可作为排查环节的辅助参考
- **与当前栈关联**：Azure Monitor 告警 -> 日志排查流程可实测该技能能否缩短定位时间
- **来源等级**：official
- **来源名称**：skills.sh（microsoft/azure-skills），榜单数据 Linkly
- **来源URL**：https://github.com/microsoft/azure-skills

- **与当前栈关联**：与已装 review 技能存在功能重叠，试用时重点比较覆盖面与输出格式
- **来源等级**：ecosystem
- **来源名称**：Linkly / skills.sh
- **来源URL**：https://linkly.ai/zh/skills

### 3. agent-browser

### 5. SkillOpt

GitHub 上 microsoft/SkillOpt 仓库，在 agent-skills 相关仓库 Star 排序搜索中位列第一（该搜索共命中约 1695 个仓库）。官方描述为"text-space optimizer"：通过轨迹驱动编辑、验证门控更新，为冻结参数的 LLM Agent 训练可复用的自然语言技能，产出可部署的 best_skill.md。属研究性质项目，工程可用性未确认。

- **来源**：GitHub API（agent-skills SKILL.md 仓库搜索，Star 排序）
- **价值判断**：官方研究仓库，方向（自动化优化技能文本）与技能生态长期演进相关
- **与当前栈关联**：当前技能库为人工维护，若该项目可工程化，长期可参考其方法
- **来源等级**：official
- **来源名称**：GitHub（microsoft）
- **来源URL**：https://github.com/microsoft/SkillOpt
