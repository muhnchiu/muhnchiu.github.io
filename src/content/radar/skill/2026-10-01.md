## 今日新发现

### 1. Microsoft Azure Skills Suite（azure-diagnostics / appinsights-instrumentation 等）

Microsoft 官方在 officialskills.sh 发布了完整的 Azure 技能套件，涵盖 azure-diagnostics、appinsights-instrumentation、azure-deploy、azure-compliance、azure-kusto、azure-storage、azure-compute、azure-kubernetes 等二十余个技能。其中 azure-diagnostics 和 appinsights-instrumentation 与当前 Azure 监控工作流直接相关，可用于 Azure 诊断和应用洞察操作。Linkly 综合榜显示该套件安装量约 61 万次，Worth-Installing Score 63+。

- **来源**：OfficialSkills.sh / Linkly Top 100
- **价值判断**：官方出品，覆盖 Azure 全栈运维场景，与当前 Azure 告警监控流程高度互补
- **与当前栈关联**：azure-diagnostics 可增强 Azure 诊断能力，appinsights-instrumentation 与现有 Azure Monitor + App Insights 查询流程衔接
- **来源等级**：official（Microsoft 官方团队）
- **来源名称**：OfficialSkills.sh / Linkly

### 2. requesting-code-review (obra/superpowers)

obra/superpowers 仓库的 code review 技能，专注于在完成任务、实现重大功能或合并前验证工作是否满足需求。SkillsMP 显示最近更新于 2026-09-19，289.8k 次浏览。与本地已安装的 review 技能相比，更侧重于"请求审查"的流程编排而非审查本身。

- **来源**：SkillsMP
- **价值判断**：补充现有 code review 工作流，提供"何时触发审查"的标准化流程
- **与当前栈关联**：可与现有 review 技能配合，形成"请求-执行-接收"完整链路
- **来源等级**：community
- **来源名称**：SkillsMP

### 3. receiving-code-review (obra/superpowers)

obra/superpowers 的配套技能，处理收到的 code review 反馈。强调技术验证而非盲目同意反馈意见，在反馈不清晰或技术上有疑问时主动质疑。与 requesting-code-review 形成配对。SkillsMP 显示最近更新于 2026-07-24。

- **来源**：SkillsMP
- **价值判断**：完善 code review 闭环，避免盲目接受反馈的风险
- **与当前栈关联**：与 requesting-code-review 配套使用
- **来源等级**：community
- **来源名称**：SkillsMP

### 4. self-improving (ivangdavila)

ClawHub 上的自我反思+自我批评+自我学习+自组织记忆技能。智能体评估自身工作、发现错误并持续改进。Linkly 综合榜 Worth-Installing Score 62.1，安装量约 21 万次。

- **来源**：ClawHub / Linkly
- **价值判断**：概念有启发性，但具体效果未确认，需观察实际可用性
- **与当前栈关联**：可用于 AI 工作流的自我优化和质量提升
- **来源等级**：ecosystem
- **来源名称**：ClawHub / Linkly

### 5. Vercel agent-browser

Vercel Labs 出品的浏览器自动化技能，Skills.sh Trending 排名第 26（12.3K），Linkly 综合榜第 1 名（Worth-Installing Score 80.8），安装量约 98 万次。为 AI agent 提供浏览器操作能力。

- **来源**：Skills.sh Trending / Linkly Top 100
- **价值判断**：生态热度极高，但与当前 Java/Spring 后端工作流关联度较低
- **与当前栈关联**：未确认与当前后端开发栈的直接关联
- **来源等级**：ecosystem
- **来源名称**：Skills.sh / Linkly
