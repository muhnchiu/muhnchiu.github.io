## 今日新发现

### 1. microsoft/SkillOpt

微软在 GitHub 发布的开源项目（19,068 Stars，2026-11-13 更新）。SkillOpt 是一种文本空间优化器，通过轨迹驱动的编辑、验证门控更新，为冻结 LLM 智能体训练可复用的自然语言技能，最终生成可部署的 best_skill.md 工件。

- **来源**：GitHub
- **价值判断**：将技能训练从手工编写推进到自动化优化方向，值得跟踪其方法论是否可迁移到当前技能工程实践。
- **与当前栈关联**：当前工作流中技能均为手工编写，SkillOpt 的优化器思路可能为技能质量改进提供新思路。
- **来源等级**：ecosystem（GitHub 社区，非官方团队发布页，但发布方为 microsoft 账号）
- **来源名称**：GitHub

### 2. LobeHub 文档技能族（pptx / pdf / docx / skill-vetter）

LobeHub 技能市场（2026-11-13 更新）中，anthropics 的 pptx 技能（182.3K 安装，4.0k 评分）以及 pdf（61 评分，3.4k 安装）、docx（40 评分，2.9k 安装）构成完整文档技能族。另有一款 skill-vetter（openclaw 出品，182 评分，3.3k 安装）提供技能安装前安全审查，检查红旗、权限范围和可疑模式。

- **来源**：LobeHub
- **价值判断**：文档技能族为日常产出提供完整工具链；skill-vetter 在技能生态扩张期有实际安全价值，与现有技能安装流程互补。
- **与当前栈关联**：当前工作流未安装文档处理技能（pptx/pdf/docx），skill-vetter 可直接用于现有技能安装前审查。
- **来源等级**：ecosystem
- **来源名称**：LobeHub
