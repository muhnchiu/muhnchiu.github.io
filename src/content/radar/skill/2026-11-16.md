## 今日新发现

### 1. appinsights-instrumentation

Microsoft 官方 Azure 技能族中的 Application Insights 埋点技能，在 Linkly Top 100 中排名 20，Worth-Installing Score 65.4，安装量 701,593（skills.sh 口径）。官方技能目录（officialskills.sh）将其收录于 Microsoft 官方发布线。功能为向应用注入 App Insights 遥测与埋点，具体操作范围未确认。

- **来源**：OfficialSkills / Linkly
- **价值判断**：与现有 Azure 告警邮件监控工作流（IMAP + 应用日志查询脚本）直接互补，可提供结构化日志查询能力，是今日与当前栈关联最强的信号。
- **与当前栈关联**：可直接纳入现有 Azure 监控工作流，作为日志诊断的技能化补充。
- **来源等级**：official
- **来源名称**：OfficialSkills.sh

### 2. vercel-labs/agent-browser

Linkly Top 1 技能（WIS 81.5，安装量 1,529,685）。Vercel Labs 发布的 Rust 原生浏览器自动化 CLI：快照式可访问性树 + 元素 ref 驱动，每条指令一次短 shell 调用，支持 CDP 附加、移动模拟器及云端浏览器（Browserbase / Browserless 等），内置 skills 机制（skills get core / list）与 MCP server。

- **来源**：Linkly / GitHub
- **价值判断**：浏览器自动化是当前工作流缺口，命令行式驱动方式与 shell 工作流天然契合，安装门槛低。
- **与当前栈关联**：可补充当前以 HTTP 抓取为主的网页访问能力，适合安排小规模测试。
- **来源等级**：ecosystem（Vercel Labs 发布，非官方团队技能目录）
- **来源名称**：Linkly

### 3. microsoft/SkillOpt

Microsoft 开源的技能自动优化器：以文本空间优化器方式训练可复用的自然语言技能（轨迹驱动编辑 + 验证门控），不改动模型权重。官方仓库 Changelog 显示：2026-11 被 NeurIPS 2026 收录为 Spotlight，并获 Microsoft Global Hackathon 2026 Executive Challenge 第一名（Microsoft Garage 颁发）。v0.2.0（2026-07-02）新增 SkillOpt-Sleep 夜间自进化引擎及多个 coding 工具的集成 shell。

- **来源**：GitHub
- **价值判断**：将技能工程从手工编写推进到自动化优化，是官方背景的先行项目，值得跟踪其方法论落地形态。
- **与当前栈关联**：当前技能均为手工编写，SkillOpt 的优化器思路可能为技能质量改进提供新思路；短期无可直接收编的产物，继续观察。
- **来源等级**：official
- **来源名称**：GitHub
