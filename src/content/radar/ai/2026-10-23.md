## 今日概览

今日生态以 AI 代理能力与免费模型为主，当前 API 模型栈无强制迁移。据报道，1Password 推出一种让 AI 代理在不见到密码的前提下代表用户登录的能力，直接关系 AI 编程与 Agent 系统方向的落地安全边界；OpenAI 的 Jev 决策模型据报道扩大可用范围，竞争仍在升温。OpenRouter 免费池保持丰富，NVIDIA Nemotron 3.5 系列与 Recursive Flint 编程模型可低成本测试；LiquidAI LFM2.5 提供免费 2.6B 变体。本地与图像生态方面，Qwen3.8-27B 与 Comfy-Org/MOSS-Image 社区获取量高，图像生成方向（flux-3 系列、LTX-2.5）活跃。今日无重大变化。

## 重点动态

### 1. 1Password 推出 AI 代理免密代登录

据报道，1Password 发布一种让 AI 代理代表用户登录的能力，代理全程无法看到明文密码。这是 Agent 系统与安全方向的落地信号：把“代理需要凭据”从明文交换改为受控通道。与当前 AI 编程工作流直接相关——Agent 代为登录第三方服务时不再暴露 secret，具体实现与兼容性待确认。

- **价值判断**：代理+凭据管理的落地信号，值得评估接入。
- **与当前栈关联**：可纳入 AI 编程代理的凭据管理候选。
- **来源等级**：media
- **来源名称**：TechCrunch

### 2. OpenAI Jev 决策模型扩大可用

据报道，OpenAI 让 Jev 决策模型更大范围可用，决策模型竞争升温。新模型发布类动态，属高关注但非紧急项；决策能力的具体基准与定价待确认，当前 API 栈无需迁移。

- **价值判断**：决策方向新选项，可跟踪。
- **与当前栈关联**：可纳入决策/规划类任务候选，不替代主力。
- **来源等级**：media
- **来源名称**：TechCrunch

### 3. Recursive 发布 Flint 编程模型

- **价值判断**：新编程模型，零成本可测试。
- **与当前栈关联**：可纳入 AI 编程候选池，不替代当前主力。
- **来源等级**：media
- **来源名称**：TechCrunch

## 研究前沿

1. **To Keep or Not to Keep: Learning KV Cache Retention in Disaggregated LLM Serving Systems**：面向分离式 LLM 服务的 KV Cache 保留策略学习，直接关系推理成本与延迟，与当前 API 模型栈的推理经济性相关。
2. **Multimodal Embodied Agents: A Unified Capability-centric Perspective from Computer-Use to Robot-Use**：从计算机操作到机器人使用的统一具身 Agent 能力视角，对 Agent 系统方向有参考价值。
3. **SimHack: Predicting the onset of detectable reward hacking before RL training**：在 RL 训练前预测 reward hacking 出现，属训练安全方向，与 Agent/RL 工程相关。
