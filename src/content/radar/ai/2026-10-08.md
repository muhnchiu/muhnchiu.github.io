## 研究前沿

从 HuggingFace Papers 和 arXiv cs.LG 中，以下论文值得关注：

1. **The Winner's Curse in LLM Self-Improvement Loops: Selection Noise, Lock-in, and Acceptance Rules**（Litao Hu, Yutong Tang）

   研究指出 LLM 自我改进循环中存在"赢者诅咒"现象：选择噪声导致模型锁定在次优输出上，自我改进反而可能降低质量。论文提出验收规则来缓解此问题。这对理解 LLM 自我训练和 RLHF 中的选择偏差有重要意义。

2. **AdvSim2Real: Training Web Agents Against Adaptive Prompt Injection in a Web World Model**（Sarim Hashmi 等）

   提出在 Web 世界模型中训练 Agent 对抗自适应提示注入攻击的方法。随着 AI Agent 在 Web 环境中部署增加，对抗提示注入的安全性研究具有实际意义。

3. **When Does External Guidance Help LLM Reasoning? A Bias-Variance Theory of Guidance-Augmented**（arXiv cs.LG）

   从偏差-方差理论角度分析外部引导何时有助于 LLM 推理，为理解 LLM 推理能力边界提供理论框架。
