## 重点动态

### 1. Replit 将 OpenAI 设为默认模型

据报道，Replit CEO 表示 Replit 已将 OpenAI 设为默认模型，替代此前的 Anthropic 默认设置。这意味着 Replit 上新的 AI 辅助编码功能默认调用 OpenAI 模型，用户侧无需改动配置即会切换。

- **价值判断**：AI Coding 工具链默认模型切换影响直接，使用 Replit 的团队需确认对现有工作流和成本的影响。
- **与当前栈关联**：当前 AI Coding 工作流若包含 Replit，默认模型切换可能改变实际调用成本和输出质量。
- **来源等级**：media
- **来源名称**：TechCrunch

### 2. Vercel 发布 Jev 模型，称其采用速度最快

据报道，Vercel 发布名为 Jev 的 AI 模型，并称其为 Vercel 史上最快采用的 AI 模型。具体模型规格、定价和 API 开放范围待确认官方文档。

- **价值判断**：若 Jev 面向 Vercel 前端部署场景，对 Web 开发 AI 工作流有潜在价值，需等待官方文档确认后再评估。
- **与当前栈关联**：当前 API 模型栈暂无 Vercel Jev，待官方 API 开放后可纳入评估。
- **来源等级**：media
- **来源名称**：TechCrunch

- **价值判断**：若 DeepSeek V4.1 Flash 确认为官方开放权重，可能对本地推理和低成本 API 有参考价值，当前信息不足以判断。
- **与当前栈关联**：当前 API 模型栈若关注低成本推理，需等待官方确认后再评估。

## 研究前沿

arXiv cs.LG 当日抓取结果为空，无法提供今日最新论文，改以 HuggingFace Papers 当日热门论文为准。值得关注：

1. **SoftCache: Adaptive Step Size Caching for Diffusion Transformers**（Shimon Malnick 等）— 提出自适应步长缓存方法加速扩散 Transformer 推理，对本地扩散模型推理优化有参考价值。
2. **PathFM: Fast Generative Forecasting of Multivariate Trajectories**（Jiachen Yao 等）— 面向多变量轨迹预测的生成式模型，适用于时间序列预测场景。
3. **DK-VLM: Geometry as Position for Spatial Reasoning in Vision-Language Models**（Han Su 等）— 将几何信息作为位置编码用于视觉语言模型的空间推理，对多模态空间理解有参考价值。
