## 研究前沿

**Probing Spatial State Representations in Visual Foundation Models**：关注视觉基础模型中的空间状态表征，可能用于解释视觉定位、世界模型与具身感知任务中的内部状态。该方向与多模态 Agent 的感知层相关，但当前论文列表未提供具体基准或可运行权重证据。

**rTaste: Do Research Agents Have Taste? Evaluating Early Stage Research Judgment**：研究 Agent 在科研早期判断中的偏好与筛选能力，适合观察 Agent 系统中“选择问题”的评价标准。若未来形成公开 benchmark，可辅助评估当前 AI Coding 与深度研究工作流。

**Video Generation Meets Agent Harness**：将视频生成与 Agent Harness 结合，讨论 Agentic Video Generation、世界建模与递归自我改进。该方向更偏前沿系统，距离生产工具仍有距离，但能反映 Agent 系统向多模态生成闭环扩展的趋势。
