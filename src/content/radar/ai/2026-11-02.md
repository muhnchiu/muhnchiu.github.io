# AI 模型与工具雷达日报 2026-11-02

> 数据来源：HuggingFace Papers、HuggingFace Models、GitHub AI Repositories、OpenRouter Models、TechCrunch AI、arXiv cs.LG
> 抓取时间：2026-11-02 08:20 (Asia/Shanghai)

---

## 今日概览

今日 AI 模型与工具生态以开放模型页面活跃为主：HuggingFace 上 baidu/Unlimited-OCR-2（MIT 许可，近30天 109519 下载）、ccore/Qwen3.5-4B-3D-Coder（44825 下载）等新开放模型出现，LTX-2.5（2431846 下载）与 Qwen3.8-27B（7892866 下载）社区获取量高。OpenRouter 免费模型列表当前包含 14 个模型，较 2026-10-30 快照（15 个）少了 Poolside Laguna S/XS 2.1，多了 google/gemma-4-31b-it:free。据报道，OpenAI 新一轮融资目标下调；Ollie（隐私向 AI 助手）据报道停止服务。当前 API 模型栈无立即迁移或强制下线信号。

---

## 重点动态

### 1. Baidu Unlimited-OCR-2 开放权重（MIT 许可）

HuggingFace 当前存在 `baidu/Unlimited-OCR-2` 页面（近30天 109519 下载，较 10-30 快照的 18141 下载显著上升），许可为 MIT（页面声明），类型为 image-text-to-text，权重格式为 safetensors。具体发布日期未确认。

- **价值判断**：MIT 许可的 OCR 模型，本地文档/票据/截图文字提取可直接使用，商用限制低。
- **与当前栈关联**：可作为本地文档处理管线补充，不与主力 API 模型冲突。
- **来源等级**：ecosystem
- **来源名称**：HuggingFace

### 2. Qwen3.5-4B-3D-Coder 4B 级 3D 编码模型

HuggingFace 当前存在 `ccore/Qwen3.5-4B-3D-Coder` 页面（近30天 44825 下载，较 10-30 快照的 12237 下载上升）。页面类型标记为未标注（抓取数据中为 -），License 未确认，架构按命名推断为 4B 级别，待页面确认。

- **价值判断**：小参数 3D 方向模型，若为代码/3D 双用途可纳入测试。
- **与当前栈关联**：AI Coding 工作流中可作为轻量候选测试，需确认能力边界。
- **来源等级**：ecosystem
- **来源名称**：HuggingFace

### 3. Google Gemma 4 31B 加入 OpenRouter 免费模型列表

OpenRouter 当前免费模型列表包含 `google/gemma-4-31b-it:free`（同时保留 `gemma-4-26b-a4b-it:free`）。与 2026-10-30 快照对比，该 31B 型号为快照中不存在的条目，属于当前存在状态，上线时间未确认。

- **价值判断**：31B 级免费 API 推理选项，agent 与多模态测试成本进一步降低。
- **与当前栈关联**：可纳入免费 fallback 层测试，不替代主力模型。
- **来源等级**：ecosystem
- **来源名称**：OpenRouter

### 4. Pika-H3-Flex 视频模型与 LTX-2.5 社区获取量高

HuggingFace 当前存在 `Pika-Labs/Pika-H3-Flex`（image-to-video，404 下载）页面，许可为自定义（Pika 社区协议，非标准开源许可证）；同时 `Lightricks/LTX-2.5` 近30天下载 2431846，为视频类模型中社区获取量最高。具体发布与授权细节部分未确认。

- **价值判断**：视频生成方向选项增多，自定义许可模型商用前需逐条确认协议。
- **与当前栈关联**：与当前模型栈无直接关联，属多模态生成方向观察。
- **来源等级**：ecosystem
- **来源名称**：HuggingFace

### 5. LiquidAI LFM3 系列（Omni/VL/1.7B）扩展

HuggingFace 当前存在 `LiquidAI/LFM3-1.7B`（37568 下载，较 10-30 快照 15885 上升）、`LFM3-Omni-2B`（8376 下载，较 1814 上升）、`LFM3-VL-2B`（9121 下载）。系列覆盖 text-generation、any-to-any、image-text-to-text 方向。

- **价值判断**：2B 级轻量模型矩阵，适合本地/边缘多模态测试。
- **与当前栈关联**：可补充 Apple Silicon 本地环境的轻量多模态层，需实测。
- **来源等级**：ecosystem
- **来源名称**：HuggingFace

### 6. DeepSeek-V4.1-Flash-1017 与社区量化版持续

HuggingFace 当前存在 `deepseek-ai/DeepSeek-V4.1-Flash-1017`（170353 下载，较 10-30 快照 131062 上升），社区量化版 `ISTA-DASLab/DeepSeek-V4.1-Flash-1017-GSQ-RCO-GGUF`（2294642 下载，较 1578937 上升）。GGUF 格式社区获取量高，许可与硬件需求未确认。

- **价值判断**：Flash 小模型本地测试层持续活跃。
- **与当前栈关联**：本地 fallback 候选，不影响当前 API 栈。
- **来源等级**：ecosystem
- **来源名称**：HuggingFace

### 7. 据报道：OpenAI 融资目标下调、Ollie 停止服务、xAI 数据中心诉讼推进

TechCrunch 报道：OpenAI 新一轮融资目标下调（待官方确认具体金额）；隐私向 AI 助手 Ollie 停止服务；xAI 数据中心污染诉讼获法官允许继续推进。均为媒体报道，非官方公告，与当前模型栈无直接技术影响。

- **价值判断**：行业资金面与合规面信号，观察即可。
- **与当前栈关联**：无直接关联。
- **来源等级**：media
- **来源名称**：TechCrunch
