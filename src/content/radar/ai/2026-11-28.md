## 今日概览

今日无重大模型发布。Inkling-2-Mini 的本地衍生生态继续扩大，HuggingFace 上集中出现多个社区 GGUF 变体与第三方适配，是当前本地 AI 方向最值得关注的信号；OpenRouter 免费模型列表当前包含 10 个 :free 模型，较昨日 11 个减少（缺失 inclusionai/ling-3.2-flash:free，原因未确认）。媒体报道（TechCrunch）称 OpenAI 合并 Chat 与 Work 后重度 ChatGPT 用户可能更快触及限额，待官方确认。GitHub 侧 llm.asm 与 opengame 两个仓库星标较高，仅为短期热度信号。arXiv cs.LG 抓取脚本未获取到条目，已通过 arXiv API 手动补充当日最新论文。与当前 API 模型栈相关的直接影响有限，主要建议集中在本地模型试用与免费模型切换评估。

## 重点动态

### 1. Inkling-2-Mini 本地衍生生态扩大：多个社区 GGUF 变体与第三方适配集中上架

HuggingFace 近 30 天热门模型中，Inkling-2-Mini 原模型（thinkingmachines）当前下载 155741，unsloth 的 GGUF 版本当前下载 3302340，AtomicChat 的 Uncensored-GGUF 当前下载 1059763，另有 orcarouter 的 abliterated-GGUF（21019）、ISTA-DASLab 的 GSQ-RCO-GGUF（24931）与 strata-engine 的 Strata 适配（4532）等社区变体。多个变体同时出现在热榜说明该模型在本地部署生态中的关注度较高。原模型为 image-text-to-text 架构，各变体的 License 未确认（HuggingFace 出现模型页面不等于开放权重，也不等于开源许可证）。

- **价值判断**：本地多模态小模型生态的可用选项正在增加，值得在本地环境实际测试。
- **与当前栈关联**：可作为当前 API 模型栈之外、Apple Silicon 本地环境的补充试用选项；内存/显存需求未确认，需实测。
- **来源等级**：ecosystem
- **来源名称**：HuggingFace

### 2. OpenRouter 免费模型列表当前包含 10 个 :free 模型，较昨日 11 个减少

当前免费模型列表包含：baidu/ernie-5.5-flash-preview、liquid/lfm-3-1.7b、particle-ai/particle-1、recursive/flint-v1.0、nvidia/nemotron-3.5-super-vl、nvidia/nemotron-3.5-lightning、nvidia/nemotron-3-ultra-550b-a55b、nvidia/nemotron-3-nano-omni-30b-a3b-reasoning、google/gemma-4-26b-a4b-it、google/gemma-4-31b-it。与昨日（11 个）对比，缺失 inclusionai/ling-3.2-flash:free，变化原因未确认（OpenRouter 免费池存在常规轮换，无官方说明）。当前列表中 NVIDIA Nemotron 3 系列与 Google Gemma 4 系列占主导。

- **价值判断**：免费池仍是低成本多模型评估的主要渠道，但需避免对 :free 模型做生产依赖。
- **与当前栈关联**：可作为当前 API 模型栈的低成本补充测试渠道，建议以非生产流量验证输出稳定性。
- **来源等级**：ecosystem
- **来源名称**：OpenRouter

### 3. OpenAI 据报道：合并 Chat 与 Work 后重度 ChatGPT 用户可能更快触及限额

据报道（TechCrunch，11-25），OpenAI 称在合并 Chat 与 Work 产品线后，重度 ChatGPT 用户可能更快触及使用限额。该信息来自媒体报道，待官方确认具体限额规则与生效时间。S&P 同时被报道在考虑因治理与关键人物风险下调 Nvidia 信用评级，属供应链背景信息，与当前模型栈无直接关联。

- **价值判断**：若属实，高频 API 调用与订阅用户需重新评估限额策略，但暂无官方证据。
- **与当前栈关联**：当前 API 模型栈不依赖 ChatGPT 订阅配额；若团队有 ChatGPT 订阅用量，建议关注官方公告。
- **来源等级**：media
- **来源名称**：TechCrunch

### 4. DRBench Pro：面向专业深度研究 Agent 的以知识为中心的基准

HuggingFace Papers 今日热榜包含 DRBench Pro（Han Huang 等）：一个以知识为中心的基准，用于评估专业领域深度研究 Agent。同类方向还包括昨日出现的 Mixture-of-Loops Transformer（arXiv 11-25 提交）等。深度研究 Agent 的评测基准持续增加，说明该方向从演示走向系统化评估。

- **价值判断**：为深度研究 Agent 类项目提供了可引用的评测参照，值得阅读。
- **与当前栈关联**：与当前 AI Coding 工作流关联较低，但可用于评估研究类 Agent 任务的设计。
- **来源等级**：research
- **来源名称**：HuggingFace Papers
