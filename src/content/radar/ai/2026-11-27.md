## 今日概览

今日 AI 生态有三条主线：其一，Inkling-2-Mini（image-text-to-text 类型）及其多个社区衍生量化/改版（unsloth GGUF、Uncensored、abliterated、strata-engine）集中出现在 HuggingFace 热门列表，其中 unsloth GGUF 当前下载量 2445633，社区获取量高，值得本地部署评估；其二，OpenRouter 当前 :free 免费模型列表包含 11 个模型，NVIDIA Nemotron 系列占据 4 席，可作为无成本推理候选；其三，媒体报道 OpenAI 称重度 ChatGPT 用户可能更快触及限额（据报道，待官方确认），与当前 API 模型栈的成本评估相关。Qwen3.8-27B 仍出现在热门列表（当前下载量 6047011），另有多个 Qwen3.8-27B 衍生适配版出现。无核心数据源缺失，可正常产出日报。

## 重点动态

### 1. Inkling-2-Mini 及社区衍生模型集中上架 HuggingFace

HuggingFace 近 30 天热门模型列表中，thinkingmachines/Inkling-2-Mini（96527 下载）出现后，unsloth/Inkling-2-Mini-GGUF（2445633 下载）、AtomicChat/Inkling-2-Mini-Uncensored-GGUF（762491 下载）、orcarouter/Inkling-2-Mini-abliterated-GGUF（12157 下载）、strata-engine/Inkling-2-Mini-Strata（2965 下载）等衍生版本集中出现，类型均为 image-text-to-text。HuggingFace 出现模型页面不等于官方发布，也不等于开放权重或特定开源许可证，License 状态待确认。

- **价值判断**：多版本快速跟进表明该模型在本地社区有实际部署需求，GGUF 版本适合 Apple Silicon 本地环境评估。
- **与当前栈关联**：可作为本地多模态推理候选，与当前 API 模型栈互补（本地跑、API 兜底）。
- **来源等级**：ecosystem
- **来源名称**：HuggingFace

## 研究前沿

1. **DRBench Pro**（HuggingFace Papers）：面向专业深度研究 Agent 的知识中心基准，评测 Agent 在真实知识任务上的表现，可作为 Agent 能力评测的补充工具。
2. **Solve Vision with Code**：实证表明 coding agent 的视觉推理强于纯 video model，对多模态推理路线选择有参考意义——"用代码桥接视觉与推理"可能优于端到端 video 模型。
3. **REI: Learning Ideation from Repository Evolution**（arXiv）：从仓库演化中学习"构思"过程，与 AI Coding 工作流的创新路径相关。
