## 重点动态

### 1. Nemotron 3.5 系列出现在 OpenRouter 免费档

当前 OpenRouter 免费模型列表包含 nvidia/nemotron-3.5-lightning 与 nvidia/nemotron-3.5-content-safety，同时 Nemotron 3 Ultra（550B-A55B）、Super（120B-A12B）、Nano Omni（30B-A3B）仍在免费列表中。Nemotron 3.5 与 3 并存于免费档，但无历史快照可确认 3.5 的上线时间，本次仅记录"当前存在"。

- **价值判断**：免费档覆盖大参数量推理模型与内容安全分类器，适合低成本验证。
- **与当前栈关联**：可作为当前 API 模型栈中非关键任务的免费补充选项。
- **来源等级**：ecosystem
- **来源名称**：OpenRouter

### 2. Qwen3.8-27B 多模态模型社区获取量领先

Qwen/Qwen3.8-27B（image-text-to-text）近 30 天下载量 6843108，为今日热门榜最高；其社区 GGUF 量化衍生（ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF）下载量 4189006，另有一个名称极长的社区微调版本下载 56525。下载量反映社区获取量高，不代表部署质量。

- **价值判断**：27B 级多模态模型社区获取量最高，评测素材与量化版本充足。

## 研究前沿

1. **One Block, Multiple Depths: Recurrent Vision Transformers with Depth-Programmed Experts**：提出用单个 block 的循环复用配合深度编程专家（depth-programmed experts）构建视觉 Transformer，目标是在固定参数量下增加有效深度。对端侧视觉模型的效率设计有参考价值。

2. **Dex-One2Many: Learning Dexterous Manipulation from a Single Human Demonstration**：研究如何从单条人类演示学习灵巧手操作并泛化到多任务场景，属于 sim-toreal 与样本效率方向的延续。

3. **DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training**：提出动作忠实（action-faithful）的机器人世界模型，通过反事实后训练提升模型对"如果采取不同动作会怎样"的预测一致性，是世界模型用于机器人规划方向的代表性工作。

## 与当前模型栈的影响

1. **成本侧**：免费档可覆盖大量非关键任务（Nemotron 3 Ultra 550B 级免费推理、Gemma 4 31B、Cohere North Mini Code 做代码辅助），当前 API 模型栈可将草稿、分类、摘要类任务分流到免费档验证质量。
2. **本地侧**：Qwen3.8-27B 的社区量化版本充足，若近期有本地多模态评测计划，素材与量化工具链已就绪，但官方许可证状态需先行确认再决定生产使用。
3. **代理治理侧**：Anthropic 评测隔离（据报道）与 Nadella"紧急制动"表态同向出现，提示当前 AI Coding 与代理工作流应持续保持权限最小化与评测环境隔离，避免代理直连生产网络。
4. **无直接影响项**：机器人/世界模型论文、Apple 智能家居新闻对当前 API 模型栈无直接影响。
