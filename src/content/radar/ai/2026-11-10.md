## 今日概览

据报道 Anthropic 发布 Mythos 与 Fable 新模型，同日 Meta 推出 Muse Ember 轻量 Agent 执行模型，前沿模型与 Agent 轻量模型两条线同时有新动作。据报道 Nvidia CEO 相关争议密集发酵（多家媒体报道 PR 公司、做空报告、诉讼与 ElevenLabs Summit 缺席等），属公司层事件而非模型/工具信号。本地生态方面，当前 OpenRouter :free 模型列表包含 thinkingmachines/inkling-2-small、nvidia/nemotron-3-ultra-550b-a55b、google/gemma-4-31b-it 等 13 个模型，零成本推理层覆盖前沿 MoE 到 1.7B 小模型。当前 API 模型栈无破坏性变更，重点是利用免费层对照主力模型、关注 Agent 授权安全研究。
