## 研究前沿

### HuggingFace Papers 方向

- **Work Agents: Systems, Capabilities, and Optimization**：面向工作场景的 Agent 系统综述与优化方向，对 Agent 工程落地有参考价值。
- **Back to Basics: A Skill-Centric Approach to Generalist Web Agents**：以 Skill 为核心的通用 Web Agent 方法，反映 Web Agent 研究向技能解耦方向演进。
- **The Agent in the Middle: How AI-Mediated Access Reshapes Web Vulnerability Exploitation**：讨论 AI 中介访问如何改写 Web 漏洞利用路径，对 Agent 安全设计有参考意义。

### arXiv cs.LG 方向

- **Autoregressive Multimodal Anomaly Detection with Large Language Models for Microservice Systems**：将 LLM 与多模态异常检测结合用于微服务系统，反映 LLM 在 SRE/可观测性方向的探索。
- **Does LeWorldModel Preserve Local Action Geometry?**：探讨世界模型是否保持局部动作几何，是世界模型方向的理论问题。
