## 研究前沿

### 1. Flash-dLLM: IO-Aware KV Caching and Parallel Decoding for Fast, Memory-Efficient Diffusion LLMs

该论文提出针对 Diffusion LLM 的 IO 感知 KV 缓存和并行解码方法，旨在提升推理速度和内存效率。Diffusion LLM 作为新兴生成范式，其推理效率是实际部署的关键瓶颈，此方法若经过验证可显著降低部署成本。

### 2. Agensh: Scaling Organizational Intelligence to 1,024 Agents

该论文研究将多智能体系统扩展到 1024 个 Agent 的规模，探讨组织级智能的规模化方法。多 Agent 协作是当前 Agent 系统设计的重要方向，规模化能力直接决定应用边界。

### 3. Beyond Repeated Sampling: Learning Search Policies for LLM Reasoning

该论文提出学习搜索策略而非依赖重复采样来提升 LLM 推理能力。当前主流方法通过多次采样提升推理质量，但成本较高。学习搜索策略可能在保持质量的同时降低推理成本。
