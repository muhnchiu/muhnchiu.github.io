## 研究前沿

1. **ScaleVLA: Scaling Vision-Language-Action Models to 552 Billion Parameters**（Ruixi Yu, Dairu Liu, Xuchuan Chen, Zekun Qi, Zekai Li）：将视觉语言动作模型扩展至 552B 参数，VLA 规模化方向，对长时序视觉 agent 系统有参考意义。
2. **ViRA: Toward Ultra-High-Resolution Visual Agents via Cross-Input Relative Policy Optimization**（Huawei Lin, Jinting Liu, Tongyan Wang, Xuyang Chen, Ruihua Shi）：面向超高分辨率视觉 Agent 的跨输入相对策略优化，视觉 Agent 方向，对高分辨率输入处理有参考意义。
3. **AuXSpec: Learning to Autoformalize Program Specifications via Executable Postconditions**（Haocheng Wang, Weixuan Yuan, Florian Hübler, Yinya Huang, Zhijiang Guo）：通过可执行后置条件学习自动形式化程序规约，AI Coding 方向，与当前 AI Coding 工作流直接相关；另有 arXiv cs.LG 当日条目 "Check Token: Real-Time Self-Verification and Precise Truncation in LLM Reasoning"（LLM 推理实时自验证与精确截断）与 "GRAFT: Cross-Backbone LoRA Reuse for Continual Language and Multimodal Learning"（跨骨干 LoRA 复用持续学习），方向相关，arXiv 数据源内容获取不完整（FAIL）。
