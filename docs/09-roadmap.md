## 优先路线

### A 完成自动运行验收

观察下一次实际调度批次，逐类核对启动、采集、分析、发布和页面，并验证环境同步。预定时间尚未发生或运行未完成时保持 PENDING，不提前关闭恢复问题。

### B 强化发布可靠性

优先落实历史 P2-007 的 STOP 边界，再处理 P2-006 的发布前 Schema 校验和 P2-008 的静默失败可见性。修复前核对这些历史 issue 是否已经关闭，避免重复工作。

验收应包含失败即停止、超限 highlights 被发布前阻断、原始分析不丢失、失败能被维护者看见。通知渠道和外发操作需对应授权。

### C 改善报告与 Pages

在现有静态站点和本地资源范围改善日期覆盖、来源状态、阅读导航与计数一致性。公开页面不得暴露私有诊断、Registry 或个人 Stack 清单。

### D 按授权独立推进能力验证

Human Validation、Domain Review 和 Score / Action capability 分别按现有冻结输入与授权进行非生产验证。Provider 不可用不能通过默认判断或伪造输入替代。

### E 保持严格 Trusted Head 独立阻塞

Profile 2.0 冻结、外部权威 qualification 和完整运行授权继续按专门门禁处理。不能为恢复日常日报降低防回滚要求，也不默认开通付费云资源。
